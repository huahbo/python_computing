# 使用说明

## 1. 在支持 Jupyter 的环境打开（Jupyter Notebook / JupyterLab / VS Code 的 Notebook 支持）。

## 2. 题目 notebook：每题的提示是隐藏的 —— 点击提示标题可以展开阅读。

## 3. 答案 notebook：每题有完整可运行代码。已在当前环境中执行并验证所有 30 个答案单元能正常运行。

## 4. 本题目覆盖主题

* Pandas 基础：Series/DataFrame 创建、索引（loc/iloc）、选择与切片。 （4.Pandas及其基本使用）

* 缺失值处理、重复数据处理、异常值检测（IQR）与替换。 （4.Pandas及其基本使用）

* 分组（groupby）：聚合、变换、过滤、以及多级聚合。  https://pandas.pydata.org

* 透视表（pivot_table）、stack/unstack 与 MultiIndex 操作。 https://pandas.pydata.org

* 时间序列：Timestamp、date_range、resample、rolling、时区基础（练习中包含重采样与滚动窗口）。（4.Pandas及其基本使用）

* 数据规约（min-max / z-score）与统计描述（describe、quantile、groupby+agg）。 （4.Pandas及其基本使用）

* Matplotlib：折线、散点、条形、箱线、子图布局、GridSpec、保存图像、图例/注释、布局微调。http://matplotlib.org

* 进阶题（较难）：性能对比（apply vs vectorize）、复杂 pivot/multiindex 操作、综合小项目（数据清洗→透视→可视化）等。
