# 绪论：什么是科学计算

## 什么是科学计算

从原始人的结绳记事到今天的 ChatGPT，数学伴随着人类文明一同发展。很多同学害怕数学，主要是觉得理论抽象、不知用途。但随着人工智能与科学计算的崛起，数学正在以非常实际的方式走向应用。科学计算已成为推动科技进步、经济发展和国际竞争力的关键力量。

> 科学计算是利用计算机技术和数学方法，对科学、工程、经济、社会等领域的复杂问题进行建模、仿真、分析和求解的过程。它旨在通过精确的计算和深入的数据分析，揭示问题的本质，预测未来的趋势，为决策提供科学依据。

## 为什么用 Python

Python 通用、易学、开源，生态中几乎每个方向都有高质量库。本课程把 Python 科学计算最常用的 8 个工具抽出来讲：

- **NumPy**：数组与线性代数（基础中的基础）
- **SymPy**：符号计算（推导、求解）
- **SciPy**：数值微积分、优化、插值、统计与 FFT
- **Pandas**：表格数据清洗与分析
- **Matplotlib / Seaborn**：可视化
- **NetworkX**：图与网络分析
- **Statsmodels**：统计建模（回归、时间序列）
- **scikit-learn**：机器学习
