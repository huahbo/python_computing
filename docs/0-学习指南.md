# 0 学习指南：环境搭建与学习路径

## 1. 推荐环境

- **Python 3.10–3.13**
- **编辑器**：VS Code（安装 Python、Jupyter 插件）或 JupyterLab
- **核心依赖**：

```bash
pip install numpy pandas scipy sympy matplotlib seaborn networkx statsmodels scikit-learn
```

> 网络慢可用国内镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <库名>`

## 2. Windows 环境搭建步骤

1. 安装 Python（勾选 **Add Python to PATH**）；
2. 打开 VS Code → 扩展市场 → 安装 **Python** 与 **Jupyter**；
3. 新建文件夹（建议全英文路径）作为课程目录；
4. 在终端创建虚拟环境：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1   # PowerShell
# 或 cmd: .venv\Scripts\activate.bat
```

5. 安装依赖（见上）；
6. 打开任意 `.ipynb`，选择内核为 `Python 3`（.venv）即可运行。

## 3. 如何打开并使用本教程

- **网页版**：GitHub Pages 部署后，从侧边栏导航；
- **本地**：用 docsify 等工具渲染；或直接打开 `chapters/` 下 `.md` 阅读；
- **上机/作业**：打开 `exercises/`、`lab/` 下的 `.ipynb`。

## 5. 作业与考核建议

- **平时作业**：每章 exercises 的 `quiz.ipynb`（自动评分）与 `assignment`；
- **上机**：每章 `lab/` 完成情况（每次上机课 4 学时：0.5h 回顾 + 3h lab + 0.5h quiz/总结）；
- **期末**：`教学资源/期末大作业/`（项目 1 电商分析 + 项目 2 交通网络），第 8 周布置，课程结束后 2–3 周内提交。

## 6. 常见问题

| 问题 | 解决办法 |
| ---- | ---- |
| `ModuleNotFoundError` | 确认激活了虚拟环境并 pip 安装 |
| 中文路径报错 | 项目路径全部用英文 |
| Jupyter 找不到内核 | 在 VS Code 中选择解释器后重启 |
| 图片不显示 | notebook 顶部加 `%matplotlib inline`，或改用 `plt.savefig` |
| 随机结果不一致 | 使用 `np.random.default_rng(seed)` / `np.random.seed(seed)` |
