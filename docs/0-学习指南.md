## 4. 作业与考核建议

- **平时作业**：每章 exercises 的 `quiz.ipynb`（自动评分）与 `assignment`；
- **上机**：每章 `lab/` 完成情况（每次上机课 4 学时：0.5h 回顾 + 3h lab + 0.5h quiz/总结）；
- **第 0 章特别要求**：提交环境自检输出 + lab0 报告 PDF（用 LaTeX）——这是期末大作业报告的预演；
- **期末**：`教学资源/期末大作业/`（项目 1 电商分析 + 项目 2 交通网络），第 8 周布置，课程结束后 2–3 周内提交，报告需用 LaTeX 排版。

## 5. 常见问题

| 问题 | 解决办法 |
| ---- | ---- |
| `ModuleNotFoundError` | 确认激活了 `scicomp` 环境并安装依赖（见第 0 章） |
| 中文路径报错 | 项目路径全部用英文 |
| Jupyter 找不到内核 | 在 VS Code 中选择解释器后重启；或 `python -m ipykernel install --user --name scicomp` |
| LaTeX 中文编译失败 | 用 `latexmk -xelatex`（不要 pdflatex）；详见第 0 章 00-05 |
| 图片不显示 | notebook 顶部加 `matplotlib.use("Agg")`，或改用 `plt.savefig` |
| 随机结果不一致 | 使用 `np.random.default_rng(seed)` / `np.random.seed(seed)` |
