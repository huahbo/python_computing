# Markdown 语法简明指南

Markdown 是一种轻量级标记语言，常用于编写说明文档、笔记、博客等。以下是常用语法说明与示例。

---
## 1. 标题

使用 `#` 来表示标题，数量越多，标题层级越低。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

效果：

# 一级标题
## 二级标题
### 三级标题

---
## 2. 段落与换行

- 直接输入文字就是段落。  
- 在行尾输入两个空格可以实现换行。

```markdown
这是第一行。  
这是第二行。
```

效果：  
这是第一行。  
这是第二行。

---
## 3. 字体样式

```markdown
*斜体* 或 _斜体_  
**加粗**  
***加粗并斜体***  
~~删除线~~
```

效果：  
*斜体* 或 _斜体_  
**加粗**  
***加粗并斜体***  
~~删除线~~

---
## 4. 列表

### 无序列表
```markdown
- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2
```

效果：
- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2

### 有序列表
```markdown
1. 第一项
2. 第二项
3. 第三项
```

效果：  
1. 第一项  
2. 第二项  
3. 第三项

---
## 5. 链接与图片

```markdown
[百度](https://www.baidu.com)  
![图片示例](https://www.markdownguide.org/assets/images/tux.png)
```

效果：  
[百度](https://www.baidu.com)  

![图片示例](https://www.markdownguide.org/assets/images/tux.png)

本地图片：
```markdown
![本地图片](./md_figures/picture.png)
```
效果

![本地图片](./md_figures/picture.png)

## 6. 引用

```markdown
> 这是一个引用。
>> 可以嵌套引用。
```

效果：
> 这是一个引用。
>> 可以嵌套引用。

---
## 7. 代码与代码块

### 行内代码
```markdown
这是 `inline code` 示例。
```

效果：这是 `inline code` 示例。

### 多行代码块
```markdown
```python
def hello():
    print("Hello, Markdown!")
```
```

效果：

```python
def hello():
    print("Hello, Markdown!")
```

## 8. 表格

```markdown

| ---- | ---- | ---- |
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

效果：

| 姓名 | 年龄 | 城市 |
| ---- | ---- | ---- |
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |

效果：

## 10. 任务列表

```markdown
- [x] 已完成任务
- [ ] 待完成任务
```

效果：
- [x] 已完成任务
- [ ] 待完成任务

## 总结

以上是 Markdown 的常用语法，适合快速编写结构化文档。
