## 二、Project 1（中等难度）：电商销量数据分析与简单预测

### 1. 背景说明

某电商平台提供了最近一年的订单数据，你需要利用本课程所学的科学计算工具，对数据进行清洗、探索性分析、统计建模与机器学习预测，并输出可视化报告。

本项目重点考察：**Pandas 数据分析、Numpy 计算、Matplotlib/Seaborn 可视化、Scipy 统计检验、Statsmodels 回归建模、Sklearn 回归预测与特征工程、Sympy 符号计算**。

### 2. 数据说明

教师将提供一个名为 `ecommerce_orders.csv` 的数据文件，或给出数据生成脚本。表结构建议如下（UTF-8 编码）：

```text
order_id        订单ID（字符串）
order_date      下单日期，格式 YYYY-MM-DD
user_id         用户ID（字符串）
product_id      商品ID（字符串）
category        商品类别（字符串）
price           商品单价（浮点数）
quantity        购买数量（整数）
city            用户所在城市（字符串）
channel         下单渠道，取值 {web, app}
ad_campaign     所属广告活动，取值 {A, B}
```

> 若实际数据结构略有不同，请根据实际字段进行相应调整，并在报告中将字段含义说明清楚。

### 3. 任务要求

   - 平均客单价（每单平均金额）；
   - 用户数量（去重后的 `user_id` 个数）；

4. 分别按 `city` 和 `category` 统计：
   - 总销售额；

#### Task 5（可选加分）：Sympy 进行利润最大化推导

假设某类商品的利润模型为：

\`\`\`math
profit(p) = (p - c) \cdot D(p)
\`\`\`

其中：

- \(p\)：商品价格；
- \(c\)：成本价（常数）；
- \(D(p) = a - b p\)：线性需求函数（参数 \(a, b > 0\)）。

要求：

1. 使用 `sympy` 定义符号变量，推导使利润 `profit(p)` 最大的最优价格 \(p^*\)；
2. 在报告中写出推导过程与最终解析式；
3. 可根据实际需求选取一组参数 \(a, b, c\)，给出数值示例。

## 三、Project 2（较高难度）：城市公共交通网络分析与客流预测

### 1. 背景说明

本项目重点考察：**Networkx 图网络建模与分析、Scipy 简单优化、Statsmodels 时间序列建模、Sklearn 回归预测与特征重要性、Sympy 符号推导**。

为便于统一评分，本项目允许你：

- 直接使用教师提供的 CSV 数据；或
- 按教师给出的数据格式，自行用随机方法生成一个小型网络数据集。

请在报告中清晰说明数据来源与构造方式。

### 2. 数据设计（建议格式）

可以使用下列三张表（CSV），或者在代码里直接构造等价的 `DataFrame`：

1. `stations.csv`：站点信息  
   ```text
   station_id    站点ID（整数或字符串）
   name          站点名称
   x, y          站点坐标（用于 2D 可视化，可虚构）
   ```

2. `edges.csv`：线路信息（边）  
   ```text
   from_station
   to_station
   travel_time   此边的行程时间（分钟）
   capacity      该边的理论最大客流（人次/小时）
   ```

3. `flows.csv`：某条或若干条线路在一段时间内的客流记录  
   ```text

   passenger_flow  当日客流量（人次）
   ```

#### Task 5：票价优化的符号推导（Sympy）

假设某条线路的每日客流量与票价 \(p\) 的关系近似为：

\`\`\`math
D(p) = \alpha e^{-\beta p}
\`\`\`

票价为 \(p\) 时，该线路的日收入：

\`\`\`math
R(p) = p \cdot D(p) = \alpha p e^{-\beta p}
\`\`\`

要求：

1. 使用 `sympy` 定义符号变量，求出使收入 \(R(p)\) 最大的最优票价 \(p^*\) 的解析形式；
2. 任选一组参数（例如 \(\alpha = 1000, \beta = 0.5\)），绘制 \(R(p)\) 关于 \(p\) 的曲线；
3. 在报告中分析：
   - 当票价过低或过高时，收入变化的趋势；
   - 最优票价大致落在什么区间，是否符合你的直观预期。
