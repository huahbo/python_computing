# 第 5 章 教学说明（教师用）

> 面向授课教师：课时建议、重点难点、上机安排、考核建议。学生无需阅读本页。

## 1. 教学目标

- 让学生**会查官方文档**并独立写出正确的 Matplotlib/Seaborn 代码；
- 建立“Figure/Axes 对象层级 + 数据驱动图形”的心智模型；
- 能独立完成：基础图表、多子图排版、Seaborn 统计图、保存高分辨率图片、一份完整数据报告图。

## 3. 重点与难点

### 重点
- Figure/Axes 对象模型与 `plt.subplots`；
- `figsize/dpi/rcParams` 与中文字体设置；
- 颜色/线宽/线型/标记/网格/图例；
- `tight_layout` / `subplots_adjust` 排版；
- `savefig` 输出与 DPI。

### 难点（学生常卡）
- 函数式与面向对象接口混用；
- `seaborn.set_theme` 覆盖字体（必须重新设 rcParams）；
- `set_xticks` 与 `set_xticklabels` 区别；
- 热力图 `fmt` 与数据类型匹配；
NaN

## 6. 易错点清单（直接用于出题）

1. 不调 `plt.show()`/`savefig`，图形“丢失”；
2. 混用 `plt.title` 与 `ax.set_title`；
3. `seaborn.set_theme` 后不重设中文字体；
4. `fmt="d"` 传给浮点 heatmap；
5. 用旧版 `shade=True`；
6. 把 `figsize` 当像素；
7. 忘记 `tight_layout`。
