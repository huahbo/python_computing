## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | 只 `plt.plot` 不 `plt.show()`/`savefig` | 脚本中用 `plt.savefig`；交互环境用 `plt.show()` | 图可能“画了不显示/不保存” |
| 2 | 面向对象代码里混用 `plt.title` | 用 `ax.set_title(...)` | 多子图时 `plt` 作用于当前轴，易错 |
| 3 | 忘记 `ax.set_xticks` 与 `set_xticklabels` 的区别 | 前者设位置，后者改文字 | 两个函数语义不同 |
| 4 | 误以为 `figsize` 是像素 | 单位是英寸，需乘 `dpi` 得到像素 | 单位语义错误 |
| 5 | `rcParams` 在 seaborn `set_theme` 之前设置 | 主题之后重新设置字体 | `set_theme` 会重置 `font.sans-serif` |
| 6 | 对 `heatmap` 传 `fmt="d"` 而数据是浮点 | 改用 `fmt=".0f"` 或 `.2f` | 格式码与数据类型不匹配 |
| 7 | 用旧版 `shade=True` | 用 `fill=True` | 新版参数已改名 |
| 8 | `plt.subplots(2,2)` 后用 `plt.subplot()` 再画 | 统一用返回的 `axs.flat` | 两个接口混用会叠加到错误的轴 |
| 9 | 忘记 `np.meshgrid` 就画 3D 曲面 | 先 `np.meshgrid` 生成 2D 网格 | 曲面需要网格化的 X, Y, Z |
| 10 | 误以为一张图只能有一个 Figure | 一个脚本可多 Figure；用 `plt.figure()` 新建 | 状态管理理解偏差 |
| 11 | 中文标题变方块还不设字体 | 设 `rcParams["font.sans-serif"] = ["Microsoft YaHei", ...]` | 默认字体不含中文字形 |
| 12 | 频繁 `plt.show()` 后又想改 `rcParams` | 先设全局参数再绘图 | `rcParams` 影响后续创建的对象 |

## 2. 原理级难点：面向对象 vs 函数式

```python
# 函数式：简单，但一张图只有一个“当前轴”
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [1, 4, 9])
plt.title("one")

# 面向对象：显式管理多个轴
fig, axs = plt.subplots(2, 2)
axs[0, 0].plot([1, 2], [2, 1])
axs[0, 0].set_title("topleft")
axs[1, 1].scatter([1, 2], [3, 4])
```

> 经验：**单图且临时探索用函数式；多子图/出版图用面向对象**。二者混用是学生最常见的返工原因。

## 3. 性能与排版技巧

- **优先 `tight_layout()`**：比反复 `subplots_adjust` 手工试更快；
- **用 `ax.set_xticks`/`set_xticklabels` 控制刻度**：避免默认 0,0.5,1 与数据不匹配；
- **大量子图用 `mosaic` / `GridSpec`**：`fig, axs = plt.subplots` 只支持均匀网格；不均匀用 `GridSpec` 更灵活；
- **图片给 `dpi`**：论文图建议 300 DPI，屏幕演示 100–150 DPI；
- **复用同一 `fig` 与 `ax`**：一个循环里不断 `plt.figure()` 会开几十个窗口，消耗内存；
- **`savefig` 前先 `fig.tight_layout()`**，否则标题会被裁剪。

## 4. 调试建议

1. 中文变方块：先检查 `font.sans-serif` 是否在用中文字体，再看 `axes.unicode_minus`；
2. 图形为空/只显示一张：确认是否用了 `plt.figure()` 后又 `plt.subplot` 建了新轴；
3. 子图重叠：调用 `fig.tight_layout()`；
4. 坐标范围不对：打印 `ax.get_xlim()` / `ax.get_ylim()` 调试；
5. 图例不出现：检查 `plot(label=...)` 是否每一条都有 `label`，再看 `legend()`；
6. 保存的文件打不开：确认有写权限，扩展名正确，且 `savefig` 前没有 `close`。
