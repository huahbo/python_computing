# 第 5 章 练习题（exercises/）

> 本章练习的**唯一入口**。原 `../chapter_4_5_quiz/` 下的 Pandas+Matplotlib 合订 quiz 已按“第 5 章独立”要求整理成 Matplotlib 专属的自动评分 quiz，本题库不再混入 Pandas 内容。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `assignment.md` | 作业题 | 覆盖基础绘图、布局排版、Seaborn、综合应用；含详细答案解析 |
| `quiz.ipynb` | 学生自测/提交版 | 14 题（题面 + 空白答案单元 + **自动评分**，总分 30） |
| `answers.ipynb` | 教学答案版 | 每题完整可运行答案 + 自动测试（已验证 30/30） |

## 使用方法

1. **作业**：打开 `quiz.ipynb`，按题号完成 `# TODO` 单元，运行全部单元后查看最后的 `总分/得分率`。
2. **自测**：先不看答案完成 `assignment.md` 的题目，再用 `answers.ipynb` 对照。
3. **课堂**：教师可用 `answers.ipynb` 现场演示每题；每道题自带自动测试。

## 建议完成顺序

1. 读 01–03 正文 → 2. `lab/` 上机 → 3. 做 `assignment.md` 第 1–6 题（易） → 4. 第 7–11 题（中） → 5. 第 12–14 题（综合/难）。

## 评分建议

- `quiz.ipynb` 自动评分 14 题、总分 30；建议占总评 15–20%；
- 上机 `lab/` 占总评 10–15%；
- 综合案例报告（04 拓展）可作为期中/项目加分项。

## 备注

- 运行 `quiz.ipynb` 会在当前目录生成 `quiz_q7.png`（第 7 题保存图像用），提交前可不删除。
- 题库使用 seaborn 内置数据（tips / flights），首次运行需联网下载或本地已缓存。
