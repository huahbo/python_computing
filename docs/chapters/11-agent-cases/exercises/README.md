# 第 11 章 练习题（exercises/）

> 本页是**第二部分（第 9–12 章）练习的统一入口**。

| 文件 | 用途 | 题量 | 说明 |
| ---- | ---- | ---- | ---- |
| [quiz.ipynb](./quiz.ipynb) | 学生自测（自动自检） | 10 题 | 概念 4 + 审查 4 + 实操 2；每题含提示与 assert 自检 |
| [answers.ipynb](./answers.ipynb) | 参考答案版 | 10 题 | 每题给参考实现，可直接运行验证 |
| [assignment.md](./assignment.md) | 课后作业 | 12 题 | 概念与流程 5 + 方法与规范 4 + 实操与复盘 3，附参考要点 |

## 使用方法

1. 学完第 9、10 章 → 做 quiz 第 1–4 题（概念），答案见 answers.ipynb；
2. 学完第 11 章案例 → 做第 5–8 题（审查），对照案例里的验收标准；
3. 完成 lab 后 → 做第 9–10 题（实操：写断言、写 AI 使用声明）；
4. assignment.md 作为课后作业，第 10–12 题需要附运行输出与会话记录。

## 自检方式

每题代码单元末尾都有 assert 自检：把 TODO 补全后运行，看到「第 N 题通过」即完成。
答案版（answers.ipynb）已全部验证通过（10/10）。
