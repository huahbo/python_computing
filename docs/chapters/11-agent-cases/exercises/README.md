# 第 11 章 练习题（exercises/）

> 本页是**第二部分（第 9–12 章）练习的统一入口**。

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `quiz.ipynb` | 学生自测 | 10 题：概念 4 + 审查 4 + 实操 2 |
| `answers.ipynb` | 教学答案版 | 每题参考实现与判据说明 |
| `assignment.md` | 作业（12 题） | 含"写验收标准""写 AGENTS.md""审查 Agent 报告"等，附 AI 使用声明模板 |

## 使用方法

1. 学完第 9、10 章后做 quiz 的 1–4 题（概念）；
2. 学完第 11 章案例后做 5–8 题（审查）；
3. 完成 lab 后做 9–10 题（实操）；
4. `assignment.md` 作为课后作业，其中第 11–12 题要求提交项目复盘与 AI 使用声明。

## 评分建议

- quiz 10 题，建议占平时 10–15%；
- assignment 12 题，建议占 15–20%；
- lab（三段式）与 Project 3，建议合计占 30% 以上（含报告与声明）。
