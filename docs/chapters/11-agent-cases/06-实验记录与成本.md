# 06 实验记录与成本

> 本节的定位：把"花了多少时间、花了多少钱"变成可核对的数据。做完四个案例后，你会得到一张自己的实验记录表。

## 本节目标

1. 会用固定的实验记录表记录任务（耗时、token 量级、花费、结论）；
2. 会用价格表估算一次任务的花费，并知道怎么省钱；
3. 会把成本写进报告，形成"可信又可控"的 AI 使用习惯。

## 6.3 成本估算方法（三步）

1. **估 token**：输入 ≈ 提示词 + 读入文件 + 工具输出（通常几千到几万 token）；输出 ≈ 改动 + 说明（通常几百到几千）；
2. **套价格**：按官方定价页的"输入（缓存命中 / 未命中）+ 输出"分别计算，注意**空闲时段半价**；
3. **乘轮次**：多轮对话会把历史重复计入输入（缓存命中部分便宜很多）。

教材第 9 章 02 节 5.4 有可直接运行的估算脚本。

## 6.4 省钱的四个开关

| 开关 | 做法 | 效果 |
| ---- | ---- | ---- |
| 选模型 | 练习用 deepseek-flash，只在复杂推理时用 pro | 差 3–4 倍 |
| 挑时段 | 大任务放空闲时段（高峰为工作日 9–12、14–18） | 省一半 |
| 控上下文 | 给最小复现、让它自己读文件、及时 /compact | 少读少算 |
| 减轮次 | 一次把判据说清，避免反复返工 | 最有效的省钱方式 |

## 6.5 把成本写进报告

在报告的方法一节写清三件事：

1. 用了什么工具与模型（含版本与日期）；
2. 总共花了多少时间与费用（量级即可，如"约 0.05 元"）；
3. 哪些环节是人工完成的（对应 AI 使用声明）。

## 本节小结

1. 记录表让"效率"可比较、可复盘；
2. 一次中等任务通常只要几分钱，但**返工才是最贵的**；
3. 省钱四开关：选模型、挑时段、控上下文、减轮次；
4. 成本要写进报告，与 AI 使用声明相互印证。
