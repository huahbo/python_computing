方法只有在真实任务里才站得住。本章用四个递进案例把第 9、10 章的概念与方法跑一遍，全部复用第 1–8 章的知识作为**验收判据**：

## 学习目标

1. 能用最小复现定位"看起来都对的"静默数值错误；
2. 能把清洗策略写成可验收的判定（行数守恒、缺失与异常处理留痕）；
3. 会固定种子并做重跑一致性检查，报告里区分"显著"与"解释力强"；
4. 能用 Pipeline 与结构检查排除数据泄漏，并让评审代理逐条回应质疑；
5. 会用 `lab/` 的离线材料在没有 API Key 的环境里完成同样的审查训练。
