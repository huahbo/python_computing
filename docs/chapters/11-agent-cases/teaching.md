# 第 11 章 教学说明（教师用）

> 面向授课教师：课时建议、上机安排与评分建议。学生无需阅读本页。

## 1. 教学目标

1. 用最小复现定位静默数值错误；
2. 写出可执行的清洗判据；
3. 固定种子并做重跑一致性检查；
4. 用结构检查排除数据泄漏并完成评审闭环。

## 2. 建议课时

上机 4 学时（Part A 1h + Part B 2h + Part C 1h），可拆成两次课。

## 3. 重点与难点

- 任务卡与验收标准的写法；
- 数据泄漏的识别；
- 报告中"局限与不确定性"的表述。

## 4. 常见坑（课堂重点提醒）

- 学生直接让 Agent 改原始数据：强调"只新增、不覆盖"；
- 示例输出与本地不一致：说明示例依赖版本与模型；
- 断网或无 Key：切到 `lab/sample_agent_output/` 做离线审查。

## 5. 资源包

- 案例：01–04 节（05、06 节陆续交付）；
- 数据：`lab/data/`；
- 参考产物：`lab/sample_agent_output/`；
- 练习：`exercises/`。

## 6. 课堂演示脚本（2 学时 / 4 学时版）

| 时段 | 内容 | 现场只敲这几条 |
| ---- | ---- | ---- |
| 0–10 min | 用案例一开场：先展示错误输出，再展示验收断言 | `python data/scores_buggy.py` |
| 10–40 min | 演示任务卡六件套与提示词（第 10 章 02 节） | 现场写一段任务卡，交给 Agent |
| 40–60 min | 演示权限与审批：先 read-only 再放开 | `/permission` |
| 上机 1h | lab Part A（离线审查 + 写断言） | 打开 `lab/lab.ipynb` |
| 上机 2h | lab Part B 三个任务（分组，助教巡场） | 提示词模板 |
| 上机 1h | Part C 项目骨架 + 报告自检清单 | `C1` / `C2` 单元 |

## 7. 评分 rubric（建议）

| 维度 | 权重 | 达标表现 |
| ---- | ---- | ---- |
| 任务卡与判据 | 25% | 六件套齐全，判据可执行、能拦住错误实现 |
| 验证充分性 | 25% | 有断言、有重跑一致性、有泄漏/异常值检查 |
| 使用规范性 | 20% | 权限与数据红线、原始数据未改动、评审闭环 |
| 报告与记录 | 20% | 报告数字可追溯、含局限、附会话与实验记录 |
| 声明真实性 | 10% | AI 使用声明逐条具体，与记录一致 |

## 8. 断网 / 无 Key 兜底

- 全部概念题与审查题可离线完成；
- Part A 完全离线（数据与参考产物在 lab/ 内）；
- Part B 若无法联网：改用 `lab/sample_agent_output/` 的会话记录做「人工扮演 Agent」演练；
- 课堂演示若 API 不可用：播放预生成的会话记录（run_fix_session.txt）。
