# 9. AI Agent 编程：以 DeepSeek Harness 为例（新版讲义）

> 本页是第 9 章的**章首页（索引）**。正文位于 01 到 08 节；本章为**拓展章（选做）**，不占主线 8 周 48 学时。
> 基线版本：dsh 0.1.5-rc.2（npm latest，2026-09-10 发布）；教材核对日期 2026-09-19。详见 dsh_version.yaml。

## 本章概览

前八章教会你用 NumPy、SciPy、Pandas、Matplotlib、NetworkX、Statsmodels、scikit-learn 做科学计算；本章回答一个新问题：**当 AI 能自己读文件、跑命令、改代码、看报错时，科学计算的工作方式会变成什么样？**

本章以 DeepSeek Harness（dsh）为例——一个"一切皆插件"的开源 agent harness。你会看到它怎么把模型、工具、上下文、权限、会话组装成一个循环，也会反复练习本课程真正看重的能力：**给 AI 定验收标准，并亲自验证它的产出。**

## 学习目标

学完本章，你应该能够：

1. 说清代码补全、对话式编程与 Agent 编程的区别，描述一次 Agent 循环的五个动作。
2. 用三件套（模型 + 上下文 + 权限）判断一个 Agent 任务的风险与成本。
3. 独立完成 dsh 的安装（Web 版 / CLI 版），并配置模型 API Key。
4. 用 dsh 完成四类递进任务：解释与修复代码、清洗与可视化数据、做可复现实验、跑端到端小项目。
5. 为一个任务写出**可执行的验收标准**，并用脚本验证 Agent 的产出。
6. 说出 Agent 编程的四类典型失败模式与对应的防错手段。
7. 按科研规范记录 AI 使用过程，写出合规的 AI 使用声明。

## 先修要求与运行环境

- 先修：第 0 章（终端、Python 环境、LaTeX）与第 1 到 8 章任一（案例会复用 NumPy、Pandas、SciPy、Statsmodels、sklearn 的知识）。
- 运行环境：
  - Node.js ^22.19.0 或 >= 24.0.0（安装与自查见 02 节）；
  - 一个 DeepSeek 开放平台账号与 API Key（申请与付费见 02 节第 5 小节）；
  - Python 环境沿用第 0 章的 scicomp 环境（案例中的验证脚本需要 numpy / pandas / scipy / statsmodels / scikit-learn / matplotlib）。
- 网络：安装与联网任务需要网络；**所有练习都提供离线替代路径**，断网时也能完成核心训练。

## 版本与时效

本章内容与 dsh 的版本强相关，因此做了三层防护：

1. 版本单一事实源：dsh_version.yaml（基线版本、核对日期、上游链接、需复核文件清单）；
2. 时效标记：正文中所有易变段落以"⏱ 时效内容（基线 vX / 日期）"开头，便于批量复核；
3. 双周巡检：build/check_dsh_release.py 与 .github/workflows/dsh-release-watch.yml 会在官方发新版时提醒，流程见 build/dsh_更新SOP.md。
