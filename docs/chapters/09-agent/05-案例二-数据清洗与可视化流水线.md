# 05 案例二：数据清洗与可视化流水线

> 案例定位：L3（多文件任务：清洗脚本 + 图表 + 结果表）。
> 复用第 4 章（缺失值、重复值、分组统计）与第 5 章（图表规范、随机种子）。

## 案例背景

`lab/data/scores_dirty.csv` 是一份"真实世界风格"的成绩表：11 行、6 列，里面混着几类常见脏数据：

| 问题 | 位置 | 数量 |
| ---- | ---- | ---- |
| 学号重复 | 张三出现两次 | 1 行 |
| 学号/姓名有空白 | 2024009 尾部空格、王五姓名两侧空格 | 2 处 |
| 成绩缺失 | 李四的期中、期末为空 | 2 个 |
| 异常值 | 孙八期末 = 999 | 1 个 |
| 班级缺失 | 周九班级为空 | 1 个 |

任务：让 Agent 产出**可复现的清洗流水线**，并给出图表与结果表。这个案例的重点不是"洗得干净"，而是**每一步都能被验收**。

## 任务卡（六件套）

| 要素 | 内容 |
| ---- | ---- |
| 目标 | 产出 `clean_scores.py`：读原始数据 → 清洗 → 输出干净数据、图表与清洗报告 |
| 约束 | 不覆盖 `data/scores_dirty.csv`；输出统一放 `output/`；随机种子固定 |
| 验收标准 | ① 行数守恒：清洗后行数 = 原始行数 − 删除的重复行数（= 10）；② 缺失与异常处理策略写进报告；③ 图有标题/坐标轴单位，保存为 PNG |
| 证据 | 脚本运行输出 + `output/` 文件清单 + 清洗报告 |
| 复核 | 异常值是被"修正"还是被"标记"？缺失值是删除还是填充？理由是否记录？ |
| 提交 | 脚本 + 输出文件 + 报告 + 会话记录 |

## 给 Agent 的提示词（原文）

```text
请为 data/scores_dirty.csv 写一个可复现的清洗脚本 clean_scores.py，要求：
1) 学号与姓名去首尾空格；班级缺失填"未知"；
2) 重复学号只保留第一条（并在报告里说明删了几行）；
3) 期末成绩大于 100 视为异常，标记为缺失（不要凭空改成 100 或平均值）；
4) 输出 output/scores_clean.csv、output/clean_report.md（写明每类问题的数量与处理策略）；
5) 画一张图 output/score_box.png：三个科目成绩的箱线图，中文标签，标题含"成绩分布"，保存 150 dpi；
6) 脚本末尾用 assert 自检：行数守恒、姓名无空白、班级无缺失。
不要修改 data/ 下的原始文件；写完后运行并把输出贴给我。
```

## 验收标准（可执行，已运行核验）

下面这段把"脏数据 → 清洗 → 判据"浓缩成 20 行，任何机器都能跑：

```python
import numpy as np
import pandas as pd

raw = pd.DataFrame({
    "学号": ["2024001", "2024002", "2024003 ", "2024004", "2024001"],
    "姓名": ["张三", "李四", "  王五 ", "赵六", "张三"],
    "班级": ["一班", "一班", "一班", None, "一班"],
    "平时": [82, 60, 95, 70, 82],
    "期中": [90, np.nan, 88, 72, 90],
    "期末": [78, np.nan, 92, 999.0, 78],
})

before = len(raw)
clean = raw.copy()
clean["学号"] = clean["学号"].str.strip()
clean["姓名"] = clean["姓名"].str.strip()
clean["班级"] = clean["班级"].fillna("未知")
clean["期末"] = clean["期末"].mask(clean["期末"] > 100)
clean = clean.drop_duplicates(subset=["学号"]).reset_index(drop=True)
removed = before - len(clean)

print("原始行数:", before, "清洗后行数:", len(clean), "删除重复行:", removed)
print("行数守恒:", removed == 1)
print("期末缺失数(含异常值置缺):", int(clean["期末"].isna().sum()))
print("姓名是否还有空白:", bool((clean["姓名"] != clean["姓名"].str.strip()).any()))
print("班级取值:", sorted(clean["班级"].unique().tolist()))
```

```text
原始行数: 5 清洗后行数: 4 删除重复行: 1
行数守恒: True
期末缺失数(含异常值置缺): 2
姓名是否还有空白: False
班级取值: ['一班', '未知']
```

## 图表复核点（第 5 章标准的 Agent 版）

1. 中文是否正常显示（字体设置），有没有方框乱码；
2. 标题、x/y 轴标签、单位是否齐全；
3. 箱线图是否说明了异常点处理方式（999 被置缺后不应再出现）；
4. 图片是否保存为文件（而不是只 `plt.show()`）；
5. 随机过程是否固定种子（本案例无随机，但报告里应体现"可复现"意识）。

## 常见坑

| 坑 | 后果 | 避免方式 |
| ---- | ---- | ---- |
| 让 Agent"把异常值改成合理值" | 999 被悄悄改成 100，数据被篡改 | 要求"标记为缺失"并写进报告 |
| 没有行数守恒判据 | 到底删了几行说不清 | 断言：清洗前行数 − 清洗后行数 == 删除的重复行数 |
| 图只 show 不 save | 提交时没有图片文件 | 验收标准里写明输出路径与 dpi |
| 报告与脚本不一致 | 报告说"填充均值"，脚本其实删了行 | 报告由脚本自动生成，不手写 |
