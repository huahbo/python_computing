> 案例定位：L4（项目级：脚本 + 统计结论 + 自动验证 + 局限说明）。
> 复用第 3 章（SciPy 检验）与第 7 章（Statsmodels 回归、时间序列）。

## 案例背景

`lab/data/sensor.csv` 是一段 240 小时的传感器记录（列：`t` 小时、`温度` 摄氏度、`振动` 无量纲）。任务假设：**温度随时间存在线性上升趋势**。

这个案例训练的不是"跑出 p 值"，而是：**固定种子、可重跑、结论有区间、局限写清楚**。

## 任务卡（六件套）

| 要素 | 内容 |
| ---- | ---- |
| 目标 | 产出 `experiment.py` + `output/fit_summary.txt` + `output/trend.png` + `report.md` |
| 约束 | 不做数据变换前先画图；种子固定 20240919；不修改 `data/sensor.csv` |
| 验收标准 | ① 重跑两次结果完全一致；② 报告给出斜率、p 值、置信区间与 R²；③ 措辞区分"相关"与"因果"；④ 报告含"局限与不确定性"一节 |
| 证据 | 两次运行的输出对比 + 图 + 报告 |
| 复核 | p 值的含义是否说对；趋势是否被季节性掩盖；结论是否超出数据支持范围 |
| 提交 | 脚本 + 输出 + 报告 + 会话记录 |

## 给 Agent 的提示词（原文）

```text
请用 data/sensor.csv 做一次可复现的统计实验 experiment.py：
1) 先画温度随时间的折线图（保存 output/trend.png，标注单位与标题）；
2) 用 OLS 拟合"温度 ~ t"，输出斜率（每小时升温）、p 值、95% 置信区间、R²；
3) 结果写入 output/fit_summary.txt；
4) 用固定种子生成同一份合成数据做一次自检，证明"同样输入 → 同样输出"（重跑一致）；
5) 写 report.md：结论 + 证据 + 局限与不确定性（例如季节性、采样频率、未测变量）。
注意：不要用"导致""证明"这类因果措辞；脚本末尾用 assert 检查重跑一致性与显著性的判断逻辑。
```

## 验收标准（可执行，已运行核验）

这段代码用与 `sensor.csv` 相同的生成方式（同一种子）做数据，因此**它同时验证了"可复现"这件事本身**：

```python
import numpy as np
import statsmodels.api as sm

def gen(seed):
    rng = np.random.default_rng(seed)
    t = np.arange(240)
    y = 20 + 0.02 * t + 3 * np.sin(2 * np.pi * t / 24) + rng.normal(0, 0.5, t.size)
    return t, y

t1, y1 = gen(20240919)
m1 = sm.OLS(y1, sm.add_constant(t1)).fit()
t2, y2 = gen(20240919)
m2 = sm.OLS(y2, sm.add_constant(t2)).fit()

print("斜率(每小时):", round(float(m1.params[1]), 6))
print("p 值:", float(m1.pvalues[1]))
print("重跑一致:", bool(np.allclose(m1.params, m2.params)))
print("显著(alpha=0.05):", bool(m1.pvalues[1] < 0.05))
```

```text
斜率(每小时): 0.018037
p 值: 1.469930277503604e-16
重跑一致: True
显著(alpha=0.05): True
```

> 用 `lab/data/sensor.csv`（同样数据、只保留 3 位小数）得到的结果一致：斜率 0.018037、p ≈ 1.47e-16、R² ≈ 0.25。
> 注意 R²：温度只有约 25% 的波动由线性趋势解释——**显著不等于解释力强**，这正是报告里要写的"局限"。

## 人工复核点

1. **种子的作用范围**：固定种子只保证随机数一致，不保证结论正确；
2. **p 值的读法**：p 小说明"在零假设下出现这种数据的概率低"，不等于"效应大"；
3. **季节性**：24 小时周期很强，只拟合线性趋势会低估波动，报告要说明；
4. **措辞**：允许写"与……一致/相关"，不允许写"证明了/导致了"；
5. **可复现三件套**：脚本、数据、环境（版本号）都在提交物里。

## 常见坑

| 坑 | 后果 | 避免方式 |
| ---- | ---- | ---- |
| 不固定种子 | 别人重跑得到不同数字 | 断言"两次重跑一致" |
| 只报 p 值不报效应量 | 结论被夸大 | 同时给斜率、置信区间、R² |
| 忽略季节性直接下结论 | 把周期当趋势 | 先画图再建模 |
| 用"证明"下因果结论 | 学术表达不严谨 | 报告模板里固定"局限"一节 |
