## 2.1 函数的零点与方程的解

### 2.1.1 `fsolve`：求单个方程/方程组的根

求 $x^2-612=0$ 的正根。`fsolve` 用最小二乘（典型 Levenberg-Marquardt）从初值出发迭代。

```python
from scipy.optimize import fsolve

def func(x):
    return x**2 - 612

print(fsolve(func, 10.0))
```

```text
[24.73863375]
```

注意：`$\sqrt{612}\approx24.7386$`；若从 `-10` 出发会得到负根。`fsolve` 的结果依赖初值，且可能只找到最接近初值的一个根。

### 2.1.2 `root`：更多算法与方程组

求方程组 $\begin{cases}x^2+y^2-4=0\\ x-y-1=0\end{cases}$。

```python
from scipy.optimize import root
import numpy as np

def func(v):
    x, y = v
    return [x**2 + y**2 - 4, x - y - 1]

sol = root(func, [0, 0])
print(sol.x, sol.success, sol.message)
```

```text
[-0.82287566 -1.82287566] True The solution converged.
```

`root` 返回 `OptimizeResult`：`x` 为解，`success` 是否成功，`message` 终止信息，也可用 `method` 选择 `hybr`/`lm`/`krylov` 等。

### 2.1.3 一维求根 `brentq`

`brentq` 需要提供包含根的区间 $[a,b]$，要求 $f(a)$ 与 $f(b)$ 异号。求 $x^2-2=0$ 的根（$\sqrt2$）。

```python
from scipy.optimize import brentq
print(brentq(lambda x: x**2 - 2, 1, 2))
```

```text
1.4142135623731364
```

> 注意：`brent`（无 q）求的是**最小值**，`brentq`（带 q）求**根**，二者用途不同，切勿混淆。

## 2.2 函数的极值优化

### 2.2.1 一维无约束：`brent`

求 $f(x)=(x-1)^2$ 的最小值点。

```python
from scipy.optimize import brent
print(brent(lambda x: (x-1)**2, brack=(0, 2)))
```

```text
0.9999999999999998
```

`brack` 是包含极小值的三点/两点区间。可设 `full_output=True` 获得函数值、迭代次数等。

### 2.2.2 多维无约束：`fmin`（Nelder-Mead）

求 $f(x)=ax^2+bx+c$，令 $a=1,b=3,c=2$。

```python
from scipy.optimize import fmin
import numpy as np

def quadratic(x, a, b, c):
    return a * x**2 + b * x + c

res = fmin(quadratic, np.array([1.0]), args=(1, 3, 2), full_output=True, disp=False)
print("x =", res[0], "  fmin =", res[1], "  iter =", res[2], "  nfev =", res[3])
```

```text
x = [-1.5]   fmin = -0.25000000000000044   iter = 19   nfev = 38
```

理论最小点 $x=-b/(2a)=-1.5$，$f_{\min}=c-b^2/(4a)=2-9/4=-0.25$。

### 2.2.3 通用接口 `minimize`

`minimize` 是更强大、更推荐的多维优化接口，可自动/手动选择算法。

**无约束**（Nelder-Mead）：

```python
from scipy.optimize import minimize

def obj(x):
    return (x[0]-1)**2 + (x[1]-2)**2

res = minimize(obj, [0, 0], method="Nelder-Mead")
print(res.x, res.fun, res.success)
```

```text
[0.99997307 2.00003382] 1.869184419935774e-09 True
```

**带约束**（SLSQP）：最小化 $x_1^2+x_2^2$，约束 $x_1+x_2\ge1$，$x_1,x_2\ge0$。

```python
cons = [{"type": "ineq", "fun": lambda x: x[0] + x[1] - 1}]
res = minimize(lambda x: x[0]**2 + x[1]**2, [0, 0], method="SLSQP",
               constraints=cons, bounds=[(0, None), (0, None)])
print(res.x, res.fun, res.success)
```

```text
[0.5 0.5] 0.5000000000000002 True
```

约束写成 `fun(x) >= 0` 形式；`bounds` 定义各变量取值范围。

### 2.2.4 线性规划 `linprog`

最小化 $c^T x$，受 $A_{ub}x\le b_{ub}$、$A_{eq}x=b_{eq}$、$x\ge0$ 约束。

```python
import numpy as np
from scipy.optimize import linprog

c = [-29, -45, 0, 0]
A_ub = [[1, -1, -3, 0], [-2, 3, 7, -3]]
b_ub = [5, -10]
A_eq = [[2, 8, 1, 0], [4, 4, 0, 1]]
b_eq = [60, 60]
bounds = [(0, None)] * 4

res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=bounds)
print(np.round(res.x, 2), round(res.fun, 2), res.success)
```

```text
[9.2 5.2 0.  2.4] -500.8 True
```

### 2.2.5 指派问题 `linear_sum_assignment`

给定成本矩阵，求“一人一任务”的最小总成本分配（匈牙利算法）。

```python
import numpy as np
from scipy.optimize import linear_sum_assignment
cost = [[4, 1, 3], [2, 0, 5], [3, 2, 2]]
row_ind, col_ind = linear_sum_assignment(cost)
print("rows =", row_ind, "  cols =", col_ind)
print("min cost =", np.array(cost)[row_ind, col_ind].sum())
```

```text
rows = [0 1 2]   cols = [1 0 2]
min cost = 5
```

即工人 A→任务2、B→任务1、C→任务3，总成本 1+2+2=5。

## 2.3 曲线拟合（最小二乘）

### 2.3.1 `leastsq`

手动给误差向量，最小化 $\sum r_i^2$。

```python
import numpy as np
from scipy.optimize import leastsq

def model(x, a, b, c):
    return a*x**2 + b*x + c

def residuals(p, x, y):
    a, b, c = p
    return y - model(x, a, b, c)

rng = np.random.default_rng(7)
x = np.linspace(-10, 10, 50)
y = model(x, 2, 3, 1) + rng.normal(0, 2, len(x))

params, flag = leastsq(residuals, [0, 0, 0], args=(x, y))
print(np.round(params, 4))
```

```text
[ 2.0191  3.0387 -0.2494]
```

### 2.3.2 更友好的 `curve_fit`

`curve_fit(model, xdata, ydata, p0=...)` 自动构造残差，返回 `(popt, pcov)`。

```python
import numpy as np
from scipy.optimize import curve_fit
popt, pcov = curve_fit(model, x, y, p0=[0, 0, 0])
perr = np.sqrt(np.diag(pcov))
print("popt =", np.round(popt, 4))
print("stderr =", np.round(perr, 4))
```

```text
popt = [ 2.0191  3.0387 -0.2494]
stderr = [0.0078 0.0409 0.3616]
```

真实参数为 $(2,3,1)$，拟合值在其附近；`pcov` 对角线开方可作参数标准误的近似。

## 常见误区

| # | 误区 | 正确做法 |
| ---- | ---- | ---- |
| 1 | 用 `brent` 求根 | 求根用 `brentq`/`fsolve`/`root` |
| 2 | `fsolve` 不设初值 / 期望得到全部根 | 一维用 `brentq` 且给出异号区间；多根问题改变初值或多个区间 |
| 3 | `fmin` 的 `full_output` 返回顺序误读 | 返回 `(xopt, fopt, iter, funcalls, ...)`，`iter`/`funcalls` 是整数 |
| 4 | `linprog` 目标默认最小化，忘了 `c` 取负号 | 若原问题是最大化，把 `c` 取负转成最小化 |
| 5 | `linear_sum_assignment` 直接返回成本矩阵 | 返回 `row_ind, col_ind`，需用 `cost[row_ind, col_ind].sum()` 得成本 |
| 6 | `minimize` 约束符号写反 | `ineq` 表示 `fun(x) >= 0`；等号约束用 `eq` |
| 7 | 不设 `p0` 就 `curve_fit` | 初值不良会导致不收敛或收敛到错误参数，应给接近真实值的 `p0` |
