## 1.1 为什么需要数值积分

很多函数的原函数无法写成初等函数（例如 $e^{-x^2}$、$\sin(x^2)$），或者我们只有离散的实验采样点。此时只能用数值方法求定积分。

### 1.1.1 梯形法：从手工到库函数

把 $[a,b]$ 等分成 $n$ 段，每段用梯形近似曲线下面积：

$$\int_a^b f(x)\,dx \approx \sum_{i=0}^{n-1}\frac{f(x_i)+f(x_{i+1})}{2}\cdot h,\quad h=\frac{b-a}{n}$$

下面用 Python 实现 $\int_0^1 x^2 dx$，理论值 $\frac{1}{3}$。

```python
def trapezoidal_rule(f, a, b, n):
    h = (b - a) / n
    s = 0.5 * (f(a) + f(b))
    for i in range(1, n):
        s += f(a + i * h)
    return s * h

def f(x):
    return x**2

for n in (10, 100, 1000):
    print(f"n={n:5d}  approx={trapezoidal_rule(f, 0, 1, n):.10f}")
print("theoretical = 1/3 =", 1/3)
```

```text
n=   10  approx=0.3350000000
n=  100  approx=0.3333500000
n= 1000  approx=0.3333335000
theoretical = 1/3 = 0.3333333333333333
```

可见 $n$ 越大，结果越接近 $\frac{1}{3}$。

### 1.1.2 用 `quad` 求一维定积分

`quad(func, a, b, args=...)` 返回二元组 `(积分值, 误差估计)`。它使用自适应算法，精度远高于固定步长的梯形法。

```python
import numpy as np
from scipy.integrate import quad
print(quad(lambda x: x**2, 0, 1))
print(quad(lambda x: np.exp(-x**2), -np.inf, np.inf))
```

```text
(0.33333333333333337, 3.700743415417189e-15)
(1.7724538509055159, 1.2386316961910534e-10)
```

第二个例子是高斯积分 $\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}\approx1.77245$，`quad` 也擅长处理无穷积分。

### 1.1.3 二重积分 `dblquad`

计算 $\int_0^1\int_0^x x y\, dy\, dx$。注意内层积分上下限函数以积分变量为自变量。

```python
from scipy.integrate import dblquad

def f(y, x):
    return x * y

result, err = dblquad(f, 0, 1, lambda x: 0, lambda x: x)
print(result, err)
```

```text
0.125 5.515032205777789e-15
```

> 理论值 $\frac{1}{8}$；若积分变量更多，可用 `tplquad`（三重）或 `nquad`（任意维）。

### 1.1.4 对离散数据积分 `trapezoid`

实验数据只有采样点 $(x_i,y_i)$，没有函数表达式，用 `trapezoid(y, x)`。注意：在 SciPy 1.15 中函数名为 `trapezoid`（老版本叫 `trapz`）。

```python
from scipy.integrate import trapezoid
import numpy as np

x = np.linspace(0, 1, 100)
y = x**2
print(trapezoid(y, x))
```

```text
0.33335033840084355
```

## 1.2 常微分方程数值解

大多数微分方程没有解析解，`scipy.integrate` 给出“列表法”近似解：针对自变量数组中的每个取值，给出高频精度的因变量值。

### 1.2.1 一阶 ODE：`odeint`

求 $\frac{dy}{dt}=\sin(t^2)$，$y(0)=1$。

```python
import numpy as np
from scipy.integrate import odeint

def dy_dt(y, t):
    return np.sin(t**2)

y0 = [1]
t = np.arange(0, 10, 0.1)
y = odeint(dy_dt, y0, t)
print("len =", len(y), "   y(0)=", y[0,0], "   y(9.9)=", y[-1,0])
```

```text
len = 100   y(0)= 1.0   y(9.9)= 1.6678897279551907
```

`odeint` 默认 `func(y, t, *args)` 参数顺序（y 在前、t 在后），基于 LSODA 可自动处理刚性问题。

### 1.2.2 二阶 ODE 转一阶方程组

求 $y''+y=0$，$y(0)=1,\ y'(0)=0$。令 $y_1=y,\ y_2=y'$，则 $y_1'=y_2,\ y_2'=-y_1$。

```python
def second_order(y, t):
    y1, y2 = y
    return [y2, -y1]

y = odeint(second_order, [1, 0], t)
print("y(9.9) =", y[-1,0], "  y'(9.9) =", y[-1,1])
```

```text
y(9.9) = -0.8891913778545403   y'(9.9) = 0.45753579354898755
```

> 该方程解析解为 $y=\cos t$，$\cos(9.9)\approx -0.8892$，$y'(9.9)=-\sin(9.9)\approx 0.4575$，数值解一致。

### 1.2.3 高阶 ODE：三阶方程

对 $y'''+y''+y'+y=0$，令 $y_1=y,\ y_2=y',\ y_3=y''$，化为三个一阶方程：$y_1'=y_2,\ y_2'=y_3,\ y_3'=-y_1-y_2-y_3$。

```python
def third_order(y, t):
    y1, y2, y3 = y
    return [y2, y3, -y1 - y2 - y3]

y = odeint(third_order, [1, 0, 0], t)
print("y(9.9) =", y[-1,0], "  y'(9.9) =", y[-1,1], "  y''(9.9) =", y[-1,2])
```

```text
y(9.9) = -0.67333854   y'(9.9) = -0.21585283   y''(9.9) = 0.67338872
```

### 1.2.4 更新更灵活的 `solve_ivp`

`solve_ivp` 是较新且更灵活的接口，支持 `t_eval`、事件检测、更多求解器。注意它的导数函数签名是 `fun(t, y)`（t 在前）。

```python
from scipy.integrate import solve_ivp

def deriv(t, y):
    return -2 * y

sol = solve_ivp(deriv, (0, 5), [1], t_eval=np.linspace(0, 5, 100))
print("y(5) =", sol.y[0, -1])
print("n_points =", len(sol.t))
```

```text
y(5) = 4.572378941563548e-05
n_points = 100
```

解析解 $y=e^{-2t}$，$e^{-10}\approx4.54\times10^{-5}$，数值解一致。

### 1.2.5 边值问题 `solve_bvp`

边值问题（BVP）给定区间两端条件，且需要初始猜测。以下求 $y''=6x$，边界 $y(0)=0,\ y(1)=1$（解析解 $y=x^3$）。

```python
from scipy.integrate import solve_bvp

def fun(x, y):
    return np.vstack((y[1], 6*x))

def bc(ya, yb):
    return np.array([ya[0], yb[0]-1])

x = np.linspace(0, 1, 20)
y = np.zeros((2, x.size))
sol = solve_bvp(fun, bc, x, y)
print("sol.x.size =", sol.x.size, "   y_mid =", round(sol.y[0,10], 6))
print("truth x^3  =", round(x[10]**3, 6))
```

```text
sol.x.size = 20   y_mid = 0.145794
truth x^3  = 0.145794
```

## 常见误区

1. **`trapz` 在新版 SciPy 已改名**：用 `trapezoid`；老教程的 `from scipy.integrate import trapz` 在 1.15 会报 `ImportError`。
2. **`odeint` 导数函数参数顺序是 `(y, t)`**，而 `solve_ivp` 是 `(t, y)`，二者顺序相反，容易写错。
3. **`solve_ivp` 用 `t_span=(t0,tf)`，不是 `t0,tf` 分开传**；想要稀疏输出用 `t_eval`。
4. **把 `quad` 返回元组当成单个值**：要取 `quad(...)[0]` 或解包 `(value, err)`。
5. **高阶 ODE 忘记降阶**：必须把 $y''$（或更高阶）化成两个/多个一阶方程组成的方程组。
6. **`odeint` 时间序列必须单调**：`t` 数组要递增或递减，且首项对应初始时间。
