## 4.1 正态性检验

许多检验（t 检验、ANOVA）都假设数据近似正态。`scipy.stats` 提供 Shapiro-Wilk 与 Anderson-Darling 检验。

### 4.1.1 Shapiro-Wilk 检验

适合小样本（$n<50$ 特别有效）。零假设 $H_0$：样本来自正态分布；p 值很小则拒绝 $H_0$。

```python
import numpy as np
from scipy.stats import shapiro

rng = np.random.default_rng(1)
data = rng.normal(0, 1, size=100)
stat, p = shapiro(data)
print(f"W={stat:.4f}, p={p:.4f}")
if p < 0.05:
    print("拒绝 H0：不认为来自正态分布")
else:
    print("不能拒绝 H0：可用正态近似")
```

```text
W=0.9802, p=0.1374
不能拒绝 H0：可用正态近似
```

### 4.1.2 Anderson-Darling 检验

适合较大样本。它不直接给 p 值，而是给出统计量与不同显著性水平下的临界值；统计量大于某临界值则在该水平下拒绝 $H_0$。

```python
from scipy.stats import anderson
res = anderson(data, dist="norm")
print(f"stat={res.statistic:.4f}")
print("levels =", res.significance_level)
print("critical=", np.round(res.critical_values, 3))
```

```text
stat=0.6713
levels = [15.  10.   5.   2.5  1. ]
critical= [0.555 0.632 0.759 0.885 1.053]
```

统计量 0.6713 大于 10% 临界值 0.632、但小于 5% 临界值 0.759，因此，在 5% 水平下**不能拒绝**正态性假设。

## 4.2 常见假设检验

### 4.2.1 卡方独立性检验 `chi2_contingency`

检验两个分类变量是否独立。对 $2\times2$ 列联表：

```python
from scipy.stats import chi2_contingency
observed = np.array([[10, 20], [30, 40]])
chi2, p, dof, expected = chi2_contingency(observed)
print(f"chi2={chi2:.4f}, p={p:.4f}, dof={dof}")
```

```text
chi2=0.4464, p=0.5040, dof=1
```

p 值 0.504 > 0.05，无充分证据说明两个分类变量不独立。

### 4.2.2 独立样本 t 检验 `ttest_ind`

比较两批不同样本（如高一与高三学生成绩）的均值是否不同。

```python
from scipy.stats import ttest_ind
s1 = rng.normal(0, 1, size=100)       # 组1
s2 = rng.normal(0.5, 1, size=100)     # 组2，均值略高
t_stat, p_val = ttest_ind(s1, s2)
print(f"t={t_stat:.4f}, p={p_val:.6f}")
```

```text
t=-3.0457, p=0.002637
```

p < 0.05，拒绝“两样本均值相等”，认为组2均值显著高于组1（t 为负表示组1均值更低）。

### 4.2.3 配对样本 t 检验 `ttest_rel`

比较同一批对象在处理前后（如用药前后）的差异。

```python
from scipy.stats import ttest_rel
before = rng.normal(0, 1, size=100)
after = before + rng.normal(0.3, 1, size=100)   # 同一批人，均提升 0.3
t_stat, p_val = ttest_rel(before, after)
print(f"t={t_stat:.4f}, p={p_val:.8f}")
```

```text
t=-4.9659, p=0.00000286
```

p 极小，说明“前后差异”在统计上显著。

### 4.2.4 单因素方差分析 `f_oneway`

比较两个及以上组的均值。

```python
from scipy.stats import f_oneway
g1 = rng.normal(0, 1, size=100)
g2 = rng.normal(0.5, 1, size=100)
g3 = rng.normal(1, 1, size=100)
F, p = f_oneway(g1, g2, g3)
print(f"F={F:.4f}, p={p:.8f}")
```

```text
F=16.7790, p=0.00000012
```

p 很小，说明至少两组均值不同；但 ANOVA 只告诉你“有差异”，不告诉你**哪两组**不同，需要事后多重比较。

### 4.2.5 事后多重比较：statsmodels Tukey HSD

```python
import numpy as np
import statsmodels.api as sm
from statsmodels.stats.multicomp import pairwise_tukeyhsd

data = np.concatenate([g1, g2, g3])
groups = np.array(["A"]*100 + ["B"]*100 + ["C"]*100)
tukey = pairwise_tukeyhsd(data, groups, alpha=0.05)
print(tukey)
print("statsmodels", sm.__version__)
```

```text
Multiple Comparison of Means - Tukey HSD, FWER=0.05
===================================================
group1 group2 meandiff p-adj  lower  upper  reject
--------------------------------------------------
     A      B   0.4926 0.0045 0.1287 0.8566   True
     A      C   0.8935    0.0 0.5295 1.2574   True
     B      C   0.4008 0.0268 0.0369 0.7648   True
--------------------------------------------------
statsmodels 0.14.6
```

可见三组之间两两差异都显著（A–B p=0.0045，A–C p≈0，B–C p=0.0268），说明组内噪声相较于组间差异较小。这比 ANOVA 的“整体显著”更细致。

## 常见误区

| # | 误区 | 正确做法 |
| ---- | ---- | ---- |
| 1 | p<0.05 就说“差异很大/很重要” | p 只说明“在随机波动下不常见”，实际大小看效应量或置信区间 |
| 2 | 不做正态性检验就强行 t 检验 | 大样本可用中心极限定理近似；小样本先 `shapiro` 检验 |
| 3 | 把 `ttest_ind` 用于配对数据 | 同一批对象前后比较用 `ttest_rel` |
| 4 | ANOVA 显著后不做两两比较 | 用 Tukey HSD 找出具体差异组 |
| 5 | 把“不能拒绝 $H_0$”当成“$H_0$ 成立” | 只能说“证据不足以拒绝”，尤其在样本量小时 |
| 6 | 忘记设定随机种子 | 统计模拟要可复现，用 `default_rng(seed)` |
