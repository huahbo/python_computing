# 07 常见误区与技巧

> 本章为新增“查漏补缺”页：把学生在 SciPy 上最容易踩的坑集中列出，并给出正确写法、性能与调试建议。

## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | `from scipy.integrate import trapz` | 用 `trapezoid` | SciPy 1.15 已移除 `trapz` |
| 2 | `odeint` 写 `func(t, y)` | 写成 `func(y, t)` | `odeint` 的签名是 `(y, t)`，`solve_ivp` 才是 `(t, y)` |
| 3 | `solve_ivp(f, 0, 5, y0)` | `solve_ivp(f, (0,5), y0)` | `t_span` 是二元组 |
| 4 | `quad(f,0,1)` 然后当数组用 | `value, err = quad(...)` | `quad` 返回 `(value, error)` 元组 |
| 5 | 用 `brent` 求根 | 求根用 `brentq`/`fsolve`/`root` | `brent` 求极小值，`brentq` 求根 |
| 6 | `linprog(c)` 直接当最大化用 | 最大化时 `c` 取负 | `linprog` 默认最小化 |
| 7 | `linear_sum_assignment` 后直接 `cost.sum()` | `cost[row_ind, col_ind].sum()` | 返回索引配对，需用索引取成本 |
| 8 | `minimize` 约束写成 `fun(x) <= 0` | `ineq` 表示 `fun(x) >= 0` | 约束符号方向易反 |
| 9 | 不给 `p0` 就 `curve_fit` | 给接近真实值的初值 | 非线性最小二乘对初值敏感 |
| 10 | 用 `interp2d` 做新代码 | 用 `RegularGridInterpolator`/`griddata` | `interp2d` 已废弃 |
| 11 | 对噪声数据做样条插值 | 改为 `curve_fit`/`np.polyfit` | 插值会“穿过噪声” |
| 12 | `griddata` 在凸包外直接外推 | 自行判断并处理 `nan` | `griddata` 不默认外推 |
| 13 | `butter(Wn=cutoff)` | `Wn = cutoff / (fs/2)` | `Wn` 是归一化频率 |
| 14 | 把 `fft` 幅值当真实幅度 | 单边需乘 $2/N$；或用 `rfft` 后归一化 | `fft` 未除以 $N$ |
| 15 | 统计 p<0.05 就说“差异很大” | 同时看效应量/置信区间 | p 值不度量重要性 |
| 16 | 不做正态性检验就小样本 t 检验 | 小样本先 `shapiro` | t 检验假设近似正态 |
| 17 | ANOVA 显著后不做事后比较 | 用 `pairwise_tukeyhsd` | 需找具体差异组 |
| 18 | 随机模拟不设种子 | `rng = np.random.default_rng(seed)` | 便于复现与讨论 |

## 2. 原理级难点：版本迁移与新接口

> SciPy 迭代较快，老教材中的某些函数已改名或废弃。写新代码时以官方最新文档为准。

| 老写法 | 新写法 | 说明 |
| ---- | ---- | ---- |
| `scipy.integrate.trapz` | `scipy.integrate.trapezoid` | 同名函数改名 |
| `scipy.integrate.odeint`（仍可用） | 推荐 `solve_ivp` | 新接口更灵活，支持事件/设置 |
| `scipy.optimize.leastsq`（仍可用） | 推荐 `curve_fit` | 接口更友好，返回协方差 |
| `scipy.optimize.fmin`（仍可用） | `minimize(method='Nelder-Mead')` | 统一入口 |
| `scipy.interpolate.interp2d` | `RegularGridInterpolator` | `interp2d` 已废弃 |
| `scipy.fftpack` | `scipy.fft` | 新模块，接口更好 |

## 3. 性能技巧

- **向量化优先**：能用 NumPy 数组一次算完就不要 Python 循环；
- **FFT 用 `rfft`**：实数信号只用一半复数，速度与内存都省一半；
- **插值选方法**：线性插值最快，三次样条更光滑但更慢；大数据散点可先 `cKDTree` 再 `griddata`；
- **`curve_fit` 给 `maxfev`**：复杂模型设 `maxfev=50000` 避免“达到最大调用次数”而失败；
- **积分用 `quad` 而非固定步长**：自适应能在光滑区间少算、在陡峭区间加密；
- **优化设 `bounds`/`constraints`**：有约束问题别用无约束方法，容易跑出物理合理区间；
- **多进程并行**：`scipy.optimize.differential_evolution` 等全局方法天然可并行，用 `workers` 参数。

## 4. 调试建议

1. **打印形状/版本**：`print(x.shape, scipy.__version__)`，先确认输入维度正确；
2. **检查收敛标志**：`root`、`minimize`、`curve_fit` 都看 `success`/`message`，别只看结果；
3. **给初值/区间**：`curve_fit` 用 `p0`；`brentq` 用 `brack`；`minimize` 用多组初值；
4. **固定随机种子**：`default_rng(seed)`，保证课堂演示与作业可复现；
5. **异常值/NaN**：先用 `np.isnan`/`np.isinf` 检查数据，再做插值/拟合；
6. **用图直观检查**：把数据、插值曲线、拟合曲线、频谱画出来，问题一眼可见；
7. **测试小数据**：先用 5 个点验证函数是否返回合理，再放大到真实数据。
