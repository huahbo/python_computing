## 5.1 从 DFT 到 FFT

离散傅里叶变换（DFT）把长度为 $N$ 的时域序列 $x[n]$ 变换为频域序列：

$$X[k]=\sum_{n=0}^{N-1}x[n]\,e^{-2\pi i\frac{kn}{N}},\quad k=0,1,\dots,N-1$$

直接计算复杂度 $O(N^2)$；快速傅里叶变换（FFT）利用旋转因子的对称性与周期性，把复杂度降到 $O(N\log N)$，因此长信号也能秒级处理。

## 5.2 单边频谱：`fft` + `fftfreq`

对实信号，频谱关于 $f_s/2$ 对称，通常只取前半。

```python
import numpy as np
from scipy.fft import fft, fftfreq

fs = 1000          # 采样率 Hz
T = 1              # 时长 s
t = np.linspace(0, T, int(fs*T), endpoint=False)
sig = 0.7*np.sin(2*np.pi*50*t)   # 50 Hz 正弦

yf = fft(sig)
xf = fftfreq(len(yf), 1/fs)
N = len(yf)//2

peak_x = xf[np.argmax(np.abs(yf[:N]))]
peak_y = np.abs(yf[:N]).max()
print(f"peak freq = {peak_x:.1f} Hz, amplitude = {peak_y:.2f}")
```

```text
peak freq = 50.0 Hz, amplitude = 350.00
```

**为什么幅值是 350 而不是 0.7？** 因为 `fft` 未做归一化：单边频谱取正值一半并乘以 $2/N$ 才是物理幅值。本例 $N=1000$，峰值（双边）约为 $0.7\times500=350$。

## 5.3 更省内存的 `rfft` + `rfftfreq`

实信号可用 `rfft`（只算一半复数），更快且省内存。

```python
import numpy as np
from scipy.fft import rfft, rfftfreq
Yr = rfft(sig)
freqs = rfftfreq(len(t), 1/fs)
print(f"peak freq = {freqs[np.argmax(np.abs(Yr))]:.1f} Hz")
print(f"n_rfft = {len(Yr)}, n_fft = {len(yf)}")
```

```text
peak freq = 50.0 Hz
n_rfft = 501, n_fft = 1000
```

`rfft` 输出约 $N/2+1$ 个点，与 `rfftfreq` 频率轴对齐。

## 5.4 用两个频率构造信号并做滤波

构造 $0.7\sin(2\pi\cdot50t)+\sin(2\pi\cdot200t)$。频谱应在 50 Hz 与 200 Hz 出现峰值。

```python
import numpy as np
sig2 = 0.7*np.sin(2*np.pi*50*t) + np.sin(2*np.pi*200*t)
Y2 = rfft(sig2)
f2 = rfftfreq(len(t), 1/fs)
top = np.argsort(np.abs(Y2))[-3:][::-1]
print("top freqs =", np.round(f2[top], 1), "  amps =", np.round(np.abs(Y2[top]), 1))
```

```text
top freqs = [200.  50.  50.1]   amps = [500.  350. 199.8]
```

`top` 中出现 50.1 Hz 是因为 50 Hz 附近存在频谱泄漏（非整数周期），属正常现象。

### 5.4.1 低通滤波

用 Butterworth 低通，保留 50 Hz、抑制 200 Hz。

```python
from scipy.signal import butter, lfilter
nyq = 0.5 * fs
b, a = butter(3, 80/nyq, btype="low")
low_pass = lfilter(b, a, sig2)
print("lowpass last3 =", np.round(low_pass[-3:], 4))
```

```text
lowpass last3 = [-0.5617 -0.639  -0.6414]
```

此时输出应只剩下 50 Hz 分量（与纯 $0.7\sin(2\pi\cdot50t)$ 相近）。

### 5.4.2 高通 / 带通 / 带阻

```python
b_hi, a_hi = butter(3, 120/nyq, btype="high")
high_pass = lfilter(b_hi, a_hi, sig2)
print("highpass last3 =", np.round(high_pass[-3:], 4))

b_bp, a_bp = butter(3, [60/nyq, 100/nyq], btype="band")
band_pass = lfilter(b_bp, a_bp, sig2)
print("bandpass last3 =", np.round(band_pass[-3:], 4))

b_bs, a_bs = butter(3, [150/nyq, 180/nyq], btype="bandstop")
band_stop = lfilter(b_bs, a_bs, sig2)
print("bandstop last3 =", np.round(band_stop[-3:], 4))
```

```text
highpass last3 = [-0.4903 -0.9695 -0.1156]
bandpass last3 = [ 0.0658  0.0332  0.0031]
bandstop last3 = [-0.9061 -1.4789 -0.628 ]
```

带通只保留 60–100 Hz 附近（此区间几乎没有信号分量，故输出接近 0）；带阻削弱 150–180 Hz 一段（该处也无信号），所以输出仍接近原始信号。

## 常见误区

| # | 误区 | 正确做法 |
| ---- | ---- | ---- |
| 1 | 直接用 `fft` 幅值当作真实幅度 | 要除以 $N$ 并（单边）乘 2 换算；或用 `rfft` 后作归一化 |
| 2 | 用 `fftfreq` 频率轴取整段画图 | 实数信号只画前一半即可，避免无意义的镜像 |
| 3 | 把 `butter` 的 `Wn` 直接当 Hz | `Wn` 是归一化频率 = 截止频率 / (fs/2) |
| 4 | 用 `lfilter` 造成相位延迟 | 需要零相位可用 `filtfilt`（`scipy.signal.filtfilt`） |
| 5 | 信号非整数周期导致“峰值多个旁瓣” | 加窗（如 `scipy.signal.windows.hann`）可减少频谱泄漏 |
| 6 | 采样率过低产生混叠 | 需满足 Nyquist：$f_s>2f_{\max}$ |
