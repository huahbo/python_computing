## 3.1 一维插值

已知 $n$ 个点 $(x_i,y_i)$，要在 $x$ 的任意位置估计 $y$。线性插值用直线连接数据点；三次样条用分段三次多项式，保证一阶/二阶导数连续，曲线更光滑。

### 3.1.1 使用 `np.interp`（线性）

```python
import numpy as np
x = np.array([0, 1, 2, 3, 4, 5])
y = np.array([0, 0.8, 0.9, 0.1, -0.8, -1])
print(np.interp([0.5, 2.5, 4.5], x, y))
```

```text
[ 0.4  0.5 -0.9]
```

`np.interp` 只能用线性插值，速度最快。

### 3.1.2 经典的 `interp1d`（注意：新版本建议优先 `CubicSpline`）

```python
from scipy.interpolate import interp1d
f_lin = interp1d(x, y, kind="linear")
f_cub = interp1d(x, y, kind="cubic")
print(np.round(f_lin([0.5, 2.5, 4.5]), 4))
print(np.round(f_cub([0.5, 2.5, 4.5]), 4))
```

```text
[ 0.4   0.5  -0.9 ]
[ 0.4583  0.575  -1.0333]
```

> `interp1d` 仍可用；新代码建议直接用下文的 `CubicSpline` 或 `RegularGridInterpolator`（更明确、更高效）。

### 3.1.3 推荐：`CubicSpline`

```python
from scipy.interpolate import CubicSpline
cs = CubicSpline(x, y)
print("cs(2.5) =", cs(2.5))
print(np.round(cs([0.5, 1.5, 2.5, 3.5, 4.5]), 4))
```

```text
cs(2.5) = 0.575
[ 0.4583  0.9667  0.575  -0.3917 -1.0333]
```

注意 `CubicSpline` 需要至少 4 个点才能做三次样条；点太少会自动降阶。

## 3.2 二维插值（规则网格）

`scipy.interpolate.interp2d` 已在较新版本中废弃，新代码推荐用 `RegularGridInterpolator`。它在规则网格 $(x_i,y_j)$ 上定义函数值 $Z_{i,j}$。

```python
from scipy.interpolate import RegularGridInterpolator
import numpy as np

xg = np.linspace(0, 3, 4)
yg = np.linspace(0, 3, 4)
X, Y = np.meshgrid(xg, yg, indexing="ij")
Z = X + Y   # 简单平面 z = x + y

rgi = RegularGridInterpolator((xg, yg), Z, method="linear")
print(rgi([[1.5, 1.5], [2.0, 3.0]]))
```

```text
[3. 5.]
```

点 $(1.5,1.5)$ 处 $z=3$，$(2,3)$ 处 $z=5$，与真值一致。

## 3.3 散点插值 `griddata`

实验数据通常是不规则散点，用 `griddata(已知点, 已知值, 待求点, method='linear'|'cubic'|'nearest')`。

```python
from scipy.interpolate import griddata
rng = np.random.default_rng(0)
pts = rng.uniform(0, 10, size=(30, 2))       # 30 个散点 (x,y)
vals = np.sin(pts[:, 0]/2) + np.cos(pts[:, 1]/3)
print(griddata(pts, vals, (5, 5)))
```

```text
0.2790441455976028
```

`griddata` 会自动三角剖分；`method='cubic'` 更光滑，但需要点数足够且可能更慢。

## 3.4 插值 vs 拟合（重点）

| 概念 | 插值 | 拟合 |
| ---- | ---- | ---- |
| 目标 | 曲线**经过所有**已知点 | 曲线**尽量接近**所有点 |
| 是否过点 | 是 | 否 |
| 适用数据 | 数据无噪声，需要精确通过 | 数据含噪声，希望反映整体趋势 |
| 典型工具 | `CubicSpline`、`griddata` | `curve_fit`、`np.polyfit` |
| 风险 | 高阶插值可能震荡（龙格现象） | 模型设定错误时欠拟合/过拟合 |

一句话：**插值信任每一个点，拟合容忍噪声**。若采样点本身有测量误差，优先拟合；若是光滑函数的真实采样，插值能给出“补全”效果。

## 常见误区

1. 把 `interp1d`/`CubicSpline` 用在噪声数据上：插值会“穿过噪声”，应改用 `curve_fit`。
2. 以为 `interp2d` 是长期可用接口：新版本已推荐 `RegularGridInterpolator`。
3. 忘了 `RegularGridInterpolator` 要求**规则网格**（`(x_i, y_j)` 组合成矩形网格）；散点要用 `griddata`。
4. `griddata` 对网格外的点会返回 `nan`：外推并非其默认功能，需自行处理。
5. 使用高阶多项式插值（如 `kind=9`）在等距点上容易产生**龙格现象**（端点附近大幅震荡）。
