## 3.1 一维插值

已知 $n$ 个点 $(x_i,y_i)$，要在 $x$ 的任意位置估计 $y$。线性插值用直线连接数据点；三次样条用分段三次多项式，保证一阶/二阶导数连续，曲线更光滑。

### 3.1.1 使用 `np.interp`（线性）

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)
x = np.array([0, 1, 2, 3, 4, 5])
y = np.array([0, 0.8, 0.9, 0.1, -0.8, -1])
print(np.interp([0.5, 2.5, 4.5], x, y))
```

```text
[ 0.4  0.5 -0.9]
```

`np.interp` 只能用线性插值，速度最快。

### 3.1.2 经典的 `interp1d`（注意：新版本建议优先 `CubicSpline`）

```python
from scipy.interpolate import interp1d
f_lin = interp1d(x, y, kind="linear")
f_cub = interp1d(x, y, kind="cubic")
print(np.round(f_lin([0.5, 2.5, 4.5]), 4))
print(np.round(f_cub([0.5, 2.5, 4.5]), 4))
```

```text
[ 0.4  0.5 -0.9]
[ 0.4583  0.575  -1.0333]
```

> `interp1d` 仍可用；新代码建议直接用下文的 `CubicSpline` 或 `RegularGridInterpolator`（更明确、更高效）。

### 3.1.3 推荐：`CubicSpline`

```python
from scipy.interpolate import CubicSpline
cs = CubicSpline(x, y)
print("cs(2.5) =", cs(2.5))
print(np.round(cs([0.5, 1.5, 2.5, 3.5, 4.5]), 4))
```

```text
cs(2.5) = 0.575
[ 0.4583  0.9667  0.575  -0.3917 -1.0333]
```

注意 `CubicSpline` 需要至少 4 个点才能做三次样条；点太少会自动降阶。

## 3.2 二维插值（规则网格）

`scipy.interpolate.interp2d` 已在较新版本中废弃，新代码推荐用 `RegularGridInterpolator`。它在规则网格 $(x_i,y_j)$ 上定义函数值 $Z_{i,j}$。

```python
from scipy.interpolate import RegularGridInterpolator
import numpy as np

xg = np.linspace(0, 3, 4)
yg = np.linspace(0, 3, 4)
X, Y = np.meshgrid(xg, yg, indexing="ij")
Z = X + Y   # 简单平面 z = x + y

rgi = RegularGridInterpolator((xg, yg), Z, method="linear")
print(rgi([[1.5, 1.5], [2.0, 3.0]]))
```

```text
[3. 5.]
```

点 $(1.5,1.5)$ 处 $z=3$，$(2,3)$ 处 $z=5$，与真值一致。

## 3.3 散点插值 `griddata`

实验数据通常是不规则散点，用 `griddata(..., method="linear"/"cubic"/"nearest")`。

```python
from scipy.interpolate import griddata
rng = np.random.default_rng(0)
pts = rng.uniform(0, 10, size=(30, 2))       # 30 个散点 (x,y)
vals = np.sin(pts[:, 0]/2) + np.cos(pts[:, 1]/3)
print(griddata(pts, vals, (5, 5)))
```

```text
0.2790441455976028
```

`griddata` 会自动三角剖分；`method='cubic'` 更光滑，但需要点数足够且可能更慢。

## 3.4 插值 vs 拟合（重点）

| 概念 | 插值 | 拟合 |
| ---- | ---- | ---- |
| 目标 | 曲线**经过所有**已知点 | 曲线**尽量接近**所有点 |
| 是否过点 | 是 | 否 |
| 适用数据 | 数据无噪声，需要精确通过 | 数据含噪声，希望反映整体趋势 |
| 典型工具 | `CubicSpline`、`griddata` | `curve_fit`、`np.polyfit` |
| 风险 | 高阶插值可能震荡（龙格现象） | 模型设定错误时欠拟合/过拟合 |


## 案例卡 3：一维插值 vs 多项式拟合——缺失值用 CubicSpline 补全

### 目标

对一条光滑曲线（$y=\sin x$）采样 10 个点并故意挖掉 2 个，分别用三次样条插值（`CubicSpline`）和 3 次多项式拟合（`np.polyfit`）去补全缺失点，并比较整段误差：理解“插值贴点、拟合平滑”在补缺失值上的差异。

### 代码

```python
import numpy as np
from scipy.interpolate import CubicSpline
np.set_printoptions(precision=4, suppress=True)

rng = np.random.default_rng(3)
x = np.linspace(0, 2*np.pi, 10)
y_true = np.sin(x)
y_obs = y_true + rng.normal(0, 0.05, x.size)
mask_ok = np.ones(x.size, dtype=bool)
mask_ok[[3, 6]] = False
x_ok = x[mask_ok]; y_ok = y_obs[mask_ok]

cs = CubicSpline(x_ok, y_ok)
coef = np.polyfit(x_ok, y_ok, 3)
poly = np.poly1d(coef)
x_miss = x[~mask_ok]
print("缺失点 x =", np.round(x_miss, 4))
print("CubicSpline 补全 =", np.round(cs(x_miss), 4))
print("poly3 拟合补全 =", np.round(poly(x_miss), 4))
print("真实值 =", np.round(y_true[~mask_ok], 4))
grid = np.linspace(0, 2*np.pi, 500)
rmse_s = np.sqrt(np.mean((cs(grid) - np.sin(grid))**2))
rmse_p = np.sqrt(np.mean((poly(grid) - np.sin(grid))**2))
print("RMSE(样条) =", round(float(rmse_s), 4))
print("RMSE(3次多项式) =", round(float(rmse_p), 4))
```

### 运行结果（已运行核验）

```text
缺失点 x = [2.0944 4.1888]
CubicSpline 补全 = [ 0.8895 -0.8448]
poly3 拟合补全 = [ 0.6857 -0.759 ]
真实值 = [ 0.866 -0.866]
RMSE(样条) = 0.0511
RMSE(3次多项式) = 0.0958
```

### 讲解

**一句话人话**：插值像“用直尺/曲线板把已知点连起来”，缺失点用相邻点推；拟合像“用一条整体趋势线去平均所有点”，缺失点由全局趋势推。

- `y_obs = y_true + rng.normal(0, 0.05, x.size)`：先给真值加一点噪声，让问题更真实（但仍是“光滑采样 + 小噪声”，更适合插值）。
- `mask_ok[[3, 6]] = False`：把第 4、7 个点设为“缺失”，`x_ok`/`y_ok` 只保留未缺失点。
- `CubicSpline(x_ok, y_ok)`：用未缺失点构造三次样条，它在缺失点处给出的 `0.8895`、`-0.8448` 贴近真实 `0.866`、`-0.866`。
- `np.polyfit(x_ok, y_ok, 3)`：用 3 次多项式拟合未缺失点，再 `np.poly1d` 转成可调用对象 `poly`；它在缺失点处给 `0.6857`、`-0.759`，偏差更大。
- 整段 500 个点的 RMSE：样条 `0.0511`，3 次多项式 `0.0958`。因为真值是光滑 `sin`，局部分段的样条比单片 3 次多项式更贴合；若噪声很大，则拟合更稳。

### 主要用法 / API

| 需求 | 写法 | 说明 |
| ---- | ---- | ---- |
| 一维三次样条插值 | `CubicSpline(x, y)` | 函数可调用，返回 `cs(xnew)` |
| 多项式拟合 | `np.polyfit(x, y, deg)` | 返回系数数组 |
| 多项式转函数 | `np.poly1d(coef)` | 返回可调用对象 |
| 布尔缺失掩码 | `mask = ~np.isnan(arr)` | 选非缺失点 |
| 整段误差 | `rmse = sqrt(mean((f(x)-true)**2))` | 评价插值/拟合质量 |

### 常见错误

- 对有噪声的数据做样条插值：插值会“穿过噪声”，此时应改用 `curve_fit`/`polyfit`；
- 认为插值能“外推”缺失区间：`CubicSpline` 边界外可能明显失真，重点应放在区间内；
- `polyfit` 的阶数过高（如 9 次）会出现龙格现象（端点震荡）；
- 用 `np.polyfit` 时忘记 `x_ok`/`y_ok` 必须等长且无 NaN。

## 常见误区

1. 把 `interp1d`/`CubicSpline` 用在噪声数据上：插值会“穿过噪声”，应改用 `curve_fit`。
2. 以为 `interp2d` 是长期可用接口：新版本已推荐 `RegularGridInterpolator`。
3. 忘了 `RegularGridInterpolator` 要求**规则网格**（`(x_i, y_j)` 组合成矩形网格）；散点要用 `griddata`。
4. `griddata` 对网格外的点会返回 `nan`：外推并非其默认功能，需自行处理。
5. 使用高阶多项式插值（如 `kind=9`）在等距点上容易产生**龙格现象**（端点附近大幅震荡）。
