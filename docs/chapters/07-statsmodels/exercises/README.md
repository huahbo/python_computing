# 第 7 章 练习题（exercises/）

> 本章练习的**唯一入口**。由 <code>../chapter_6_7_8_quiz</code> 中的 10 道 Statsmodels 题整理而来。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| <code>quiz.ipynb</code> | 学生自测/提交版 | 10 道题，含题面 + 提示 + TODO 代码单元 |
| <code>answers.ipynb</code> | 教学答案版 | 每题含思路 + 可运行的参考实现 |
| <code>assignment.md</code> | 书面作业 | 覆盖回归、ANOVA、GLM、诊断、时间序列 |

## 使用方法

1. **自测**：打开 <code>quiz.ipynb</code>，按题号完成 <code># TODO</code> 单元，运行全部单元；
2. **对照**：先独立完成，再用 <code>answers.ipynb</code> 对照代码与思路；
3. **课堂**：教师可用 <code>quiz.ipynb</code> 现场演示，每题自带提示。

## 建议完成顺序

1. 读 01–02 正文 → 2. <code>lab/</code> 上机 → 3. <code>quiz</code> 第 1–5 题（容易/中等） → 4. 第 6–10 题（中等/稍难）。

## 评分建议

- 10 道题建议占总评 15–20%；
- 上机 <code>lab/</code> 占总评 10–15%；
- 综合案例报告（03 拓展）可作为期中/项目加分项。
