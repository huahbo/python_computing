# 04 常见误区与技巧

> 本章为新增“查漏补缺”页：把 statsmodels 使用中最容易踩的坑集中列出，并给出正确写法、性能与调试技巧。

## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | <code>sm.OLS(y, X)</code> 直接用原始 X | <code>X = sm.add_constant(X)</code> | OLS 默认不自动加截距 |
| 2 | 公式里 <code>y ~ group</code> | <code>y ~ C(group)</code> | 分类变量需转成哑变量 |
| 3 | <code>y ~ x1 * x2</code> 当“乘法项” | <code>y ~ x1 + I(x1*x2)</code> 或 <code>y ~ x1 + x2 + x1:x2</code> | 公式里 <code>*</code> 表示主效应+交互 |
| 4 | 用 <code>predict(X_new)</code> 预测 | 预测前也要 <code>sm.add_constant(X_new)</code> | 训练/预测设计矩阵必须一致 |
| 5 | 把 GLM <code>predict</code> 当 0/1 | 需要 <code>(p > thr).astype(int)</code> | 默认返回到概率 <code>p</code>，不是类别 |
| 6 | 对非平稳序列直接 ARIMA | 先 <code>adfuller</code>，必要时差分 | 非平稳易“伪回归” |
| 7 | <code>seasonal_decompose</code> 不设 period | 日数据设 7、月数据设 12 | 否则季节期抓不到 |
| 8 | 忘差分后 <code>dropna()</code> | <code>ts.diff().dropna()</code> | 差分首元素为 NaN |
| 9 | 只看 R² 不看诊断 | 同时看 <code>summary()</code> 的 F、P、JB、Durbin-Watson | R² 高可能只是表面拟合 |
| 10 | 用 <code>np.linalg.lstsq</code> 替代 OLS 推断 | 需要 P 值/置信区间用 <code>sm.OLS</code> | lstsq 只给系数，不给推断 |
| 11 | 用 <code>anova_lm</code> 传原始数组 | 传 <code>ols(...).fit()</code> 的结果 | anova_lm 需要回归结果对象 |
| 12 | 混淆 <code>params</code> 与 <code>bse</code> | 系数看 params，精度看 bse/P 值 | params 只是点估计 |

## 2. 原理级难点

### 2.1 为什么必须加常数列

OLS 的模型是 $y = X\beta + \varepsilon$。若不手动加一列全 1，模型里就没有截距项，相当于强制过原点。公式 API 会自动加 <code>Intercept</code>，而数组 API 需要你显式 <code>sm.add_constant</code>。

### 2.2 C()、I()、* 的区别

<code>ols</code> 用的公式语法来自 patsy：

- <code>C(x)</code>：把数值列当分类变量；
- <code>I(x**2)</code>：对数值列做数学变换（<code>I</code> 包裹）；
- <code>x1*x2</code>：展开为主效应+交互；<code>x1:x2</code> 只写交互；<code>x1+x2</code> 只加主效应。

### 2.3 predict 返回什么

默认 <code>predict</code> 返回**线性预测值**（对 GLM 是 logit 的线性部分），需要加参数 <code>linear=False</code> 或直接用概率。对 OLS，两者一致。对二分类 GLM，想得到概率且区分清楚，建议用 <code>model.predict(X)</code>（默认即概率），再用阈值分类。

### 2.4 summary() 里关键字段

| 字段 | 含义 | 关注点 |
| ---- | ---- | ---- |
| <code>coef</code> | 系数估计 | 解释“每单位变化” |
| <code>std err</code> | 标准误 | 越小越稳 |
| <code>t</code> / <code>P&gt;|t|</code> | t 检验 | P<0.05 显著 |
| <code>[0.025, 0.975]</code> | 95% 置信区间 | 含 0 一般说明不显著 |
| <code>R²</code> / <code>Adj. R²</code> | 拟合优度 | Adj. R² 更能防过拟合 |
| <code>F</code> / <code>Prob(F)</code> | 整体显著性 | 模型整体是否有解释力 |
| <code>Jarque-Bera</code> / <code>Prob(JB)</code> | 残差正态性 | Prob(JB)>0.05 可接受 |
| <code>Durbin-Watson</code> | 残差自相关 | 接近 2 好 |

## 3. 性能技巧

- **先聚合再建模**：对大数据，先用 <code>groupby</code> 聚合或抽样，减少矩阵规模；
- **避免频繁 <code>summary()</code>**：大模型渲染完整摘要会慢，调试时用 <code>params</code>、<code>bse</code>、<code>rsquared</code> 等属性；
- **OLS 可用 <code>np.linalg.lstsq</code> 快速求解**，但推断请回落 statsmodels；
- **GLM 拟合用 <code>fit(maxiter=...)</code> 控制迭代**，必要时增加 <code>maxiter</code>；
- **时间序列建模**：<code>ARIMA</code> 用 <code>model.fit(method='lbfgs')</code> 或 <code>disp=False</code> 减少输出，提升速度；
- **大数据回归**：考虑 <code>GD/IRLS</code>（<code>fit_regularized</code>）或改用 scikit-learn。

## 4. 调试建议

1. 先打印 <code>type(df)</code>、<code>df.shape</code>、<code>df.dtypes</code>，确认数据已正确进入 DataFrame；
2. 确认因变量 <code>y</code> 是一维 Series/array，自变量 X 是二维；（<code>X.shape</code>）
3. 用 <code>sm.add_constant</code> 后立即检查列名是否含 <code>const</code>；
4. 用 <code>help(model)</code>、<code>dir(model)</code> 查看可用属性（<code>params</code>、<code>bse</code>、<code>pvalues</code>、<code>conf_int</code>）；
5. 随机/拟合问题**固定种子** <code>np.random.default_rng(seed)</code>，便于复现；
6. 用 <code>df.isna().sum()</code>、<code>np.isinf</code> 检查缺失与异常值；
7. 公式写错时，把 <code>data=df</code> 换成 <code>data=df[['x','y']]</code> 或打印 <code>df.head()</code> 排除列名问题。
