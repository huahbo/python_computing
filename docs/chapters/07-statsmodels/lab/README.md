# 第 7 章 上机实验（lab/）

> 本目录是第 7 章的**上机实验**：一份可独立完成的 <code>lab.ipynb</code>，覆盖从环境自检到综合任务的完整流程。

## 文件

| 文件 | 说明 |
| ---- | ---- |
| <code>lab.ipynb</code> | 上机实验 notebook（21 个单元：10 个代码单元，Part 1–9，含 TODO 与检查项） |

## 如何开始

1. 打开 <code>lab.ipynb</code>（JupyterLab / VS Code）；
2. 按顺序运行 Part 1 → Part 9；
3. 完成所有 <code># TODO</code>，记录输出；
4. 在末尾 <code>提交清单</code> 逐项打钩；
5. 导出（可选）后提交 <code>.ipynb</code>。

## 各部分用时建议

| Part | 内容 | 建议时间 |
| ---- | ---- | ---- |
| 1 | 单因素方差分析 | 15 min |
| 2 | 一元线性回归（数组接口） | 15 min |
| 3 | 公式 API 与多元回归 | 15 min |
| 4 | GLM 二分类 Logit | 15 min |
| 5 | 回归诊断（QQ 图 / JB） | 15 min |
| 6 | 时间序列分解 | 15 min |
| 7 | 平稳性检验（ADF） | 15 min |
| 8 | ARIMA 拟合与预测 | 20 min |
| 9 | 综合任务：城市日负荷分析 | 25 min |

## 教师说明

- 可作为一次 2–3 学时的上机课；
- 检查重点：Part 1 的 P 值判断、Part 5 的 JB、Part 7 的 ADF 对比、Part 9 的三句结论；
- 可要求学生把每个 Part 的输出截图附在报告里。
