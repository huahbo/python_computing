# 第 6 章 练习题（exercises/）

> 本章练习的**唯一入口**。自测题整理自历史综合测验（../chapter_6_7_8_quiz）中的 NetworkX 部分。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| quiz.ipynb | 学生自测/提交版 | 10 道自测题（容易/中等/稍难），含可折叠提示与空的作答代码单元 |
| answers.ipynb | 教学答案版 | 同题目的可运行参考答案，已附真实输出 |
| assignment.md | 作业题（12 题） | 覆盖创建图、有向图、属性、度/聚类/中心性、连通性、MST、最短路径、社区划分、图生成器；含答案解析 |

## 使用方法

1. **自测**：打开 quiz.ipynb，按题号完成作答单元，运行全部单元后对照 answers.ipynb。
2. **作业**：完成 assignment.md 的 12 题，将代码运行结果写在每题后的输出区再提交。
3. **课堂**：教师可用 answers.ipynb 现场演示；亦可把 quiz.ipynb 的提示折叠起来做随堂测试。

## 建议完成顺序

1. 读 01–03 正文 → 2. lab/ 上机 → 3. 做 assignment.md 1–6（容易） → 4. 7–10（中等） → 5. 11–12（稍难/挑战）。

## 评分建议

- quiz.ipynb 共 10 题，教师可按每题 1–2 分赋分；建议占总评 10–15%；
- 上机 lab/ 占总评 10–15%；
- 综合案例报告（04 拓展）可作为期中/项目加分项。
