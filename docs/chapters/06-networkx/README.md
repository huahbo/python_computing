# 6. NetworkX 及其基本使用（新版讲义）

## 本章概览

复杂系统（社交网络、交通网、生物分子网络、互联网）都可抽象为“节点 + 边”的图（Graph）。NetworkX 是 Python 中创建、操作、分析复杂网络的标准库：它内置 Graph（无向图）与 DiGraph（有向图），以及度、聚类系数、中心性、最短路径、最小生成树、社区划分等大量图论算法。本章将带你从“创建一张图”走到“分析图的结构指标”，再到“求解遍历、最短路径、最小生成树等基本问题”。

## 学习目标

学完本章，你应该能够：

1. 用 nx.Graph 与 nx.DiGraph 创建无向图/有向图，并添加节点、边与属性（权重、标签）。
2. 读取 nodes / edges / degree，访问邻居、前驱、后继与入度/出度。
3. 计算并解释度/度分布、平均路径长度、聚类系数、传递性、介数中心性、接近中心性、模块度等结构指标。
4. 用 DFS / BFS 遍历图，并用 shortest_path 求无权/带权最短路径（Dijkstra、Bellman-Ford、Floyd-Warshall）。
5. 用 minimum_spanning_tree 求解最小生成树，并理解 Kruskal / Prim 的适用场景。
6. 判断图的连通/强连通/弱连通，识别连通分量。
7. 完成一个综合案例（空手道俱乐部的社区划分与最短路径），把本章知识串起来。

## 先修要求与运行环境

- 熟悉 Python 基础语法（变量、列表、字典、函数、循环）。
- 建议先学第 1 章 NumPy（用于邻接矩阵、向量化统计）。
- 安装 Python 3.10+ 与 NetworkX：

~~~bash
pip install networkx
# 若需要绘图/上机，再安装
pip install matplotlib numpy
~~~

- 推荐在 JupyterLab / VS Code 中打开 .ipynb 练习；命令行列出的脚本直接保存为 .py 运行即可。
