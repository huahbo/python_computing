# 第 6 章 教学说明（教师用）

> 面向授课教师：课时建议、重点难点、上机安排、考核建议。学生无需阅读本页。

## 1. 教学目标

- 让学生建立“复杂系统可抽象为图”的思维，会用 NetworkX 创建、修改、分析图；
- 掌握度、聚类系数、中心性、模块度等结构指标的含义与计算；
- 能根据问题性质选择合适算法（遍历、最短路径、最小生成树）；
- 能完成一个真实网络（空手道俱乐部）的综合分析并可视化。

## 3. 重点与难点

### 重点
- Graph 与 DiGraph 的区别，nodes/edges/degree、邻居/前驱/后继；
- 节点与边属性（weight），加权度（点强度）；
- 度分布、聚类系数、传递性、介数/接近中心性、模块度的含义；
- 最短路径算法选择（Dijkstra / Bellman-Ford / Floyd-Warshall）；
- 最小生成树（MST）概念与实现。

### 难点（学生常卡）
- 有向图的“前驱 vs 后继”，以及强连通/弱连通的区别；
- 加权图函数是否需要传 weight="weight"（默认按无权计算）；
- 视图对象 nodes()/edges() 不能当列表直接改；
- 社区划分结果非唯一，需结合 Q 值判断；
- 复杂网络指标（介数中心性、模块度）的直观理解，建议用 04 案例图示讲解。

## 4. 上机（lab/）使用建议

- 每部分 10–15 分钟；要求每格代码都运行并记录输出；
- 综合任务（空手道俱乐部）可小组完成，每人写 3 句结论；
- 教师可在 lab 基础上增加“隐藏检查点”（如最终社区数、模块度、最短路径断言）。

## 5. 作业与考核建议

- **平时**：exercises 自测 10 题（quiz.ipynb），可回收批改；
- **上机**：lab.ipynb 完成情况 + 04 拓展任务；
- **期中/期末融合**：把 NetworkX 指标（如度分布、社区结构）与第 8 章 sklearn 聚类/PCA 结合，做“复杂网络 + 机器学习”小项目。

## 6. 易错点清单（直接用于出题）

1. 在 DiGraph 上不清前驱/后继；
2. zip(nodes, in_degree, out_degree) 解包错误；
3. 加权图不传 weight="weight"；
4. 负权图用 Dijkstra；
5. 不连通图用 diameter；
6. 把 MST 当最短路径；
7. 随机图不设 seed；
8. 社区检测结果当成唯一解。
