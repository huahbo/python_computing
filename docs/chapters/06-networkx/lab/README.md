# 第 6 章 上机实验（lab/）

> 本目录是第 6 章的**上机实验**：一份可独立完成的 lab.ipynb，覆盖从环境自检到综合任务的完整流程。

## 文件

| 文件 | 说明 |
| ---- | ---- |
| lab.ipynb | 上机实验 notebook（18 个单元：7 个 Part，含 TODO 与检查项） |
| karate_degree_lab.png | 运行 Part 6 后生成的度分布图像 |

## 如何开始

1. 打开 lab.ipynb（JupyterLab / VS Code）；
2. 按顺序运行 Part 1 → Part 6；
3. 完成所有 TODO，记录输出；
4. 在末尾提交清单逐项打钩；
5. 导出（可选）后提交 .ipynb。

## 各部分用时建议

| Part | 内容 | 建议时间 |
| ---- | ---- | ---- |
| 1 | 创建无向图与基本属性 | 10 min |
| 2 | 有向图：入度/出度/前驱后继 | 10 min |
| 3 | 节点/边属性与加权图 | 10 min |
| 4 | 图的分析指标 | 10 min |
| 5 | 遍历、最短路径与最小生成树 | 15 min |
| 6 | 综合任务（空手道俱乐部） | 20 min |

## 教师说明

- 可作为一次 2–3 学时的上机课；
- 检查重点：Part 4 的中心性、Part 5 的最短路径与 MST、Part 6 的社区数与模块度；
- 可要求学生把每个 Part 的输出截图附在报告里。
