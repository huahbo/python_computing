# 第 2 章 教学说明（教师用）

> 面向授课教师：课时建议、重点难点、上机安排、考核建议。学生无需阅读本页。

## 1. 教学目标

- 让学生理解**符号计算与数值计算的区别**，并能根据问题选择 SymPy 或 NumPy；
- 掌握符号对象、极限、导数、积分、化简与数值化；
- 能独立用 SymPy 解方程/方程组、处理符号矩阵、求解常微分方程；
- 能通过 `lambdify` 把符号公式接入 NumPy/Matplotlib 完成“推导→数值→可视化”闭环。

## 3. 重点与难点

### 重点
- 符号对象创建与假设（`positive`、`real`、`integer`）；
- `limit` / `diff` / `integrate` 的准确用法与精确结果；
- `solve` / `solveset` / `linsolve` / `nonlinsolve` 的选择与返回值差异；
- `lambdify` 的“符号→数值”桥梁作用；
- `dsolve` 的通解与初值解。

### 难点（学生常卡）
- 表达式相等判断：一定要用 `simplify(a-b)==0` 或 `.equals`，而不是 `==`；
- `sqrt(x**2)` 的假设问题：无假设返回 `Abs(x)`，加 `positive=True` 才是 `x`；
- SymPy 矩阵与 NumPy 矩阵的 `*` 语义差异；
- `lambdify` 返回的是数值函数，不能再做 `diff`/`subs`；
- `dsolve` 对无法解析求解的方程会卡住/返回空，需转数值解。

## 4. 上机（lab/）使用建议

- 每部分 10–15 分钟；要求每格代码都运行并记录输出；
- 综合任务（符号面积 + 切线图）可小组完成；
- 教师可在 lab 基础上增加“隐藏检查点”用来回收（如最终数值断言）。

## 5. 作业与考核建议

- **平时**：exercises 10–15 题（quiz.ipynb 自动评分）；
- **上机**：lab.ipynb 完成情况 + 03 拓展任务；
- **期中/期末融合**：把 SymPy 的符号推导能力与 NumPy/SciPy 数值求解结合，例如用 `lambdify` 生成函数后做优化/拟合。

## 6. 易错点清单（直接用于出题）

1. `math.pi` 与 `sp.pi` 混用；
2. 用 `==` 判断符号表达式相等；
3. `sqrt(x**2)` 默认返回 `Abs(x)`；
4. `lambdify` 之后又调用 `diff`；
5. `dsolve` 未定义 `Function`；
6. `Matrix` 的 `*` 与 NumPy 的逐元素 `*` 混淆；
7. `solveset` 返回集合、`solve` 返回列表，类型不同。
