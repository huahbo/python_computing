# 第 2 章 练习题（exercises/）

> 本章练习的**唯一入口**。题目由历史测验 `../chapter_2_3_quiz` 中的 SymPy 部分整理而来，并补充了一些概念题。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `assignment.md` | 作业题 | 10 道覆盖符号创建、极限、导数、积分、解方程、矩阵、lambdify、dsolve；含详细答案解析 |
| `quiz.ipynb` | 学生自测/提交版 | 题面 + 空白答案单元 + **自动评分**（`_GRADES`） |
| `answers.ipynb` | 教学答案版 | 每题含提示 + 可展开答案 + 自动评分 |

## 使用方法

1. **作业**：打开 `quiz.ipynb`，按题号完成 `YOUR ANSWER HERE` 单元，运行全部单元后查看 `_GRADES` 汇总。
2. **自测**：先不看答案完成 `assignment.md` 的 10 道题，再用 `answers.ipynb` 对照。
3. **课堂**：教师可用 `quiz.ipynb` 现场演示；每题自带提示与自动测试。

## 建议完成顺序

1. 读 01–02 正文 → 2. `lab/` 上机 → 3. 做 `assignment.md` 1–5（易） → 4. 6–10（中/难）。

## 可选增补题（教师视情况布置）

1. **假设的影响**：比较 `sp.sqrt(x**2)` 在有无 `positive=True` 时的差异，并截图说明。
2. **符号 vs 数值**：用 `lambdify` 生成 `sin(x)/x` 数值函数，画出图像，说明在 0 点附近的行为。
3. **微分方程与数值对照**：用 `dsolve` 求 `y'+y=x` 的解析解，并用 SciPy `solve_ivp` 数值解在相同初值下比较。

## 评分建议

- `quiz.ipynb` 自动评分至 10 题；建议占总评 15–20%；
- 上机 `lab/` 占总评 10–15%；
- 综合案例报告（03 拓展）可作为期中/项目加分项。
