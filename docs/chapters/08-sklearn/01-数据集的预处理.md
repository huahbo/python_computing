### 1. 特征编码：把“文字”变成“数字”

大多数 sklearn 模型只能吃数值矩阵。对待分类特征，有两种常见编码。

#### 1.1 独热编码（OneHotEncoder）

把每个类别展开成一位为 1、其余为 0 的向量。默认输出稀疏矩阵，用 `sparse_output=False` 得到稠密数组。

```python
import numpy as np
from sklearn.preprocessing import OneHotEncoder

data = np.array([['male'], ['female'], ['male'], ['female']])
encoder = OneHotEncoder(sparse_output=False)
encoded = encoder.fit_transform(data)
print("categories_:", encoder.categories_)
print("shape:", encoded.shape)
print("特征名:", encoder.get_feature_names_out())
print(encoded)
```

```text
categories_: [array(['female', 'male'], dtype='<U6')]
shape: (4, 2)
特征名: ['x0_female' 'x0_male']
[[0. 1.]
 [1. 0.]
 [0. 1.]
 [1. 0.]]
```

> 注意：`male` 被编码为 `[0,1]`（因为 `categories_` 按字母序把 `female` 排在 0 列、`male` 排 1 列）。独热编码没有“谁大谁小”的含义，适合无序类别。

#### 1.2 标签编码（LabelEncoder）

把每个类别映射成 0、1、2 等整数。它暗示类别之间有顺序，对无序类别（如颜色、性别）通常不合适。

```python
from sklearn.preprocessing import LabelEncoder

labels = ['male', 'female', 'male', 'female']
le = LabelEncoder().fit(labels)
print("classes_:", le.classes_)
print("transform:", le.transform(labels))
```

```text
classes_: ['female' 'male']
transform: [1 0 1 0]
```

> 若类别本身有序（如 `小/中/大`），可改用 `OrdinalEncoder` 并显式指定 `categories`；若只是把字符串标签喂给分类器，常用 `LabelEncoder` 只看目标 y，而特征 x 的分类列建议用 `OneHotEncoder` 或 `OrdinalEncoder`。

### 2. 特征缩放：把量纲拉平

当各列量纲差别很大（比如一列在 0~1，另一列在 10^4 量级）时，距离类算法（KNN、SVM、KMeans、PCA）会被大方差特征主导，因此需要缩放。

#### 2.1 标准化（StandardScaler）

`x' = (x - mean) / std`，使每列均值 0、标准差 1。

```python
import numpy as np
from sklearn.preprocessing import StandardScaler

X = np.array([[1, 2], [3, 4], [5, 6]])
ss = StandardScaler().fit(X)
print("mean_:", ss.mean_, "scale_:", np.round(ss.scale_, 6))
print(ss.transform(X))
```

```text
mean_: [3. 4.] scale_: [1.632993 1.632993]
[[-1.22474487 -1.22474487]
 [ 0.          0.        ]
 [ 1.22474487  1.22474487]]
```

#### 2.2 归一化（MinMaxScaler）

把每列压缩到 `[0, 1]`（或其他 `feature_range`）。

```python
from sklearn.preprocessing import MinMaxScaler

mm = MinMaxScaler().fit(X)
print("data_min_:", mm.data_min_, "data_max_:", mm.data_max_)
print(mm.transform(X))
```

```text
data_min_: [1. 2.] data_max_: [5. 6.]
[[0.  0. ]
 [0.5 0.5]
 [1.  1. ]]
```

> 标准化对异常值更稳健（用均值/标准差），归一化把数据严格限制到区间。若有人告诉你“某个算法必须归一化”，指的是这两者之一；具体选哪个要看数据分布与模型（树模型一般不需要缩放）。

### 3. 数据集切分与交叉验证

#### 3.1 train_test_split

```python
from sklearn.model_selection import train_test_split
from sklearn.datasets import load_iris

iris = load_iris(); X, y = iris.data, iris.target
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)
print("train shape:", Xtr.shape, "test shape:", Xte.shape)
print("测试集各类数量:", np.unique(yte, return_counts=True))
```

```text
train shape: (105, 4) test shape: (45, 4)
测试集各类数量: (array([0, 1, 2]), array([15, 15, 15]))
```

> `stratify=y` 让训练/测试集各类比例一致（对分类很重要）；`random_state=42` 保证可复现。

#### 3.2 K 折交叉验证（cross_val_score）

把数据切成 K 份，轮流用 K-1 份训练、1 份测试，最后平均各折分数。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

model = LogisticRegression(max_iter=1000)
scores = cross_val_score(model, Xtr, ytr, cv=5)
print("各折分数:", np.round(scores, 4))
print("平均:", round(scores.mean(), 4))
```

```text
各折分数: [0.9524 0.9524 1.     0.9524 1.    ]
平均: 0.9714
```

> `cross_val_score` 内部会把每个模型 `fit` 在训练折、`score` 在验证折，因此它比单次 train/test 更稳健、也更少受随机划分影响。

#### 3.3 留一交叉验证（LeaveOneOut）

每次只留 1 个样本测试。适合小数据集，但计算量大。

```python
from sklearn.model_selection import LeaveOneOut

loo = LeaveOneOut()
scores = []
for tr, te in loo.split(Xtr[:30], ytr[:30]):
    m = LogisticRegression(max_iter=1000).fit(Xtr[tr], ytr[tr])
    scores.append(m.score(Xtr[te], ytr[te]))
print("留一法样本数:", len(scores), "平均:", round(np.mean(scores), 4))
```

```text
留一法样本数: 30 平均: 0.9333
```

### 4. 特征选择：保留更少的列

特征选择从原始列中挑出“最重要”的子集，能降低过拟合、加速训练。

#### 4.1 过滤法：VarianceThreshold（方差阈值）

```python
from sklearn.feature_selection import VarianceThreshold

sel = VarianceThreshold(threshold=0.8)
Xv = sel.fit_transform(X)
print("方差:", np.round(sel.variances_, 4))
print("变换后 shape:", Xv.shape)
```

```text
方差: [0.6811 0.1887 3.0955 0.5771]
变换后 shape: (150, 1)
```

> 只保留方差 ≥ 0.8 的特征（这里只有第 3 列）。方差小的列信息量低；但注意它只按方差筛，完全不看与 y 的关系。

#### 4.2 过滤法：SelectKBest + 互信息

```python
from sklearn.feature_selection import SelectKBest, mutual_info_classif

selb = SelectKBest(mutual_info_classif, k=2)
Xb = selb.fit_transform(X, y)
print("选中的特征索引:", selb.get_support(indices=True))
print("各特征互信息:", np.round(selb.scores_, 4))
print("变换后 shape:", Xb.shape)
```

```text
选中的特征索引: [2 3]
各特征互信息: [0.494  0.2597 0.9784 0.9804]
变换后 shape: (150, 2)
```

#### 4.3 包装法：RFE（递归特征消除）

```python
from sklearn.linear_model import LogisticRegression
from sklearn.feature_selection import RFE

est = LogisticRegression(max_iter=1000)
r = RFE(est, n_features_to_select=2)
Xr = r.fit_transform(X, y)
print("support_:", r.support_)
print("ranking_:", r.ranking_)
print("变换后 shape:", Xr.shape)
```

```text
support_: [False False  True  True]
ranking_: [3 2 1 1]
变换后 shape: (150, 2)
```

#### 4.4 嵌入法：Lasso / SelectFromModel

Lasso 的 L1 正则会把不重要的系数压到 0；用 `SelectFromModel` 包一个树模型，可按重要性阈值自动选列。

```python
from sklearn.linear_model import Lasso

ls = Lasso(alpha=0.1).fit(X, y)
print("Lasso 系数:", np.round(ls.coef_, 6))
print("非零掩码:", ls.coef_ != 0)
```

```text
Lasso 系数: [ 0.       -0.        0.408119  0.      ]
非零掩码: [False False  True False]
```

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import SelectFromModel

rf = RandomForestClassifier(n_estimators=10, random_state=42).fit(X, y)
selm = SelectFromModel(rf, prefit=True, threshold='mean')
Xm = selm.transform(X)
print("重要性:", np.round(rf.feature_importances_, 4), " 均值:", round(rf.feature_importances_.mean(), 4))
print("support_:", selm.get_support())
print("变换后 shape:", Xm.shape)
```

```text
重要性: [0.1293 0.0158 0.4447 0.4102]  均值: 0.25
support_: [False False  True  True]
变换后 shape: (150, 2)
```

### 5. 特征降维一览

特征降维是把高维空间压到低维（如 2 维便于可视化）。sklearn 常用：

- **PCA**（无监督）：找方差最大的方向，示例见 03 节。
- **LDA**（有监督）：融合类别信息，最大化类间/类内方差之比，示例见 03 节。

## 常见误区

1. 用 `fit_transform` 处理测试集 → 应先在训练集 `fit`，再对训练/测试都用 `transform`；最稳的做法是放进 `Pipeline`。
2. 用 `LabelEncoder` 编码无序分类特征 → 会引入虚假顺序；无序类别建议 `OneHotEncoder`。
3. 分类数据不编码直接喂 `LogisticRegression` → 会报错或产生错误结果。
4. 对树模型强行缩放，既不必要也浪费算力（通常无收益）。
5. `cross_val_score` 里把整个数据（含测试集）都用来调参 → 信息泄漏；网格搜索要放在独立验证集或嵌套交叉验证中。
