# 05 常见误区与技巧

> 本章新增“查漏补缺”页：把 sklearn 使用中最常见的坑集中列出，并给出性能、调试与自测清单。

## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | `scaler.fit_transform(X_test)` | 训练集 `fit`，然后训练/测试都 `transform`；或用 `Pipeline` | 用测试集统计量会“泄漏”测试信息 |
| 2 | 对无序分类特征用 `LabelEncoder` | 用 `OneHotEncoder` / `OrdinalEncoder` | 整数编码隐含顺序，误导模型 |
| 3 | `r2_score(y_pred, y_test)` | `r2_score(y_test, y_pred)` | 第一个参数是真值 y_true |
| 4 | 分类问题用 `r2_score` | 用 `accuracy_score` / `f1_score` / `roc_auc_score` | R² 只用于连续回归 |
| 5 | `fit_transform` 后再 `fit` 另一模型 | 把缩放放进 `Pipeline` 统一处理 | 避免重复/不一致的预处理 |
| 6 | `load_boston()` | 用 `load_diabetes` / `fetch_california_housing` / 自定义数据 | `load_boston` 已在 sklearn 1.2 移除 |
| 7 | `OneHotEncoder(sparse=False)` 老参数 | `sparse_output=False` | 新版本用 `sparse_output` |
| 8 | `RFE(estimator, 5)` 传位置参数 | `RFE(estimator, n_features_to_select=5)` | 新版 `n_features_to_select` 是关键字参数 |
| 9 | 用 `fit` 后直接 `transform` 新数据 | 先 `fit` 再 `transform`，否则 `NotFittedError` | 估计器必须携带训练统计量 |
| 10 | `GridSearchCV` 不设 `random_state` | 给模型与 `shuffle` 设置种子 | 结果不可复现 |
| 11 | 对树模型也强制缩放 | 通常可跳过（缩放对树无益） | 树按阈值切分，不受量纲影响 |
| 12 | `DBSCAN` 一个 `eps` 走天下 | 按数据量纲调 `eps`/`min_samples` | 密度参数与数据尺度强相关 |
| 13 | KMeans 不设 `random_state` | `KMeans(..., random_state=0)` | 初始中心随机，结果不稳定 |
| 14 | 用 `predict` 取概率 | 概率用 `predict_proba`（二分类取 `[:,1]`） | `predict` 返回类别标签 |
| 15 | 混淆矩阵行/列方向记反 | 记住 `confusion_matrix(y_true, y_pred)` 行是真值 | 行=真实，列=预测 |

## 2. 性能技巧

- **数据量优先用 `n_jobs=-1`**：`RandomForestClassifier(n_jobs=-1)`、`GridSearchCV(..., n_jobs=-1)` 可并行（注意 RAM）。
- **能向量化别循环**：特征处理尽量用 sklearn 方法一次性完成，避免 Python 逐行 for。
- **大矩阵用稀疏表示**：OneHot 后特征维度很大时保留稀疏矩阵（默认 `sparse_output=True`），别急着 `toarray()`。
- **`Pipeline` 更好维护**：把缩放、编码、特征选择、模型串成一个对象，训练/预测/调参都更安全。
- **网格搜索先粗后细**：先搜大跨度，再在小范围精调；必要时用 `RandomizedSearchCV` 代替 `GridSearchCV`。
- **启用 Warm start**：增量训练可用 `partial_fit`（如 `SGDClassifier`）或 `warm_start=True`（部分集成模型）。

## 3. 调试建议

1. 先打印 `X.shape`、`y.shape`、`dtype`，确认维度与缺失值。
2. 用 `np.isnan(X).sum()`、`np.isinf(X).sum()` 检查异常值。
3. 出错先看 **fit 是否成功**：`model.fit(X, y)` 后打印 `model.coef_` / `model.feature_importances_`。
4. 对 `Pipeline`，用 `pipe.named_steps` 查看每一步；用 `pipe.get_params()` 检查参数名。
5. 检查是否“数据泄漏”：
   - 缩放器是否只 `fit` 在训练折（用 Pipeline 最保险）；
   - `train_test_split` 是否在归一化之前。
6. 收敛警告（如“lbfgs failed to converge”）通常提示：特征未缩放、`max_iter` 太小，或类别不平衡。
7. 固定所有随机种子（`random_state`）并记录，便于复现与讨论。
