# 第 8 章 练习题（exercises/）

> 本章练习的**唯一入口**。quiz 与答案改编自 `../chapter_6_7_8_quiz` 中第 6–8 章综合测验的 sklearn 部分（第 21–30 题）。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `quiz.ipynb` | 学生自测/提交版 | 10 道 sklearn 自测题（含 TODO 空白与可展开提示），覆盖预处理、分类、回归、聚类、降维、调参 |
| `answers.ipynb` | 教学答案版 | 每题给参考实现，可直接运行 |
| `assignment.md` | 作业（12 题） | 含简答 + 编程 + 综合题，附参考答案要点 |
| `quiz_hidden_answers.ipynb` | （可选，未提供） | 教师可按需从 answers 复制并折叠答案 |

## 使用方法

1. **自测**：打开 `quiz.ipynb`，按题号补全 `# TODO` 后运行，核对输出是否接近 `answers.ipynb`。
2. **作业**：完成 `assignment.md` 的 12 题，提交为 `.py` 或 `.ipynb`。
3. **课堂**：教师可用 `answers.ipynb` 现场演示；每题自带提示与参考实现。

## 建议完成顺序

1. 读 01–03 正文 → 2. `lab/` 上机 → 3. 做 `quiz.ipynb` 1–5（容易/中等） → 4. 6–10（中等/稍难） → 5. `assignment.md`（含 04 综合案例拓展）。

## 评分建议

- `quiz.ipynb` 10 题，建议占总评 10–15%；
- `assignment.md` 12 题，建议占总评 15–20%；
- 上机 `lab/` 占总评 10–15%；
- 综合案例报告（04 拓展）可作为期中/项目加分项。
