## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | `df.loc[0]` 想取第一行但索引是字符串 | `df.iloc[0]`（位置）或 `df.loc['r0']`（标签） | loc 按标签、iloc 按位置 |
| 2 | `s[0]` 取 Series 位置 | `s.iloc[0]` | 整数标签歧义，位置访问应显式 iloc |
| 3 | `df[(df.A>2) and (df.B<40)]` | `df[(df.A>2) & (df.B<40)]`（每个条件加括号） | `and`/`or` 用于 Python 布尔，`&`/`|` 用于逐元素布尔数组 |
| 4 | `df['A']` 当“单个 DataFrame” | 需要单列 DataFrame 用 `df[['A']]` | `df['A']` 返回 Series |
| 5 | `fillna(method='ffill')` | `df.ffill()` | pandas 2.x 已弃用 method 写法 |
| 6 | `dropna()` 误删有效数据 | 先 `df.isna().sum()` 看缺失情况，用 `thresh` 控制 | dropna 默认删任意含缺失的行 |
| 7 | 以为 `groupby` 返回 DataFrame | 返回 `groupby` 对象，需 `.mean()`/`.agg()` 等 | groupby 是“中间对象” |
| 8 | `pivot_table` 出现 NaN | 加 `fill_value=0` | 交叉格无数据 |
| 9 | `resample('W')` 当“滑动平均” | 降频聚合用 resample；滑窗用 `rolling(7).mean()` | 二者语义不同 |
| 10 | 用 `apply` 做可向量化运算 | `s*2+1` 优先 | apply 逐行 Python 调用，慢 |
| 11 | 修改切片后以为原数据不变 | 注意 Pandas 的视图/拷贝语义（建议对新结果 `.copy()`） | 部分切片是视图 |
| 12 | 读 Excel 报错 | 先 `pip install openpyxl` | 缺读写引擎 |

## 2. 原理级难点：loc vs iloc

```python
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s.loc['b'])     # 20（按标签）
print(s.iloc[1])      # 20（按位置）
```

- 标签是字符串时，`s[0]` 会歧义甚至报错；统一 `s.loc['b']` / `s.iloc[1]`。
- `.loc` 切片是**闭区间**（`df.loc['a':'c']` 含 c），`.iloc` 切片是**开区间**（`df.iloc[0:2]` 只含 0,1）。

## 3. 性能技巧

- **向量化优先**：能 `df['x'] * 2 + 1` 就不要 `df['x'].apply(lambda v: v*2+1)`；
- **避免在循环里逐行 `append`/`concat`**：先用列表收集再一次性 `pd.DataFrame(...)`；
- **用 `rename`/`astype` 前先想好副本**：多数方法返回新对象；
- **大文件用 `chunksize`**：`pd.read_csv('big.csv', chunksize=10_000)` 分批读；
- **时间序列避免逐元素循环**：用 `resample`/`rolling`/`shift`/`diff`；
- **用 `pd.qcut`/`cut`** 做分箱，避免手写条件判断。

## 4. 调试建议

1. 先打印 `df.head()`、`df.dtypes`、`df.shape` 确认数据形状；
2. 布尔筛选把中间掩码存成变量：`mask = (df.A > 2) & (df.B < 40); df[mask]`；
3. 用 `df.isna().sum()` 检查缺失；用 `df.duplicated().sum()` 检查重复；
4. 遇到 `KeyError` 先打印 `df.columns`；
5. 数值异常用 `df.describe()` 看 min/max/分位数；
6. 随机/抽样问题**固定种子** `rng = np.random.default_rng(42)`。
