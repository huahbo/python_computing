## 2.1 重复、缺失与异常值

### 2.1.1 处理重复

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'A': [1, 2, 2, 3, 4],
                   'B': [10, 20, 20, 30, 40],
                   'C': ['x', 'y', 'y', 'z', 'w']})
print(df)
print('重复行数:', df.duplicated().sum())
print(df.drop_duplicates())
print(df.drop_duplicates(subset=['A', 'B'], keep='last'))
```

```text
   A   B  C
0  1  10  x
1  2  20  y
2  2  20  y
3  3  30  z
4  4  40  w
重复行数: 1
   A   B  C
0  1  10  x
1  2  20  y
3  3  30  z
4  4  40  w
   A   B  C
0  1  10  x
2  2  20  y
3  3  30  z
4  4  40  w
```

> `keep='first'`（默认）保留首次出现，`keep='last'` 保留最后一次；`subset` 指定判断重复的列。

### 2.1.3 用 IQR 识别异常值

```python
df = pd.DataFrame({'Value': [1, 2, 3, 4, 100]})
Q1 = df['Value'].quantile(0.25)
Q3 = df['Value'].quantile(0.75)
IQR = Q3 - Q1
print('Q1, Q3, IQR:', Q1, Q3, IQR)
mask = (df['Value'] < Q1 - 1.5 * IQR) | (df['Value'] > Q3 + 1.5 * IQR)
print('outlier mask:', mask.tolist())
print('异常值:', df.loc[mask, 'Value'].tolist())

# 用中位数替换
df.loc[mask, 'Value'] = df['Value'].median()
print(df)
```

```text
Q1, Q3, IQR: 2.0 4.0 2.0
outlier mask: [False, False, False, False, True]
异常值: [100]
   Value
0      1
1      2
2      3
3      4
4      3
```

> 处理异常值要谨慎：异常可能携带重要信息（如真实故障/异常记录），应在了解数据背景后再决定删除、替换或保留。

## 2.2 数据规约

### 2.2.1 Min-Max 归一化

$$
X_{norm} = \frac{X - X_{min}}{X_{max} - X_{min}}
$$

```python
df = pd.DataFrame({'feature': [1, 2, 3, 4, 5]})
df['feature_norm'] = (df['feature'] - df['feature'].min()) / (df['feature'].max() - df['feature'].min())
print(df)
```

```text
   feature  feature_norm
0        1          0.00
1        2          0.25
2        3          0.50
3        4          0.75
4        5          1.00
```

### 2.2.2 Z-Score 标准化

$$
Z = \frac{X - \mu}{\sigma}
$$

```python
df['feature_std'] = (df['feature'] - df['feature'].mean()) / df['feature'].std()
print(df)
print('z均值(≈0):', df['feature_std'].mean(), 'z标准差(≈1):', df['feature_std'].std())
```

```text
   feature  feature_norm  feature_std
0        1          0.00    -1.264911
1        2          0.25    -0.632456
2        3          0.50     0.000000
3        4          0.75     0.632456
4        5          1.00     1.264911
z均值(≈0): 4.4408920985006264e-17 z标准差(≈1): 1.0
```

> 若某列标准差为 0（所有值相同），Z-Score 会除以 0；实际中可加一个小常数 `eps` 或跳过该列。Min-Max 依赖数据范围，Z-Score 不依赖具体范围，更适合近似正态的分布。

## 2.4 分组分析（groupby）

```python
df = pd.DataFrame({'Category': ['A', 'B', 'A', 'B', 'C', 'A'],
                   'Value': [10, 15, 14, 20, 5, 11]})
print(df.groupby('Category')['Value'].mean())
print(df.groupby('Category').agg({'Value': ['mean', 'sum', 'count']}))
```

> `groupby` 后可使用 `agg` 传入列表（多列多函数）或字典（列->函数）。

## 2.5 透视表（pivot_table）

```python
df = pd.DataFrame({'Category': ['A', 'A', 'B', 'B', 'C'],
                   'Year': [2020, 2020, 2021, 2021, 2022],
                   'Value': [5, 7, 3, 4, 2]})
pt = df.pivot_table(values='Value', index='Category', columns='Year',
                    aggfunc='mean', fill_value=0)
print(pt)
```

```text
Year      2020  2021  2022
Category                   
A          6.0   0.0   0.0
B          0.0   3.5   0.0
C          0.0   0.0   2.0
```

> `pivot_table` 会自动聚合重复项；`fill_value=0` 填充缺失交叉格。

## 2.6 时间序列：resample 与 rolling

```python
idx = pd.date_range('2023-01-01', periods=12, freq='D')
ts = pd.Series(np.arange(12, dtype=float), index=idx)
print(ts.resample('W').mean())       # 按周重采样取均值
print(ts.rolling(3).mean())          # 3 天滑动平均
```

```text
2023-01-01    0.0
2023-01-08    4.0
2023-01-15    9.5
Freq: W-SUN, dtype: float64
2023-01-01     NaN
2023-01-02     NaN
2023-01-03     1.0
2023-01-04     2.0
2023-01-05     3.0
2023-01-06     4.0
2023-01-07     5.0
2023-01-08     6.0
2023-01-09     7.0
2023-01-10     8.0
2023-01-11     9.0
2023-01-12    10.0

```

> `resample` 把高频率数据**聚合**成低频率（如日->周/月）；`rolling` 是在每个时间点取**滑动窗口**统计。

## 2.7 apply vs 向量化（性能提示）

```python
import time
rng = np.random.default_rng(0)
s = pd.Series(rng.normal(size=200_000))

t0 = time.perf_counter(); r1 = s.apply(lambda x: x * 2 + 1); t1 = time.perf_counter()
r2 = s * 2 + 1; t2 = time.perf_counter()
print(f'apply: {t1-t0:.4f}s   vec: {t2-t1:.4f}s')
print('结果一致:', np.allclose(r1.values, r2.values))
```

```text
apply: 0.0486s   vec: 0.0010s
结果一致: True
```

> 实测向量化比 `apply` 快约 40–50 倍。优先用列/Series 的向量化写法，只在无法向量化时才用 `apply`。

## 常见误区

1. **`fillna(method='ffill')`** 弃用：新版用 `df.ffill()`/`df.bfill()`。
2. **`dropna()` 默认删所有含缺失的行**：可用 `thresh` 控制保留条件。
3. **`groupby` 后直接 `.mean()` 会丢掉非数值列**：用 `agg` 或先选列。
4. **`pivot_table` 忘了 `fill_value`**：交叉格缺失变 NaN。
5. **`resample` 与 `rolling` 混用**：前者降频聚合，后者滑动窗口。
6. **滥用 `apply`**：能用向量化就不用 apply。
