# 第 4 章 练习题（exercises/）

> 本章练习的**唯一入口**。原 ../chapter_4_5_quiz 中与 Pandas 相关的题目已转入本目录并整理为 Pandas 专项（Matplotlib 部分归第 5 章）。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| assignment.md | 作业题（15 题） | 覆盖 Series/DataFrame 创建、loc/iloc、布尔筛选、重复/缺失/异常值（IQR）、数据规约、describe、groupby、pivot_table、merge/concat、时间序列 resample/rolling、apply vs 向量化；含提示和参考要点 |
| quiz.ipynb | 学生自测/提交版 | 25 道题（简单/中等/困难），题面 + 隐藏提示 + 空白答案单元 |
| answers.ipynb | 教学答案版 | 25 道题完整可运行答案（已在本机逐格验证通过） |

## 使用方法

1. **自测**：打开 quiz.ipynb，按题号完成代码单元，运行全部单元后对照 answers.ipynb。
2. **作业**：先不看答案完成 assignment.md 的 15 题，再对照 answers.ipynb 检查。
3. **课堂**：教师可用 answers.ipynb 现场演示；quiz 的隐藏提示可在课堂上点击展开。

## 建议完成顺序

1. 读 01–02 正文 → 2. 完成 lab/ 上机 → 3. 做 assignment.md 1–8（基础） → 4. 9–12（中档） → 5. 13–15（综合/挑战）。

## 评分建议

- quiz.ipynb 逐题人工/自动核查，建议占总评 15–20%；
- 上机 lab/ 占总评 10–15%；
- assignment.md 可作为课后作业，占 10–15%；
- 综合案例报告（../03-综合案例.md 拓展）可作为项目加分项。
