## 案例 1：SVD 低秩近似——用 3.3% 的存储量近似一张 120×120 合成图

### 目标

把一张 120×120 的合成“灰度图”看作矩阵，用 SVD 只保留前 $k$ 个奇异值，观察“压缩率 vs 重构误差”，理解 SVD 是图像压缩、PCA、数据降维的共同原理。

### 背景

一张 $m \times n$ 的灰度图可看作矩阵。SVD 给出

$$
A = U \Sigma V^T,\qquad U\in\mathbb{R}^{m\times r},\ \Sigma\in\mathbb{R}^{r\times r},\ V\in\mathbb{R}^{n\times r}
$$

只保留前 $k$ 个奇异值，得到低秩近似

$$
A_k = U_{:,1:k}\ \Sigma_{1:k,1:k}\ V_{1:k,:}^T
$$

存储量从 $m n$ 减少到 $k(m+n+1)$，当 $k\ll \min(m,n)$ 时压缩明显。

### 代码

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

# 1) 生成一张“合成灰度图”（120x120，含正弦图案、高斯亮斑与渐变）
x = np.linspace(0, 1, 120); y = np.linspace(0, 1, 120)
X, Y = np.meshgrid(x, y)
img = (np.sin(6 * X) * np.cos(6 * Y)
       + np.exp(-((X - 0.4) ** 2 + (Y - 0.6) ** 2) * 40)
       + 0.6 * X - 0.4 * Y)
img = (img - img.min()) / (img.max() - img.min())

# 2) SVD
U, S, Vt = np.linalg.svd(img, full_matrices=False)

# 3) 不同秩的重建与误差
for k in (2, 6, 20):
    A_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
    mse = np.mean((img - A_k) ** 2)
    params = k * (img.shape[0] + 1 + img.shape[1])
    print(f"rank={k:2d}  MSE={mse:.5f}  存储量={params} / 原图={img.size} "
          f"({100*params/img.size:.1f}%)")
```

### 运行结果（已运行核验）

```text
rank= 2  MSE=0.00087  存储量=482 / 原图=14400 (3.3%)
rank= 6  MSE=0.00000  存储量=1446 / 原图=14400 (10.0%)
rank=20  MSE=0.00000  存储量=4820 / 原图=14400 (33.5%)
```

![SVD 图像压缩](images/svd_compression.png)

### 讲解

- `np.linalg.svd(img, full_matrices=False)` 返回 `U (120,120)`、`S (120,)`、`Vt (120,120)`；`S` 是**奇异值向量**（降序），不是对角矩阵。
- 重构公式 `U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]`：只取前 $k$ 个奇异值对应的“列/行”，就得到最优低秩近似。
- rank=2 时仅用 3.3% 的存储量，MSE≈0.0009（肉眼几乎无差别）；rank=6 之后误差已低于打印精度。
- 为什么效果好？**自然图像的能量高度集中在前几个奇异值**（低频/整体结构），后面的奇异值对应高频细节与噪声。

### 主要用法 / API

- `np.linalg.svd(M, full_matrices=False)`：经济型 SVD；
- `np.diag(S[:k])`：把奇异值向量转成对角阵；
- `np.mean((img - A_k) ** 2)`：MSE 重构误差；
- 若要“压缩数量”，可先保存 `U[:, :k]`、`S[:k]`、`Vt[:k, :]`，用时再重建。

### 常见错误

- 直接 `U @ S @ Vt` 会报错：`S` 不是对角矩阵；
- 忘记 `full_matrices=False` 可能得到很大的 `U`/`Vt`（补全正交基），浪费内存；
- 只看 MSE 不看视觉：MSE 很低不等于“视觉无损”，反之亦然；
- 把“压缩率”理解成文件压缩率：这里的“存储量”是**矩阵元素个数**，不含编码/位深。

### 拓展

1. 用 `np.linalg.norm(img - A_k, 'fro')` 计算相对误差；
2. 对一张真实图片（PIL 读取灰度化）重复实验，观察“压缩率 vs 视觉质量”;
3. 把 `img` 换成随机噪声图，观察奇异值衰减是否还那么快？为什么？
4. 画出 `S` 的对数谱（`plt.plot(np.log10(S))`），看“能量集中在前几个奇异值”。

## 案例 2：模拟实验数据的最小二乘拟合——模型正确时能恢复参数，过拟合会在测试集原形毕露

### 目标

用“已知二次模型 + 高斯噪声”模拟一批实验数据，分别做 2 次与 5 次多项式拟合，比较**训练集**与**独立测试集**的 RMSE，体会“模型设定正确时最小二乘能恢复参数，次数越高越容易背噪声”。

### 背景

物理实验得到一组 $(x_i, y_i)$，理论公式是二次函数，但测量有噪声。用 `np.polyfit` 求 $y = a x^2 + b x + c$ 的最佳系数，并评估拟合质量。（为便于课堂复现，这里用**模拟数据**而非真实仪器读数。）

### 代码

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

np.random.seed(7)
def theory(x): return 2 * x ** 2 - 3 * x + 1

x = np.linspace(-2, 3, 40)
y = theory(x) + np.random.normal(0, 2, x.size)

def rmse(c, xx, yy):
    return np.sqrt(np.mean((np.polyval(c, xx) - yy) ** 2))

# 前 28 个点训练，后 12 个点独立测试
x_train, y_train = x[:28], y[:28]
x_test,  y_test  = x[28:], y[28:]

coef2 = np.polyfit(x_train, y_train, 2)   # 与理论模型一致
coef5 = np.polyfit(x_train, y_train, 5)   # 模型更复杂（可能过拟合）

print("train deg2 coef:", coef2)
print("train deg5 coef:", coef5)
print("RMSE train:", round(rmse(coef2, x_train, y_train), 3),
      round(rmse(coef5, x_train, y_train), 3))
print("RMSE test :", round(rmse(coef2, x_test, y_test), 3),
      round(rmse(coef5, x_test, y_test), 3))
```

### 运行结果（已运行核验）

```text
train deg2 coef: [ 1.8416 -3.4436  0.8602]
train deg5 coef: [-0.9174 -1.5886  1.2521  4.336  -2.8519  0.5595]
RMSE train: 1.967 1.646
RMSE test : 3.111 139.106
```

![polyfit 示例](images/polyfit.png)

### 讲解

- **二次拟合系数接近真实值 $(2, -3, 1)$**（1.84、-3.44、0.86，噪声不大时能恢复参数），说明“模型设定正确”时最小二乘有效；
- **五次拟合在训练集上的 RMSE 更低**（1.646 vs 1.967）——它能更紧地贴合训练数据；
- 但在**独立测试集**上：`deg2 RMSE=3.111`，而 `deg5 RMSE≈139.1`！五次多项式在训练范围外/区间间**剧烈振荡**，过拟合暴露无遗。
- 结论：**选模型/次数必须看独立测试集或交叉验证，而不是训练误差**。

### 主要用法 / API

- `np.polyfit(x, y, deg)`：最小二乘多项式系数（降幂）；
- `np.polyval(coef, x)`：多项式求值；
- `np.sqrt(np.mean((pred - y) ** 2))`：RMSE（均方根误差）；
- `np.linalg.lstsq`：更通用的最小二乘（见 03 章案例 2）。

### 常见错误

- 用训练 RMSE 选次数 → 一定选高次；
- 测试集与训练集有重叠 / 测试集太小 → 评估不可靠；
- 把“模拟数据”当成真实实验数据汇报 → 应写明数据来源与噪声假设；
- 不做残差分析，直接相信一个“很低”的测试 RMSE。

### 拓展

1. 划分训练/测试集时使用 `sklearn.model_selection.train_test_split`（随机划分，代替前 28/后 12）；
2. 用 `np.linalg.lstsq` 重写拟合，体会与 `polyfit` 的关系；
3. 打印 95% 置信区间（提示：用 `np.polyfit` 的 `cov` 参数或 `scipy.stats`）；
4. 增加 $\ell_2$ 正则（Ridge）看测试误差能否下降。
