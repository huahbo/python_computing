# 06 常见误区与技巧

> 本章为新增“查漏补缺”页：把学生最容易踩的坑集中列出，并给出正确的写法和性能技巧。

## 1. 高频误区速查表

| # | 误区 / 错误写法 | 正确做法 | 原因 |
| ---- | ---- | ---- | ---- |
| 1 | `A * B` 当矩阵乘法 | `A @ B` 或 `np.matmul(A, B)` | `*` 是逐元素乘（ufunc） |
| 2 | `np.zeros(2, 3)` | `np.zeros((2, 3))` | 形状要传元组，两个括号 |
| 3 | 以为 `reshape` 是拷贝 | 需要独立数据用 `arr.reshape(...).copy()` | 连续内存的 reshape 是视图 |
| 4 | `x[x > 0 and x < 5]` | `x[(x > 0) & (x < 5)]` | 数组布尔运算用 `&`，且加括号 |
| 5 | `len(a)` 猜数组维数 | `a.shape`、`a.ndim` | `len` 只给第一维长度 |
| 6 | 对非方阵 `np.linalg.inv` | `np.linalg.pinv` / `lstsq` | 逆只定义于方阵 |
| 7 | `np.linalg.svd(M)` 直接 `U@S@Vt` | `U @ np.diag(S) @ Vt` | `S` 是奇异值向量，不是对角阵 |
| 8 | 认为 `eig` 适用于任意矩阵 | 方阵用 `eig`，任意矩阵用 `svd` | `eig` 数学条件限制 |
| 9 | `np.random.rand` 不设种子 | `default_rng(42)` | 结果不可复现 |
| 10 | 循环里 `np.append` | 预分配数组或列表收集 | 每次 append 都会新建数组 |
| 11 | 混淆 `axis=0/1` | 记“消除哪一维就写哪一维” | `sum(axis=0)` 消行得列统计 |
| 12 | 用 `astype` 想“改原数组” | `arr.astype` 返回新数组；原地改 dtype 不可直接 | 类型转换是拷贝 |

## 2. 原理级难点：视图 vs 拷贝

```python
a = np.arange(6)
b = a.reshape(2, 3)     # 视图
b[0, 0] = 99
print(a[0])             # 99

c = a.copy()
c[0] = 0                # 不影响 a
```

判断是否共享内存：

```python
b.base is a              # True → 视图
np.may_share_memory(a, b)  # 更稳的检查
```

**为什么重要**：视图省内存、速度快；但并发修改或函数返回到别人手里时容易“隐形改数据”。对外返回数据前，若不想共享，显式 `.copy()`。

## 3. 广播规则速记

1. 从右往左对齐；
2. 相同或一方为 1 → 兼容；
3. 全部兼容 → 结果为各维最大；否则 `ValueError`。

```python
A = np.zeros((4, 1, 6))
B = np.zeros((3, 6))
try:
    print((A + B).shape)     # (4, 3, 6)，B 自动补成 (1,3,6)
except ValueError as e:
    print("广播失败：", e)
```

> 注意：`(3,) + (4,)` 不兼容；`(3,1) + (3,)` 也不兼容（末尾 1 vs 3）。想“列向量与行向量做外积”要用 `(3,1) + (1,3)`。

## 4. 性能技巧

- **向量化优先**：能一次 `a[np.newaxis, :] + b[:, np.newaxis]` 就不要双重循环；
- **`out=` 原地计算**：`np.add(a, b, out=a)` 避免额外分配；
- **`in-place` 算术**：`a += b`（注意类型安全）；
- **`einsum` 表达张量收缩**：`np.einsum('ik,kj->ij', A, B)` 既是矩阵乘，也能表达更复杂收缩且减少中间数组；
- **`np.lib.stride_tricks.sliding_window_view`** 做滑窗（移动平均/卷积）时避免显式复制：
  ```python
  x = np.arange(10)
  w = np.lib.stride_tricks.sliding_window_view(x, 3)
  print(w.mean(axis=1))   # 窗口大小为 3 的移动平均
  ```
- **大数组用 `np.savez_compressed`** 存储；文本 `savetxt` 慢且丢精度。

## 5. 调试建议

1. 出错先打印 `shape` / `dtype`，再用 `np.allclose` 比较；
2. 用 `np.set_printoptions(precision=4, suppress=True)` 让输出可读；
3. 复杂布尔条件拆成中间变量（`mask1 = ...; mask2 = ...`）；
4. 随机/拟合问题**固定种子**，便于复现与讨论；
5. 用 `np.isnan` / `np.isinf` 检查异常值。
