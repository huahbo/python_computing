## 4.1 多项式的构造与运算

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

# 2x^2 + 3x + 1
p = np.poly1d([2, 3, 1])
print(p)          # 2 x^2 + 3 x + 1
print(p(5))       # 66
```

### 4.1.1 四则运算

```python
p = np.poly1d([2, 3, 1])       # 2x^2+3x+1
q = np.poly1d([1, -1])         # x - 1

print(p + q)      # 加法
print(p - q)      # 减法
print(p * q)      # 乘法（系数卷积）
quotient, remainder = p / q    # poly1d 直接除返回 (商, 余数) 元组
print(quotient)
print(remainder)
```

### 4.1.2 求导与积分

```python
p = np.poly1d([2, 3, 1])
print(p.deriv())      # 4x + 3
print(p.deriv(2))     # 二阶导
print(p.integ())      # 0.6667x^3 + 1.5x^2 + x（常数默认为 0）
print(p.integ(m=2))   # 二重积分
```

### 4.1.3 系数与求根

```python
p = np.poly1d([1, -3, 2])     # x^2 - 3x + 2
print(p.coeffs)               # [ 1. -3.  2.]
print(p.c)                    # 按降幂的系数
np.roots(p)                   # [2. 1.]
```

> `np.roots` 也支持直接传系数数组：`np.roots([1, -3, 2])`。

## 4.2 最小二乘拟合：polyfit

```python
x = np.array([0, 1, 2, 3, 4], dtype=float)
y = np.array([1, 2, 9, 28, 65], dtype=float)   # 恰好是 x^3 + 1

coef = np.polyfit(x, y, 3)       # 3 次多项式最小二乘
print(np.round(coef, 4))         # [ 1.  0. -0.  1.]（浮点误差约 1e-14）
p = np.poly1d(coef)
print("p(2.5) =", round(np.polyval(coef, 2.5), 4))   # 16.625
```

**含噪声数据的拟合与过拟合**：

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(7)
def f(x): return 2 * x ** 2 - 3 * x + 1
x = np.linspace(-2, 3, 40)
y = f(x) + np.random.normal(0, 2, x.size)

for deg in (1, 3, 5):
    coef = np.polyfit(x, y, deg)
    print(deg, ":", np.round(coef, 4))

xs = np.linspace(-2, 3, 200)
plt.scatter(x, y, s=16, label="data")
for deg, c, ls in [(1, "grey", "--"), (3, "orange", "-."), (5, "green", "-")]:
    plt.plot(xs, np.polyval(np.polyfit(x, y, deg), xs), c=c, ls=ls, label=f"deg {deg}")
plt.legend(); plt.savefig("poly_fit_demo.png")
```

![polyfit 示例](images/polyfit.png)

**观察**：次数越高，拟合曲线越可能贴近噪声（过拟合）；次数过低则拟合不足。选择次数可用交叉验证或残差分析，而不是盲目升高次数。

## 4.3 新版多项式接口（了解）

NumPy 1.x 之后的 `np.polynomial` 提供更现代、更稳定的 `Polynomial` / `Chebyshev` 等类：

```python
from numpy.polynomial import Polynomial
p = Polynomial([1, 3, 2])     # 注意：系数从常数项开始！
print(p(2))                   # 1 + 3*2 + 2*2^2 = 15
print(p.roots())
```

> `np.poly1d` 是旧接口（系数降幂、基于 `np.poly`），大量教程/教材仍在使用；新代码可优先考虑 `np.polynomial`。本讲义两者都给出，以兼容常见场景。

## 案例卡 1：噪声数据的“多项式拟合 + 训练/测试误差”——一次、二次、五次对比

### 目标

对“已知二次函数 + 正态噪声”的数据分别用 1、2、5 次多项式拟合，比较训练集与独立测试集的 RMSE，直观看到**次数越高不代表越好**。

### 代码

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

rng = np.random.default_rng(7)
def f(x): return 2 * x ** 2 - 3 * x + 1

x = np.linspace(-2, 3, 40)
y = f(x) + rng.normal(0, 2, x.size)

def rmse(coef, xx, yy):
    return np.sqrt(np.mean((np.polyval(coef, xx) - yy) ** 2))

# 全量看一眼系数
for deg in (1, 2, 5):
    print("deg", deg, "coef:", np.round(np.polyfit(x, y, deg), 4))

# 前 28 个点训练，后 12 个点独立测试
x_train, y_train = x[:28], y[:28]
x_test,  y_test  = x[28:], y[28:]
for deg in (1, 2, 5):
    c = np.polyfit(x_train, y_train, deg)
    print(f"deg={deg}  train RMSE={rmse(c, x_train, y_train):.3f}  test RMSE={rmse(c, x_test, y_test):.3f}")
```

### 运行结果（已运行核验）

```text
deg 1 coef: [-1.0864  4.1331]
deg 2 coef: [ 2.2266 -3.313  -0.1869]
deg 5 coef: [-0.0503  0.0661  0.4681  1.8231 -4.2196  0.0869]
deg=1  train RMSE=2.395  test RMSE=14.206
deg=2  train RMSE=1.578  test RMSE=2.936
deg=5  train RMSE=1.428  test RMSE=98.279
```

### 讲解

- **一次**：欠拟合，训练/测试误差都大（模型太简单）；
- **二次**：正好对应当前模型，训练误差略高于五次，但测试误差最小（2.936）——**选对模型**；
- **五次**：训练误差最低（1.428）但测试误差暴增到 98.279——**过拟合**，它在“背噪声”。
- 结论：**选次数必须看独立测试集/交叉验证，而不是训练误差**。

### 主要用法 / API

- `np.polyfit(x, y, deg)`：最小二乘多项式系数（降幂）；
- `np.polyval(coef, x)`：用系数在 `x` 处求值；
- `np.poly1d(coef)`：包装成多项式对象，支持 `deriv()`/`integ()`/`roots()`；
- `np.polynomial.Polynomial`：新版接口（系数常数项在前）。

### 常见错误

- 系数顺序搞反：`poly1d([a, b, c])` 表示 $a x^2 + b x + c$；`Polynomial` 是常数项在前；
- 用“训练集 RMSE 最小”选模型 → 必然选最高次，必须用测试集/交叉验证；
- 数据点少于或等于次数时，多项式会“精确穿过所有点”（插值），此时训练误差为 0 但毫无预测能力。

### 拓展

- 用 `np.linalg.lstsq` 重写上面的拟合，体会 `polyfit` 只是它的特例；
- 用 `sklearn.model_selection.train_test_split` 随机划分训练/测试集，重复 10 次看 RMSE 分布；
- 给 5 次拟合加 $\ell_2$ 正则（岭回归），观察测试误差如何变化。

## 常见误区

1. **系数顺序搞反**：`poly1d([a, b, c])` 表示 $a x^2 + b x + c$；`np.polynomial.Polynomial` 则是常数项在前。
2. **`polyfit` 次数过高**：数据少时高次多项式会震荡/过拟合。
3. **忘记噪声与残差**：拟合不是“解释唯一真理”，要报告残差与预测区间。
4. **把 `polyfit` 当精确解**：它是数值最小二乘，数据含噪声时系数有误差。
5. **直接用 `np.polyval` 外推太远**：多项式在训练范围外可能剧烈振荡。
