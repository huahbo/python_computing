# 第 1 章 教学说明（教师用）

> 面向授课教师：课时建议、重点难点、上机安排、考核建议。学生无需阅读本页。

## 1. 教学目标

- 让学生**会查官方文档**并独立写出正确的 NumPy 代码；
- 建立“ndarray 是连续内存、形状驱动运算”的心智模型；
- 能够用 NumPy 独立完成：数据整理、统计、解方程组、拟合、简单分解。

## 3. 重点与难点

### 重点
- ndarray 的 dtype / shape / 视图语义；
- 广播规则与 shape 兼容判断；
- `*` vs `@`；`axis` 方向；
- `solve` / `lstsq` / `svd` / `polyfit` 的适用条件。

### 难点（学生常卡）
- 视图 vs 拷贝：建议用 `base` 与 `may_share_memory` 课堂演示；
- 广播：给出 `(4,1,6)+(3,6)` 让学生手工推导；
- `axis`：用 3×4 成绩矩阵现场数“消行得列”；
- 病态方程与条件数：用 `cond_sensitivity.png` 讲数值稳定性；
- 过拟合：用 05 案例的 deg2 vs deg5 测试 RMSE（3.11 vs 139.1）直观展示。

## 4. 上机（lab/）使用建议

- 每部分 10–15 分钟；要求每格代码都运行并记录输出；
- 综合任务（SVD 压缩）可小组完成；
- 教师可在 lab 基础上增加“隐藏检查点”用来回收（如最终数组形状断言）。

## 5. 作业与考核建议

- **平时**：exercises 20 题（quiz.ipynb 自动评分）；
- **上机**：lab.ipynb 完成情况 + 05 拓展任务；
- **期中/期末融合**：把 NumPy 知识点并入第 8 章 sklearn 或期末大作业（e.g. 特征标准化、矩阵运算）。

## 6. 易错点清单（直接用于出题）

1. `np.zeros(2, 3)` 报错（应为元组）；
2. 误以为 `reshape` 是拷贝；
3. `A * B` 与 `A @ B`；
4. `x[(x>0) & (x<5)]` 的括号；
5. `np.linalg.svd` 返回的 `S` 是向量；
6. `np.poly1d` 与 `np.polynomial.Polynomial` 系数顺序不同。
