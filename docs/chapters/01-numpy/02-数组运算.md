## 2.1 向量的运算

### 2.1.1 逐元素操作

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

v = np.array([2, 3])
w = np.array([3, 1])
print(v + w)     # [5 4]
print(v - w)     # [-1  2]
print(2 * v)     # [4 6]
print(v * w)     # 逐元素乘 [6 3]
print(v / w)     # 逐元素除 [0.6667 3.    ]
print(v ** 2)    # 逐元素平方 [4 9]
```

![向量运算示意](images/vector_ops.png)

### 2.1.2 数量积（点积）与叉积

```python
a = np.array([1, 2])
b = np.array([3, 4])
print(np.dot(a, b))      # 1*3 + 2*4 = 11
print(a @ b)             # 向量点积同样可用 @

c = np.array([1, 2, 3])
d = np.array([4, 5, 6])
print(np.cross(c, d))    # [-3  6 -3]
```

### 2.1.3 向量的范数

```python
x = np.array([3, 4])
np.linalg.norm(x)        # 5.0（默认 2-范数）
np.linalg.norm(x, ord=1) # 7.0（1-范数）
```

### 2.1.4 排序

```python
a = np.array([3, 1, 2])
np.sort(a)          # 返回新数组 [1 2 3]
a.sort()            # 原地排序
np.argsort(a)       # 排序后原索引
```

## 2.2 向量/矩阵的逻辑运算——筛选

```python
x = np.array([1, -2, 3, -4, 5])

print(x[x > 0])              # [1 3 5]
print(x[(x > 1) & (x < 5)])  # [3]
print(np.where(x > 0, x, 0)) # [1 0 3 0 5]
```

二维按行筛选：

```python
m = np.array([[1, 9], [6, 2], [7, 8]])
print(m[(m[:, 0] > 3) & (m[:, 1] < 9)])   # [[6 2] [7 8]]
```

> 组合条件必须加括号，且不能用 `and` / `or`，要用 `&` / `|` / `~`。

## 2.3 矩阵的运算

### 2.3.1 算术运算

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A + B)      # 矩阵加法
print(A - B)      # 矩阵减法
print(A * B)      # 注意：逐元素乘
print(A @ B)      # √ 矩阵乘
print(np.matmul(A, B))   # 同 @
```

**为什么 `*` 不是矩阵乘**：NumPy 中 `*` 是 `ufunc` 的逐元素运算；要数学上的矩阵乘法，用 `@`（或 `np.dot` / `np.matmul`，二者在 2D 下等价，但 `@` 语义更明确）。

### 2.3.2 矩阵上的统计

```python
S = np.array([[85, 90, 80],
              [78, 85, 90],
              [90, 95, 85]])

S.sum(axis=0)      # 每列和 [253 270 255]（三门课总分）
S.sum(axis=1)      # 每行和 [255 253 270]（每个学生总分）
S.mean(axis=0)     # 每列均值
S.max(axis=1)      # 每行最大值
S.std()            # 全体标准差
```

记忆：`axis=0` 表示“沿第 0 轴（行方向）折叠”，即求**每列**的统计量；`axis=1` 求**每行**。

### 2.3.3 查找（where / argmax）

```python
m = np.array([[3, 7], [9, 2]])
np.where(m > 5)          # (array([0,1]), array([1,0])) 坐标
np.argmax(m)             # 展平后的最大索引 2 → (1,0)
np.argmax(m, axis=1)     # 每行最大索引 [1 0]
```

## 2.4 结果的保存与读取

```python
a = np.array([[1, 2], [3, 4]])

np.savetxt("result.txt", a, fmt="%.2f", delimiter=",")
b = np.loadtxt("result.txt", delimiter=",")

np.save("a.npy", a)      # 二进制（推荐：更快、保留 dtype）
c = np.load("a.npy")

np.savez_compressed("data.npz", x=a, y=b)
d = np.load("data.npz")
d["x"], d["y"]
```

> 文本格式 `savetxt` 直观但慢、且可能丢精度；大数组优先二进制 `np.save`/`np.savez_compressed`。

## 案例卡 1：传感器滑动平均——滑窗视图与向量化

### 目标

对一串传感器读数做“窗口大小为 3”的移动平均，用 `numpy.lib.stride_tricks.sliding_window_view` 一步生成全部窗口，避免显式 `for` 循环。

### 代码

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

x = np.array([1.0, 3.0, 2.0, 5.0, 4.0, 6.0, 2.0])

# sliding_window_view 返回“视图”（不复制数据），形状 = 原长 - 窗口 + 1
w = np.lib.stride_tricks.sliding_window_view(x, 3)
print("窗口矩阵:")
print(w)
print("移动平均:", w.mean(axis=1))
```

### 运行结果（已运行核验）

```text
窗口矩阵:
[[1. 3. 2.]
 [3. 2. 5.]
 [2. 5. 4.]
 [5. 4. 6.]
 [4. 6. 2.]]
移动平均: [2.     3.3333 3.6667 5.     4.    ]
```

### 讲解

- `sliding_window_view(x, 3)` 得到 `(5, 3)` 的窗口矩阵：第 i 行 = `x[i:i+3]`。
- `w.mean(axis=1)` 对每行（每个窗口）求均值，即移动平均。
- 这是**视图**，不复制数据；适合窗口大、数据长的场景。

### 主要用法 / API

- `numpy.lib.stride_tricks.sliding_window_view(a, window_size)`；
- 配合 `mean`/`std`/`diff` 等做平滑、差分、局部统计；
- 需要“截断首尾”时用 `np.convolve` 或 `pandas.Series.rolling`。

### 常见错误

- 忘记这是视图，修改窗口会改原数组；
- 把它当“卷积”：窗口求均值与卷积核为 `1/w` 的卷积在边界处理上不同；
- 对 `mean(axis=1)` 写成 `axis=0`，得到每列统计。

### 拓展

- 改成“指数加权移动平均”（提示：`np.convolve` + 权重向量）；
- 对二维图像做 3×3 局部均值滤波（提示：两层滑窗）。

## 案例卡 2：成绩排名与补考改分——argsort / where

### 目标

给一组成绩排名（从高到低），并把不及格（< 62）的学生分数改为 65。核心是 `argsort` 的“索引排序”和 `np.where` 的条件替换。

### 代码

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

scores = np.array([85, 92, 78, 60, 95, 88])

# argsort(-scores)：分数取负后从小到大排，等价于原分数从大到小的索引
order = np.argsort(-scores)

# 为每位学生计算名次（1 表示最高分）
ranks = np.empty(6, dtype=int)
ranks[order] = np.arange(1, 7)

print("从高到低:", scores[order])
print("每位学生的排名(对应原位置):", ranks)

# 条件替换：< 62 的分数补考改成 65
fixed = np.where(scores < 62, 65, scores)
print("60 分补考为 65 后:", fixed)
```

### 运行结果（已运行核验）

```text
从高到低: [95 92 88 85 78 60]
每位学生的排名(对应原位置): [4 2 5 6 1 3]
60 分补考为 65 后: [85 92 78 65 95 88]
```

### 讲解

- `np.argsort(-scores)` 返回“排序后的原索引”：`order[0]` 是最高分所在位置。
- `scores[order]` 按 `order` 重新取值，就得到从高到低的成绩序列。
- 排名时：`ranks[order] = np.arange(1, 7)`，意思是“第 1 名放在 order[0] 的位置”，这是 NumPy 里“按位置反填”的常用技巧。
- `np.where(cond, a, b)` 等价于“条件成立取 a，否则取 b”，但对数组**逐元素**执行。

### 主要用法 / API

- `np.argsort(a)`：升序索引；`np.argsort(-a)`：降序索引；
- `np.where(cond, x, y)`：条件替换/筛选；
- `np.sort(a)` 返回新数组，`a.sort()` 原地排序；
- 简化排名可用 `scipy.stats.rankdata` 或 `pandas.Series.rank`。

### 常见错误

- 混淆 `np.sort` 与 `np.argsort`：前者给排序后的值，后者给排序后的索引；
- 用 `scores[scores < 62] = 65` 也能改分，但 `np.where` 写法更显式、且不改变原数组；
- 排名时正序/逆序写反。

### 拓展

- 若有并列分数，如何让并列者名次相同（提示：研究 `scipy.stats.rankdata` 的 `method`）；
- 按“数学成绩”排名后只输出前 3 名学生名单。

## 案例卡 3：成绩表另存与回读——文本与二进制

### 目标

把学生成绩矩阵保存成 `CSV`（文本）与 `.npz`（二进制压缩），再读回来，比较两种方式。

### 代码

```python
import numpy as np

data = np.array([[85, 92, 78], [67, 73, 60]], dtype=int)

# 文本：CSV，可被 Excel 打开
np.savetxt("_numpy_scores.csv", data, fmt="%d", delimiter=",")
loaded = np.loadtxt("_numpy_scores.csv", delimiter=",")

# 二进制：更快、保留 dtype，且可压缩多个数组
np.savez_compressed("_numpy_scores.npz", data=data)
d = np.load("_numpy_scores.npz")

print("loadtxt:")
print(loaded)
print("npz data:")
print(d["data"])
```

### 运行结果（已运行核验）

```text
loadtxt:
[[85. 92. 78.]
 [67. 73. 60.]]
npz data:
[[85 92 78]
 [67 73 60]]
```

### 讲解

- `np.savetxt` 输出文本，`fmt="%d"` 保证整数格式；`loadtxt` 读回后默认转成 `float64`。
- `np.savez_compressed` 把多个数组打进一个 `.npz`，读回用 `d["data"]`；保留 `dtype`，且体积更小、速度更快。
- 实际项目中：**中间结果用二进制 npz 快存快取；给 Excel/同学看的导出 CSV**。

### 主要用法 / API

- `np.savetxt(path, a, fmt=..., delimiter=...)` / `np.loadtxt(path, delimiter=...)`；
- `np.save` / `np.load`（单数组 .npy）；
- `np.savez_compressed` / `np.load`（多数组 .npz）。

### 常见错误

- `savetxt` 对高精度 float 默认保留 `%.18e`，导致文件很大且不可读——指定 `fmt`；
- `loadtxt` 读文本遇到表头会报错，表头用 `skiprows=1`；
- 用 `np.savez_compressed` 后忘记用 `d["key"]` 取出，直接 `print(d)` 只能看到键。

### 拓展

- 把 CSV 读成“带表头 + 中文列名”的表格，应改用 `pandas.read_csv`（第 4 章）；
- 逐列比较二进制与文本读回的精度差异。

## 常见误区

1. **`*` 与 `@` 混用**：`A * B` 是逐元素乘；数学矩阵乘必须 `@`。
2. **axis 方向记反**：`sum(axis=0)` 是“消除第 0 维”，得到每列结果。
3. **条件用 `and`/`or`**：数组布尔运算必须 `&`/`|`，且每个条件加括号。
4. **反复 `np.append`**：每次产生新数组，大数组循环中极慢；先估算容量或用列表。
5. **`np.dot` 语义在多维下容易混淆**：明确用 `@` 更直观。
6. **用 `np.save` 存文本**：二进制文件没有扩展名也可以 `np.load`，但 CSV 用 `savetxt` 再 `loadtxt`。
