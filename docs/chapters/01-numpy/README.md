> 本页是第 1 章的**章首页（索引）**。正文位于 `01-数组基础.md` ~ `06-常见误区与技巧.md`，与原版资料完全分离（原版见 `../../原始资料/`）。

## 本章概览

NumPy 是 Python 科学计算的地基：它用高效的 `ndarray`（N 维数组）统一表示向量、矩阵和张量，并用 C 语言实现底层计算，速度远快于纯 Python 列表。本章将带你从“创建一个数组”走到“解线性方程组、做矩阵分解、拟合多项式”，为后续 SymPy、SciPy、Pandas、Matplotlib、NetworkX、Statsmodels、scikit-learn 各章打下基础。

## 学习目标

学完本章，你应该能够：

1. 创建并操作 NumPy 数组，理解 `ndarray` 的属性（`shape`、`ndim`、`dtype`、`size`）。
2. 熟练使用索引、切片、花式索引、布尔掩码，并理解**视图 vs 拷贝**的区别。
3. 掌握广播（broadcasting）规则，能判断两个形状是否可广播。
4. 完成向量/矩阵的算术、逻辑、统计运算，正确区分 `*` 与 `@`。
5. 使用 `numpy.linalg` 求解线性方程组、计算范数/秩/行列式，进行特征值分解、SVD、Cholesky、QR 分解。
6. 用 `poly1d` / `polyfit` 做多项式运算与最小二乘拟合。
7. 用随机数生成器（`default_rng`）生成可复现的随机数组。
8. 完成一个综合小案例（如 SVD 图像压缩），体会 NumPy 在真实数据上的用法。
