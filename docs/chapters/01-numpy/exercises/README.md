# 第 1 章 练习题（exercises/）

> 本章练习的**唯一入口**。原有历史版本保存在 `../../原始资料/chap1/assignment/`，仅作存档。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `assignment.md` | 作业题（20 题） | 覆盖 dtype、创建、reshape、视图拷贝、广播、高级索引、布尔掩码、ufunc、矩阵乘法、条件数、特征值/SVD、广播内存、NaN、argsort、I/O、结构化数组、stride、向量化、广播陷阱、移动平均；含详细答案解析 |
| `quiz.ipynb` | 学生自测/提交版 | 题面 + 空白答案单元 + **自动评分**（`_GRADES`） |
| `answers.ipynb` | 教学答案版 | 每题含提示 + 可展开答案 + 自动评分 |
| `quiz_hidden_answers.ipynb` | 隐藏答案版 | 与教学版相同但答案折叠默认隐藏，可用于课堂随机抽查 |

## 使用方法

1. **作业**：打开 `quiz.ipynb`，按题号完成 `YOUR ANSWER HERE` 单元，运行全部单元后查看 `_GRADES` 汇总。
2. **自测**：先不看答案完成 `assignment.md` 的 20 题，再用 `answers.ipynb` 对照。
3. **课堂**：教师可用 `quiz_hidden_answers.ipynb` 现场演示；每题自带提示与自动测试。

## 建议完成顺序

1. 读 01–04 正文 → 2. `lab/` 上机 → 3. 做 `assignment.md` 1–8（易） → 4. 9–15（中） → 5. 16–20（难/挑战）。

## 可选增补题（教师视情况布置）

1. **滑窗移动平均**：用 `np.lib.stride_tricks.sliding_window_view` 实现 `moving_average(arr, k)`，与 `np.convolve` 结果比较。
2. **广播陷阱排查**：构造一个“列向量 `(3,1)` 与行向量 `(3,)` 相加”的例子，说明为什么结果不对，并给出正确写法。
3. **SVD 压缩实践**：读入 05 综合案例的合成图（或任意灰度图），画出“压缩率 vs MSE”曲线，写 3 句结论。
