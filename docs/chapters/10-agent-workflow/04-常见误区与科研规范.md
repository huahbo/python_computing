# 04 常见误区与科研规范

> 本节是第二部分的方法收口：先列出最常见的 12 个误区，再给出可执行的科研规范（AI 使用声明、可复现三件套、学术诚信红线）。

## 本节目标

1. 识别 12 个常见误区，并说出对应的纠正做法；
2. 会写一份合格的 **AI 使用声明**；
3. 掌握可复现三件套（版本锁定、随机种子、环境记录）；
4. 明确学术诚信的允许与禁止边界，以及"什么时候不该用 Agent"。

## 4.1 十二个常见误区

| # | 误区 | 典型表现 | 纠正做法 |
| ---- | ---- | ---- | ---- |
| 1 | 把 Agent 当搜索引擎 | 只问"怎么做"，不干活 | 给任务卡与判据，让它执行并自证 |
| 2 | 不给验收标准 | "帮我优化一下" | 任务卡六件套，判据可执行 |
| 3 | 一次要求改太多 | 一句话让它重构整个项目 | 拆成多轮，每轮一个目标 |
| 4 | 不看 diff 就接受 | 直接 `git commit` | 每步看 `git diff`，确认范围 |
| 5 | 用"跑通"代替"正确" | 脚本能跑就算完 | 对照判据库，跑断言 |
| 6 | 盲信图表 | 图好看就下结论 | 检查坐标轴、单位、样本量、异常点 |
| 7 | 忘记固定种子 | 别人复现不了 | `np.random.default_rng(42)`，写进 AGENTS.md |
| 8 | 忘记记录版本 | 三个月后无法复现 | 记录 Python/库/dsh 版本（可复现三件套） |
| 9 | 把 Key 写进 notebook | 提交时泄漏 | 用凭据文件；提交前 `git status` 检查 |
| 10 | 让它直接改原始数据 | `data/` 被就地覆盖 | 原始数据只读，输出写到 output/ |
| 11 | 评审缺位 | 自己写、自己评、自己签 | 引入评审代理或同学互评 |
| 12 | 把隐私数据贴进对话 | 成绩单、手机号、医疗记录 | 脱敏或本地处理；红线不可越 |

## 4.2 AI 使用声明（模板）

提交作业与报告时附上，逐条填写（不能只写"使用了 AI 辅助"）：

```text
## AI 使用声明
1. 使用的工具与版本：DeepSeek Harness <版本>，模型 <deepseek-flash / deepseek-v4-pro>，日期 <YYYY-MM-DD>
2. 使用环节：□环境搭建 □代码编写 □调试排错 □数据分析 □图表 □文字润色 □其他：____
3. 关键提示词：附 2–3 条最能代表工作方式的提示词（或随附 /export 的会话记录）
4. 人工修改：说明你对 AI 产出做了哪些实质性修改（至少 3 条）
5. 验证方式：列出你运行的断言/复核（如行数守恒、交叉验证、与手算对照）
6. 未使用 AI 的部分：问题定义、结论、报告正文（按课程要求勾选）
7. 我确认：最终提交内容由我负责，AI 产出已逐条核验。
```

## 4.3 可复现三件套

| 要素 | 做法 | 检查方式 |
| ---- | ---- | ---- |
| 版本锁定 | 记录 Python 与小包版本；dsh 记录基线版本（见 `docs/build/dsh_version.yaml`） | 报告里列出 `python -V`、关键库版本、dsh `--version` |
| 随机种子 | 所有随机过程固定种子并写进 AGENTS.md | 两次重跑结果一致（断言 `np.allclose`） |
| 环境记录 | 依赖文件（environment.yml / requirements.txt）+ 运行命令 | 换机器按文件能跑通 |

## 4.4 学术诚信：允许与禁止

| 允许（鼓励） | 禁止 |
| ---- | ---- |
| 用 Agent 解释报错、查文档、写样板代码 | 直接提交 AI 产出而不核验 |
| 用它生成测试、补边界条件，你审 diff | 伪造数据、伪造运行结果 |
| 用它做初步分析，你复核统计结论 | 把 AI 生成的参考文献当作真实文献引用 |
| 在声明中如实记录使用过程 | 隐瞒使用（课程明确要求声明时） |

> 判断标准：**"如果老师问我这条结论是怎么来的，我能完整讲清楚并复现吗？"**

## 4.5 什么时候不该用 Agent

- 一行代码、明确的小改动：自己写更快；
- 涉及未发表/涉密数据，且没有合规的本地方案；
- 你已经知道答案、只是想要"确认"：请用文档或同学互评；
- 时间紧到没空验收：没有验收的 AI 产出，风险高于收益。

## 本节小结

1. 12 个误区可以归纳为两条：不给判据、不做验收；
2. AI 使用声明要具体到版本、环节、提示词、修改与验证；
3. 可复现三件套：版本、种子、环境；
4. 学术诚信的底线是"能讲清楚、能复现、能负责"。

## 思考题

3. 如果课程不允许使用 AI，但你已经用了，应该怎么处理？
