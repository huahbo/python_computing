# 10. Agent 工作流与验证方法

> 本页是第二部分第 10 章的章首页。上一章回答"它是什么、怎么装"，本章回答"**怎么干才靠谱**"。

## 本章概览

Agent 编程的成败，很少取决于模型强弱，而取决于**方法与验证**：有没有把项目规范写进 `AGENTS.md`、复杂任务有没有先出计划、有没有把"什么叫做对"写成可执行的判据、关键结论有没有第二双眼睛。

本章把这套方法固化成可重复的操作流程，并在最后一节给出科研规范与学术诚信要求（AI 使用声明）。

## 学习目标

1. 会写最小可用的 `AGENTS.md`，把项目约定变成常驻指令；
2. 会用计划模式推进复杂任务，并用"小步执行 + 逐步验证"控制返工；
3. 会用**任务卡六件套**（目标、约束、验收标准、证据、复核、提交）描述任务；
4. 会为科学计算任务写出**可执行的验收标准**，并用断言把结论钉死；
5. 知道什么时候该派子代理、什么时候纯属浪费；
6. 说出 12 条常见误区，并按规范提交 AI 使用声明。
