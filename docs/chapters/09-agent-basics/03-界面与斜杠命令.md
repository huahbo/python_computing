# 03 界面与斜杠命令

> 本节解决"装好之后怎么用"：Web 界面在哪里、斜杠命令怎么用、哪些操作**不经过模型**。
> 基线版本：dsh 0.1.5-rc.2（2026-09-10）；命令清单与菜单分组随版本变化，权威说明见官方文档站。

## 本节目标

1. 认识 Web 界面的主要区域：工作区、会话、设置（模型）、权限指示；
2. 理解斜杠命令与普通对话的**本质区别**：命令在本地执行，不会变成模型消息；
3. 掌握 8 条常用命令的语法与使用时机；
4. 知道哪些入口**没有**命令面（headless、SDK、ACP）。

## 先修

- 02 节：已经装好 dsh，并完成模型与 API Key 配置。

## 3.1 界面导览（Web 版）

| 区域 | 位置 | 作用 |
| ---- | ---- | ---- |
| 工作区选择 | 首屏 / 左侧 | Agent 能读写的目录边界；**没选工作区时输入框不可用** |
| 会话区 | 中间 | 对话、工具调用与结果的流水账（这就是"证据链"） |
| 输入框 | 底部 | 输入任务；点 + 按钮或输入斜杠打开同一个菜单 |
| 设置 → 模型 | 右上 | 选择模型、填 API Key、切换推理等级 |
| 权限指示 | 会话附近 | 当前权限档位；触发写文件或命令时会弹出审批 |

输入框的 + 菜单与斜杠菜单是同一个（各版本措辞可能不同），分两段：

- **Add**：File（把工作区文件加入上下文）、Goal、Plan、Feedback；
- **Commands**：Compact、Permission、Model、Export。

## 3.2 斜杠命令是什么：不经过模型的控制面板

普通对话会作为消息进入模型上下文；**斜杠命令在本地直接执行**，命令本身与执行结果默认不会变成模型消息（因此也不消耗 token）。

命令行的语法固定：斜杠开头 + 小写名称（字母、数字、下划线、连字符）+ 空格 + 参数。名称后面的全部内容都是该命令自己的参数（各命令语法不同）。

> 重要限制：**命令面只在交互式界面（Web / CLI）存在**。用 headless 模式跑脚本、或通过 SDK / ACP 集成时没有这套命令，需要在提示词里用自然语言表达需求。

## 3.3 速查表（基线 v0.1.5-rc.2）

| 命令 | 语法 | 作用 | 什么时候用 |
| ---- | ---- | ---- | ---- |
| /compact | 无参数 | 压缩较早的会话历史 | 会话很长、开始变慢或答非所问时 |
| /plan | /plan [off\|message]，支持附件 | 进入或退出计划模式 | 多文件改动、动数据之前 |
| /goal | /goal [目标\|clear\|edit 目标\|pause\|resume] | 设定或查看长任务目标 | 跨多轮的长任务（论文复现、项目开发） |
| /feedback | /feedback 文本 | 记录对本次会话的反馈 | 发现工具不好用、想留改进线索 |
| /export | 无参数（仅 Web） | 把会话日志打包成 ZIP 下载 | **交作业**、留档、复盘 |
| /model | 打开弹窗 | 切换模型与推理等级 | 想省钱（换 flash）或想更强推理（换 pro） |
| /permission | 打开弹窗 | 切换权限档位 | 先只读审视，再放开写 |
| /file | 打开文件选择 | 把工作区文件加入上下文 | 想让 Agent 只看某个文件时 |

> 时效内容：命令名与菜单分组由插件提供，可能随版本增删。请用斜杠菜单查看当前版本的实际清单；升级后复核本表。

## 3.4 三个真实用法示例

**示例 1：先计划、再立目标（大任务开场）**

```text
/plan 帮我用 sklearn 的 wine 数据做一个分类小项目，先给我计划，不要动手
（看完计划、确认没问题后）
/goal 完成 wine 分类小项目：脚本 + 5 折交叉验证 + 报告
```

要点：`/plan` 只负责先看计划，`/goal` 负责记住目标，两者都不需要额外对话轮次去解释。

**示例 2：会话太长，先压缩再继续**

```text
/compact
（然后继续提要求）请把刚才的 verify.py 补上数据泄漏检查
```

要点：压缩会丢失部分细节，**重要结论要写进工作区文件**（如 output/review.md），不要只留在对话里。

**示例 3：换模型省钱 + 收紧权限 + 导出交作业**

```text
/model            # 选择 deepseek-flash（练习阶段）
/permission       # 切到 workspace-write（或更小的 read-only）
/export           # 会话日志打包下载，作为作业附件
```

要点：`/export` 产出的 ZIP 是"AI 使用声明"的最强证据；把它和脚本、报告一起提交。

## 3.5 两个最容易踩的坑

1. **以为命令内容会进入模型上下文**：不会。想让 Agent 知道你的目标，要用自然语言再说一遍，或写进 AGENTS.md；
2. **把命令当成万能开关**：命令只改会话层的行为（上下文、权限、模型、目标），不改变你的验收标准——判据仍然由你写。

## 3.6 五分钟练习

1. 在工作区里新建一个空目录，用 `/plan` 让 Agent 给出"读取一个 CSV 并输出摘要"的计划；
2. 确认计划后，用 `/permission` 把权限调到 read-only，再让它执行——观察审批与拒绝的提示；
3. 用 `/compact` 压缩会话，检查它是否还记得你的目标（如果不记得，说明目标该写进文件）；
4. 用 `/export` 下载会话日志，打开看看里面记录了哪些工具调用。

## 本节小结

- 斜杠命令是本地控制面：不进模型上下文、不消耗 token；
- 8 条常用命令覆盖"上下文、计划、目标、模型、权限、导出"六件事；
- 命令面只在交互式界面存在，脚本化（headless）时要用自然语言；
- `/export` 让"提交会话记录"变成一条命令，直接服务于课程作业要求。
