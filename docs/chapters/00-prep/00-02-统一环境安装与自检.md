## 2.2 安装 Miniconda

**为什么推荐 Miniconda 而不是 Anaconda？** 两者内核相同；Anaconda 预装大量用不到的工具（约 2–3 GB），Miniconda 只带最小核心（约 150–200 MB），可由课程 `environment.yml` 精确安装所需包。对机房/学生机更友好。

### Windows 步骤

1. 打开清华镜像站 Miniconda 目录：`https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/`；
2. 下载 **最新版** `Miniconda3-latest-Windows-x86_64.exe`（约 80 MB）；
3. 双击安装：**为当前用户安装**，勾选 “Add Miniconda3 to my PATH environment variable”（若没勾，之后从 “Anaconda Prompt” 启动也行）；
4. 安装完成后打开 **Anaconda Prompt**（或重启终端），验证：

```powershell
conda --version
python --version
```

### macOS / Linux 备注

- macOS：下载 `Miniconda3-latest-MacOSX-x86_64.sh`（Apple Silicon 用 arm64 版本），运行 `bash 文件名`；
- Linux：下载 `Miniconda3-latest-Linux-x86_64.sh`，同样执行；Linux（含 CI）请额外安装中文字体与 `xelatex`（见 00-05）。

## 2.3 配置国内镜像（可选但强烈推荐）

### conda 使用清华镜像

```powershell
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --set show_channel_urls yes
```

> 若提示 channel 冲突，也可只保留 default 并在安装时加 `-c https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/`。

### pip 使用清华镜像

```powershell
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn
```

## 2.4 创建课程统一环境

课程已提供环境定义文件：`教学资源/环境配置/environment.yml`。把它复制到你的课程目录（或直接引用绝对路径），然后：

```powershell
cd D:\Scientific_Computing_Class\course-dist   # 或你的课程目录
conda env create -f environment.yml
conda activate scicomp
```

如果以后想重建（比如学期中途更新）：先 `conda env remove -n scicomp` 再 create。若你更喜欢 pip：

```powershell
conda create -n scicomp python=3.12 -y
conda activate scicomp
pip install -r requirements.txt
```

> 环境文件里包含：numpy、sympy、scipy、pandas、matplotlib、seaborn、networkx、statsmodels、scikit-learn、jupyterlab/ipykernel。第 1~8 章全部够用。

## 2.5 安装 VS Code 与扩展

### 安装 VS Code

1. 打开 `https://code.visualstudio.com/`，下载 Windows 安装包并安装（默认选项即可）；
2. 安装完成后，打开命令行确认：

```powershell
code --version
```

### 安装必需扩展

在 VS Code 扩展市场（`Ctrl+Shift+X`）搜索并安装：

| 扩展 | 扩展 ID | 用途 |
| ---- | ---- | ---- |
| Python | `ms-python.python` | 解释器、运行/调试 |
| Pylance | `ms-python.pylance` | 类型检查、补全 |
| Jupyter | `ms-toolsai.jupyter` | 运行 .ipynb 笔记本 |
| LaTeX Workshop | `james-yu.latex-workshop` | LaTeX 编辑/自动编译 |
| Rainbow CSV（可选） | `mechatroner.rainbow-csv` | 方便查看 csv |
| GitLens（可选） | `eamodio.gitlens` | 代码历史/协作 |

也可以在命令行一键安装：

```powershell
code --install-extension ms-python.python
code --install-extension ms-python.pylance
code --install-extension ms-toolsai.jupyter
code --install-extension james-yu.latex-workshop
```

### 导入课程共享配置

打开任意课程目录，把 `教学资源/环境配置/vscode-settings.json` 的内容合并进你的 `设置（JSON）`；关键项包括：

- `python.defaultInterpreterPath`：指向 `scicomp` 环境的 Python；
- `jupyter.notebookFileRoot`：项目根目录；
- `latex-workshop.latex.recipes`：`latexmk -xelatex`（中文必须）。

> 配置片段见 00-03 与 00-05；直接复制文件即可。

## 2.8 常见问题与排错

| 现象 | 原因与解决 |
| ---- | ---- |
| `conda` 不是内部或外部命令 | 未加 PATH；用 Anaconda Prompt，或重新安装时勾选 PATH |
| 下载很慢 | 用清华镜像下载安装包；之后 conda/pip 也配镜像 |
| `conda env create` 报错通道冲突 | 注释掉 `.condarc` 中自定义 channel 后重试；或改用 pip 安装 |
| VS Code 找不到 `scicomp` 解释器 | `Ctrl+Shift+P` → `Python: Select Interpreter` → 选 `scicomp`；若找不到，重启 VS Code 或 `conda activate` 后再开 |
| Jupyter 找不到内核 | 在环境中执行 `python -m ipykernel install --user --name scicomp` |
| `xelatex` 未找到 | 尚未安装 TeX Live，见 00-05；临时可用 Overleaf/LoongTeX |
| 中文输出乱码 | 终端用 `chcp 65001` 或 PowerShell；文件本身是 UTF-8 即可 |
