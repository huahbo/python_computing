# 06 科学计算工作流与代码规范

> 本节目标：让第 0 章成为你“会做项目”的起点：目录规范、notebook 组织、代码风格、环境复现、Git 版本管理入门。

## 本节目标

- 建立全英文、按主题分层的项目目录；
- 按“一个任务一个单元格”组织笔记本并保证可复现；
- 知道科学计算代码的基本规范与命名；
- 用 `environment.yml` / `requirements.txt` 复现环境；
- 掌握 Git 的 4 个核心命令（选学，期末大作业前会用到）。

---

## 6.1 项目目录规范

```text
course-dist/                    # 你的工作区
+-- data/                       # 原始数据（只读）
+-- src/ 或 scripts/            # 可复用 .py 脚本
+-- notebooks/                  # 各章 .ipynb
+-- report/                     # LaTeX 报告
+-- output/                     # 生成结果（图/表/txt）
+-- environment.yml             # 环境定义
+-- README.md
```

- **路径全英文**：中文/空格路径会让 LaTeX、Jupyter、pandoc 等工具出幺蛾子；
- 数据与代码分离：数据放 `data/`，结果写 `output/`，不要混在源码目录。

## 6.2 Notebook 组织（重要）

1. **第一个 Markdown 单元格**：标题、姓名、学号、日期、依赖；
2. 按任务分块：`## 任务 1 读取数据` → 代码 → 输出；`## 任务 2 统计` → 代码 → 输出；
3. **从上往下能一键重跑**：提交前 `Restart Kernel & Run All`，确认没有“靠之前的变量”才能通过；
4. 中间过程用 Markdown 写“这里做了什么”，不要只有代码；
5. 大结果存文件（`output/result.txt`、`output/fig.png`），notebook 里只留摘要。

## 6.3 代码规范（够用版）

- 命名：函数动词开头（`compute_average`）、常量全大写、变量小写下划线；
- 一个函数一个职责；超过 20 行考虑拆分；
- 导入置顶：标准库、第三方、本地模块分组；
- 注释写“为什么”；不要在提交代码里留 `print(123)` 测试垃圾；
- 涉及随机结果一定要设种子（`random.seed` / 后续 `np.random.default_rng`）。

## 6.4 可复现环境

- 用课程提供的环境文件重建：`conda env create -f environment.yml`；
- 也可以用 pip 冻结：`pip freeze > requirements.txt`；
- 提交作业时注明 Python 版本与关键包版本（`python -V`、`pip list` 截取）。

## 6.5 Git 入门（选学，期末前补）

安装 Git for Windows：`[链接](https://git-scm.com/`。四个核心命令：)

```powershell
git clone https://github.com/你的账号/仓库.git   # 第一次
git add .
git commit -m "week0: 环境+报告"
git push
```

- `.gitignore`：把 `.venv`、`output/`、`*.pdf`（如不需要提交）排除；
- 只提交源码、笔记、报告源码；不要提交大文件（数据 > 50 MB 走网盘/云盘）；
- 每完成一章提交一次，方便回溯与协作。

## 6.6 提交与打包规范

第 0 章提交内容（示例）：

```text
学号_姓名_第0章_env_check.txt      # 环境自检输出
学号_姓名_第0章_lab0.ipynb        # lab 完成版
学号_姓名_第0章_lab0报告.pdf       # LaTeX 报告
学号_姓名_第0章_result.txt        # 数据统计结果
```

- 命名统一：`学号_姓名_第N章_类型.扩展名`；
- PDF 用课程模板编译，不交 `.tex` 可以不交（老师按需收源码）。

## 6.7 本节小结

- 工具链稳定 = 项目能跑通的一半；目录规范 = 能被复现的一半；
- Notebook 的“可重跑”比“我运行过”更重要；
- Git 不是期末考试，但期末大作业小组协作时是“保命”技能。
