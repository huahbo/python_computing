# 第 0 章 教学说明（教师用）

> 面向授课教师：课时建议、重点难点、上机安排、考核建议。学生无需阅读本页。

## 1. 教学目标

- 让学生在第 1 章开始前**环境就绪**（Python + VS Code + LaTeX），并提交环境自检输出；
- 用“自测 → 查漏”的方式强化容器/函数/异常/文件等科学计算常用 Python 能力；
- 让学生能写出第一份中文 LaTeX 课程报告（公式/表格/插图 + 一键编译）；
- 跑通“数据 → 统计 → 图表 → 报告”完整闭环，为期末大作业打底。

## 2. 建议课时与安排

### 方案 A：标准第 0 周（推荐）

| 课次 | 内容 | 建议形式 |
| ---- | ---- | ---- |
| 上课 2h | 00-01 导览 10 min → 00-02 环境 35 min → 00-03 VS Code 25 min → 00-04 Python 查漏 40 min → 00-05 LaTeX 10 min（演示为主） | 讲授 + 现场演示 |
| 上机 4h | 0.5h 环境自检（lab A）→ 2h Python 热身（lab B）→ 1h LaTeX 报告（lab C）→ 0.5h quiz/总结 | 巡场 + 现场验收 |

### 方案 B：压缩版（不占第 0 周课堂）

| 时机 | 内容 |
| ---- | ---- |
| 第 1 周上机课前 1h | 00-02 + 00-03 环境与 VS Code 快速安装 |
| 第 1 周上课前 15 min | 00-04 自测讲解（只讲错得最多的 3 题） |
| 第一次作业前 45 min | 00-05 LaTeX 带练（在线/本地二选一） |
| 第 1 周上机后段 | lab 的 A/B/C 压缩为 3h 完成 |

> **教学组织（BYOD）**：要求学生**自带笔记本电脑**操作，机房仅作应急。建议开课前 1 天收集一次“是否已装好环境”的问卷，把明显缺环境的学生编入“互助小组”（每排 1 名技术小组长），第 1 周课前完成兜底。

> 无论哪种方案，**建议第 1 章正式开课前收集环境自检**，否则第 1 章 numpy 教室会变成“装环境大会”。

## 3. 重点与难点

### 重点

- 解释器/内核选择（`scicomp`）——解决 70% 的“我电脑报错”；
- Python 强化：切片、推导式、`dict/get`、`with open`、`try/except`；
- LaTeX 最小可用集：ctexart + 公式 + 表格 + 插图 + `latexmk -xelatex`；
- 在线备选：Overleaf / LoongTeX（强调 XeLaTeX）。

### 难点（学生常卡）

- 环境变量/PATH：建议每排 1 名“技术小组长”，先把 3 台机器装好再帮周围同学；
- `conda activate` 后 `python` 仍指向系统 Python：教室演示 `where python`；
- LaTeX 用 pdflatex 编中文：直接演示报错，再切 xelatex；
- `ModuleNotFoundError`：先查环境/解释器（`sys.executable`），再查包名。

## 4. 上机（lab/）使用建议

- Part A（环境自检）：要求提交 `env_check.txt` 或截图；未通过的学生现场结对排查；
- Part B（Python 热身）：2h 内完成；教师巡场重点看“会不会写函数、会不会读 csv”；
- Part C（LaTeX 报告）：现场给出模板，演示一遍保存→编译→看 PDF；不追求排版美观，跑通即可；
- 综合任务：有余力的同学把 00-07 的 6 项自检全部做完并提交完整打包。

## 5. 作业与考核建议

- **quiz.ipynb**（15 题，自动评分）：当场上机收尾完成，占平时 10%（或按平时比例）；
- **lab0 提交**：命令输出 + notebook + 报告 PDF，占平时 15%；
- **LaTeX 报告**：作为第 0 章作业单独评分（重点看：公式、表格、图、编译成功）；
- 期末大作业提醒：第 8 周布置，报告必须用 LaTeX，第 0 章就是为此铺路。

## 6. 易错点清单（直接用于出题）

1. `conda` 命令找不到（PATH）；
2. 没激活环境就 `pip install`；
3. 默认参数 `=[]` 共享列表；
4. `except:` 吞错误；
5. `open` 不写编码导致中文乱码；
6. LaTeX 用 pdflatex 编中文；
7. 忘记 `\usepackage{amsmath}` 直接用 `\begin{equation}`；
8. 图片路径写错导致编译警告/失败。
