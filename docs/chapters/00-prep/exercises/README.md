# 第 0 章 练习题（exercises/）

> 本章练习的**唯一入口**。内容：环境工具 + Python 强化 + LaTeX 基础，共 15 题，quiz 自动评分。

## 文件说明

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `quiz.ipynb` | 学生自测/提交版 | 题面 + 空白答案单元 + **自动评分**（_GRADES 汇总） |
| `answers.ipynb` | 教学答案版 | 每题含提示 + 可展开答案 + 自动评分 |
| `assignment.md` | 书面/编程作业 | 3 个层次，共 12 题，含答案要点 |
| `quiz_hidden_answers.ipynb` | 隐藏答案版 | 课堂随机抽查用（可选补充） |

## 使用方法

1. **上机收尾**：完成 `quiz.ipynb`，运行全部单元格后查看 `_GRADES` 汇总；
2. **课后**：完成 `assignment.md` 中的 12 题，用 `answers.ipynb` 或答案要点核对；
3. **自测**：先不看答案做 00-04 的 10 道“课前自测”，再对照答案定位薄弱点。

## 覆盖主题（15 题）

| 组 | 题号 | 主题 |
| ---- | ---- | ---- |
| 环境工具 | Q1–5 | conda 创建/激活、环境文件、检查命令、VS Code 解释器/内核、镜像 |
| Python 强化 | Q6–11 | 切片、推导式、dict/get、函数默认值、异常/文件、内置函数 |
| LaTeX | Q12–15 | 中文编译器、文档结构、公式环境、插图/表格、在线平台 |

## 评分建议

- 自动评分 15 题（每题 1–2 分），建议纳入平时成绩 10%；
- 与 lab0 提交分开计分（lab0 看过程与报告）。
