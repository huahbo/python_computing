# 01 课程导览：学什么、怎么学、怎么考

> 本节目标：让你在开课前知道这门课的坐标、8 周怎么走、第 0 章负责什么、作业与考核如何完成。

## 本节目标

- 理解《Python 科学计算》在知识地图中的位置（上游/下游课程）；
- 记住 8 个主题章与每周的学习循环（上课 2h + 上机 4h）；
- 知道第 0 章要做什么、什么时候做；
- 明确三类产出：上机 lab、练习题 quiz、LaTeX 课程报告。

---

## 1.1 这门课讲什么

本课程用 **Python 生态** 完成科学计算、数据分析、统计建模与机器学习小项目：

| 周 | 章 | 主题 | 一句话说明 |
| -- | -- | ---- | ---- |
| 0 | 第 0 章 | 前置基础 | 环境、编程强化、LaTeX 报告 |
| 1 | 第 1 章 | NumPy | 数组、向量化、线性代数、拟合 |
| 2 | 第 2 章 | SymPy | 符号运算、极限/导数/积分、方程求解 |
| 3 | 第 3 章 | SciPy | 数值积分、优化、插值、假设检验、FFT |
| 4 | 第 4 章 | Pandas | 表格数据、清洗、分组、透视、时序 |
| 5 | 第 5 章 | Matplotlib | 可视化、图窗布局、seaborn 美化 |
| 6 | 第 6 章 | NetworkX | 图结构、中心性、最短路、社区发现 |
| 7 | 第 7 章 | Statsmodels | 回归、方差分析、时间序列 |
| 8 | 第 8 章 | scikit-learn | 预处理、有监督/无监督学习 |

第 0 章不独立成“知识主题”，而是给后面 8 章**铺路**：统一环境、补齐 Python 弱点、学会 LaTeX 出报告。

## 1.2 课程怎么组织

- 学时：**48 学时** = 8 周 ×（2h 上课 + 4h 上机）；第 0 周为预备周（标准版 2h 上课 + 4h 上机，可在上机课完成）。
- 每周循环：

```text
上课(2h)：精讲本章核心 + 现场演示
   ↓
上机(4h)：0.5h 回顾 → 3h 完成 lab → 0.5h 当场 quiz/总结
   ↓
课后：完成 exercises 作业；自读“常见误区”页；预习下一章
```

- 详细课表见 `教学资源/课时安排总表.md`。

## 1.3 第 0 章怎么学（建议顺序）

1. **课前（30–60 min）**：读 00-01、00-02、00-03，把 Miniconda 与 VS Code 装上；
2. **第一次上机（4h）**：跟 lab 完成环境自检 → Python 热身 → LaTeX 报告；
3. **课后（2–3h）**：完成 exercises/quiz.ipynb 自测；写一份《学习目标与课程期待》LaTeX 报告（用课程模板，练手）；
4. **遇到问题**：先按 00-02 常见问题表自查，再问同学/助教；机房网络不行时用在线 LaTeX 平台（见 00-05）。

## 1.5 作业、考核与提交

1. **每章 quiz.ipynb**：自动评分（_GRADES 汇总），当场或课后完成；
2. **每章 assignment.md**：课后书面/编程题，含答案要点；
3. **lab/ 完成情况**：上机课检查；第 0 章要求提交 环境自检输出 + lab0 报告 PDF；
4. **期末大作业**：第 8 周布置，课程结束后 2–3 周内提交，要求用 LaTeX 排版报告（这就是为什么第 0 章必须学 LaTeX）。

**提交命名规范**（后面 8 章通用）：

```text
学号_姓名_第0章_lab0.py
学号_姓名_第0章_lab0报告.pdf
学号_姓名_第0章_env_check.txt
```

## 1.6 常见问题

| 问题 | 建议 |
| ---- | ---- |
| 电脑装环境要多久？ | 正常 30–60 min；机房统一预装或提供离线包可压缩到 10 min |
| 我能用在线编译器代替本地 LaTeX 吗？ | 可以（Overleaf/LoongTeX），但上课讲的是本地 VS Code 流程，建议至少会一种 |
| 之前 Python 只学过皮毛，跟得上吗？ | 第 0 章 00-04 就是为你准备的：先自测再查漏；后面章节会反复用 |
| 这门课一定要写 LaTeX 吗？ | 课程报告与期末大作业要求 PDF 报告，LaTeX 是推荐方式；不会的话本章就是补课 |
