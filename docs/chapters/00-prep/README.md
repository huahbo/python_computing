# 0. 前置基础：环境、编程与 LaTeX（新版讲义）

> 本页是第 0 章的**章首页（索引）**。正文位于 `00-01-课程导览与学习路径.md` ~ `00-07-综合案例.md`。本课程原有 8 章（第 1~8 章）无需重编号，第 0 章作为“预备周”放在最前。

## 本章概览

第 0 章解决开课前的三件“小事”，但它们决定了后面 8 周是否顺畅：

1. **统一环境**：每人一套相同的 Python + VS Code + LaTeX 工具链，用脚本自检，避免“我的电脑装不上”；
2. **编程查漏**：你们学过语言程序设计课，本章不重讲语法百科，而是用 10 道自测题找出缺口，针对性强化容器、函数、异常、文件与常用内置函数；
3. **LaTeX 报告**：掌握“文档骨架 + 公式 + 表格 + 插图 + 一键编译”，以便完成课程报告与期末大作业；同时介绍 Overleaf、LoongTeX 等在线编译平台作为备选。

## 学习目标

学完本章，你应该能够：

1. 按讲义在你自己的电脑上搭好与课程一致的 Python + VS Code + LaTeX 环境，并通过 `check_env.py` 自检；
2. 用 VS Code 打开项目、运行 `.py` 脚本与 `.ipynb` 笔记本，切换解释器和内核；
3. 完成 Python 强化自测，熟练使用容器切片、列表推导式、函数参数、异常处理、文件读写与 `zip/enumerate/sorted` 等常用工具；
4. 写出第一个中文 LaTeX 文档并编译出 PDF，能插入公式、表格、图片，能用课程自带模板排版一份小报告；
5. 完成综合案例“从成绩单数据到 LaTeX 报告”，跑通“数据 → 统计 → 图表 → 报告”的完整工作流。

## 先修要求与运行环境

- 修过一门语言程序设计课（C/C++/Python 均可），会写变量、条件、循环、函数；
- 不要求任何 LaTeX 基础；
- 建议课前用自己的电脑安装好课程统一环境标准（见下文“统一环境标准”），或直接使用机房已装好的环境。

## 使用说明

- **学生**：先读 00-01 ~ 00-06 并动手操作 → 跑 `lab/`（上机课完成）→ 用 `exercises/quiz.ipynb` 自测 → 按 00-07 完成第一份 LaTeX 报告。
- **教师**：按 teaching.md 的课时表讲解；lab 是上机课主线；quiz 带自动评分可直接回收；LaTeX 部分建议现场演示“保存 → 自动编译 → 看 PDF”。
