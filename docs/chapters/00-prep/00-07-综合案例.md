## 7.2 任务 1：读取与清洗

```python
import csv

    rows = list(csv.DictReader(f))
```

要求：把成绩转成 `float`；发现异常行时打印并跳过（本数据默认无异常，代码要能容错）。

## 7.3 任务 2：统计与排名

```python
def compute(row):
    py, ma, en = float(row["Python"]), float(row["数学"]), float(row["英语"])
    total = py + ma + en
    return total, total / 3

for r in rows:
    r["总分"], r["平均分"] = compute(r)

by_avg = sorted(rows, key=lambda r: r["平均分"], reverse=True)
print("第一名:", by_avg[0]["姓名"], by_avg[0]["平均分"])
print("倒数第一:", by_avg[-1]["姓名"], by_avg[-1]["平均分"])

class_stats = {
    "Python 平均": sum(float(r["Python"]) for r in rows) / len(rows),
    "平均分 ≥ 60 人数": sum(1 for r in rows if r["平均分"] >= 60),
    "90 分以上（Python）": sum(1 for r in rows if float(r["Python"]) >= 90),
}
```

要求：输出总分排名前 3 与最后 3；统计各科平均分、最高分、最低分。

## 7.4 任务 3：写出结果文件

```python
with open("output/result.txt", "w", encoding="utf-8") as f:
    f.write("== 课程成绩统计 ==\n\n")
    for name, val in class_stats.items():
        f.write(f"{name}: {val:.2f}\n")
    f.write("\n排名前 3：\n")
    for r in by_avg[:3]:
        f.write(f"  {r['姓名']} 平均 {r['平均分']:.1f}\n")
print(open("output/result.txt", encoding="utf-8").read())
```

注意：先 `os.makedirs("output", exist_ok=True)`。

## 7.5 任务 4：画一张简图（预告第 5 章）

```python
import matplotlib
matplotlib.use("Agg")   # 无界面后端，保存文件不弹窗（上课/机房必备）
import matplotlib.pyplot as plt

names = [r["姓名"] for r in rows]
avgs = [r["平均分"] for r in rows]
plt.figure(figsize=(9, 4))
plt.bar(names, avgs)
plt.axhline(60, color="red", linestyle="--", label="及格线 60")
plt.xlabel("姓名"); plt.ylabel("平均分"); plt.title("课程平均分分布")
plt.legend()
plt.savefig("output/avg_scores.png", dpi=120)
plt.close()
print("已保存 output/avg_scores.png")
```

## 7.6 任务 5：LaTeX 报告（核心交付物）
