# 03 综合项目 Project 3

> 本节的定位：把第二部分的方法用在一个完整项目上。Project 3 与期末大作业 Project 1/2 并列，可直接沿用它俩的数据与报告规范。

## 项目目标

用 Agent 完成一次**端到端数据分析**，并提交可复现的产物与 AI 使用声明。

## 选题（任选其一）

| 题目 | 数据 | 任务 |
| ---- | ---- | ---- |
| A 电商用户分析 | 期末项目 1 的数据 | 清洗 → 用户分群（聚类）→ 关键指标与图表 → 结论 |
| B 交通网络分析 | 期末项目 2 的数据 | 建图 → 中心性/最短路/社区 → 可视化 → 结论 |
| C 自选（需教师同意） | 你自己的数据（须合规） | 自定分析目标与判据 |

## 交付物清单

1. 项目目录：AGENTS.md、src/（脚本）、output/（结果与图）、report/（LaTeX 源码与 PDF）；
2. 报告 PDF：含数据、方法、结果、局限、AI 使用声明；
3. 会话记录：关键任务的 /export 存档；
4. 实验记录表（第 11 章 06 节格式）：耗时、花费、人工修改。

## 阶段安排（建议 2 周）

| 阶段 | 产出 | 对应方法 |
| ---- | ---- | ---- |
| 1 选题与计划 | 任务卡 + 计划（plan mode） | 第 10 章 01–02 节 |
| 2 数据与清洗 | clean_rules.yaml + verify_clean.py | 第 11 章 02 节 |
| 3 分析与建模 | 分析脚本 + 判据断言 | 第 11 章 03–04 节 |
| 4 评审与修复 | review.md（意见逐条回应） | 第 11 章 04 节与 05 节 |
| 5 报告与提交 | LaTeX PDF + AI 使用声明 | 第 10 章 04 节、第 0 章 LaTeX |

## 评分标准（建议）

| 维度 | 权重 | 看什么 |
| ---- | ---- | ---- |
| 分析正确性 | 30% | 判据是否成立（行数守恒、交叉验证、检验前提） |
| 验证充分性 | 25% | 断言/复核是否覆盖关键风险（泄漏、异常值、稳健性） |
| 使用规范性 | 20% | 任务卡、AGENTS.md、权限与数据红线、评审闭环 |
| 报告质量 | 15% | 结构、图表规范、局限与不确定性 |
| 声明与记录 | 10% | AI 使用声明完整、会话记录与实验记录可追溯 |

## 常见扣分点

- 只报"最好结果"，不报基线、区间与失败尝试；
- 报告数字与 output/ 对不上；
- 没有逐条回应评审意见；
- 用 Agent 直接生成结论段落，且无法解释来源。

## 本节小结

1. Project 3 复用期末项目的数据与报告规范，只是多了"AI 使用规范"这一层；
2. 五个阶段各有方法出处，照着做即可；
3. 评分看的是"可信度"，不是"用了多少 AI"。

## 思考题

1. 为什么评分把"验证充分性"放在与"正确性"接近的权重？
2. 如果你的分析结论与 Agent 的建议相反，你会怎么处理与记录？
3. 写出你打算做的 Project 3 的一句话目标与两条验收判据。
