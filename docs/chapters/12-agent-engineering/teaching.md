# 第 12 章 教学说明（教师用）

> 面向授课教师：课时建议与项目布置建议。学生无需阅读本页。

## 1. 教学目标

1. 建立版本单一事实源并会跑巡检；
2. 会写更新 SOP 与控制成本；
3. 制定协作规范与合规声明；
4. 完成 Project 3 端到端项目。

## 2. 建议课时

上课 1 学时（版本与成本）；项目辅导 2 学时（Project 3 启动）。

## 3. 重点与难点

- 把版本巡检理解为可迁移的工程能力；
- 成本控制：模型档位、token 估算、轮次限制。

## 4. 常见坑（课堂重点提醒）

- 把版本巡检当"运维活"：强调通用性；
- 项目选题过大：要求沿用期末项目 1/2 的数据与报告规范。

## 5. 资源包

- 维护件：`docs/build/dsh_version.yaml`、`check_dsh_release.py`、`dsh_更新SOP.md`；
- 项目：`教学资源/期末大作业/` 的 Project 3。
