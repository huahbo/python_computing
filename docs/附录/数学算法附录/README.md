# 数学与算法补充（附录 A~F）

> 本附录把各章用到的**数学与算法背景**从章节正文中"抽出来"，按**数学主题**组织，供课堂讲解、上机回查、期末复习和期末大作业参考。正文各章只保留"数学预备"提示框（一段话 + 本附录链接）。

## 使用建议

1. **讲课前**：教师按"各章 → 本附录"映射表，挑出必讲小节；
2. **进入正文前**：学生花 5~10 分钟读对应主题的"直觉"小节即可；
3. **上机时**：遇到公式/算法不确定，回查"速查表"与"Python 对应"；
4. **期末大作业前**：完整过一遍 A~E（约 1 小时），作为建模与汇报的数学底子。

## 与下游课程《数学建模导论》的对齐

本附录的数学主题与 [datawhalechina/intro-mathmodel](https://github.com/datawhalechina/intro-mathmodel)（解析几何与方程模型 / 微分方程与动力系统 / 函数极值与规划模型 / 复杂网络与图论模型 / 时间序列与投资模型 / 机器学习与统计模型…）**一一照应**：本附录给"数学直觉+速查"，intro-mathmodel 给"建模与算法专辑"。学好本附录 = 给该课程打底。

## 与各章的关系
