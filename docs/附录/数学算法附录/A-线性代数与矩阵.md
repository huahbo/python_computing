# 线性代数与矩阵

> 一句话：矩阵是"线性变换"的记录，线性代数是研究"用好这些变换解决问题"的学科。本章只讲科学计算最常用的部分：矩阵运算、分解、最小二乘与数值稳定性。

## A.1 直觉：向量、线性组合与线性变换

- **向量**：既有大小又有方向；在数据里，一行记录就是一个向量（`[身高, 体重, 年龄]`）。
- **线性组合**：`c1·v1 + c2·v2`：把若干向量按比例"混"起来。
- **矩阵 = 线性变换**：`A ` 把向量 `x` 变成 `Ax`（旋转、拉伸、投影）。矩阵乘法 `AB` = 先做 `B` 再做 `A`，所以**矩阵乘法一般不可交换**（`AB ≠ BA`）。
- **线性方程组 `Ax = b`**：问"哪个向量经过 `A` 变换会变成 `b`"——即把 `b` 表示为 `A` 的列向量的线性组合。有唯一解 等价于 `A` 可逆（列向量线性无关）。

## A.2 速查：定义与公式

### A.2.1 基本运算

| 概念 | 记号 | 直觉 |
| ---- | ---- | ---- |
| 转置 | `A^T` | 行列互换；`(AB)^T = B^T A^T` |
| 内积/点积 | `x·y = x^T y` | 相似度、投影长度 |
| 范数 | `||x||_2 = sqrt(x^T x)` | 向量长度 |
| 迹 | `tr(A) = sum(a_ii)` | 特征值之和（不随基改变） |
| 逆 | `A^{-1}` | `A A^{-1} = I`；存在 等价于 满秩 |
| 秩 | `rank(A)` | 矩阵"真正维度"；列向量中线性无关个数 |

### A.2.2 关键量

| 量 | 定义 | 用途 |
| ---- | ---- | ---- |
| 行列式 `det(A)` | 体积缩放系数 | 可逆性；`det=0` 时不可逆 |
| 特征值/特征向量 | `Av = λv` | 只被拉伸不改变方向的向量；用于分解/稳态/收敛 |
| 条件数 `cond(A)` | `||A||·||A^{-1}||` | 数值稳定性：越大解越"抖" |
| 谱半径 | 最大 | 特征值的绝对值 | 迭代法收敛性 |

### A.2.3 常用分解与公式

| 分解 | 形式 | 用途 | 适用 |
| ---- | ---- | ---- | ---- |
| LU | `A = L U` | 解方程组 | 方阵 |
| Cholesky | `A = L L^T` | 更快 | 对称正定 |
| QR | `A = Q R` | 最小二乘/特征值迭代 | 一般 |
| 特征分解 | `A = V Λ V^{-1}` | 分析/对称矩阵 | 方阵可对角化 |
| SVD | `A = U Σ V^T` | 降维/压缩/伪逆 | **任意矩阵** |

最小二乘（超定方程 `Ax ≈ b`）：

```text
正规方程：      x^ = (A^T A)^{-1} A^T b
几何解释：      把 b 投影到 A 的列空间
数值稳健：      优先用 QR / SVD / lstsq，避免直接求 (A^T A)^{-1}
```

## A.3 算法思路

1. **高斯消元 → LU**：把解方程组变成"前代 + 回代"，复杂度 `O(n^3)`；有部分主元策略时数值更稳。
2. **特征值问题**：找一个"方向"，矩阵作用后只缩放。求 `Av = λv` 等价于找 `det(A - λI) = 0` 的根；对称矩阵特征值全是实数，且特征向量正交（SVD 是它的推广）。
3. **SVD**：`A = UΣV^T`，其中 `U`/`V` 是正交阵，`Σ` 是对角阵（奇异值降序）。奇异值大小 = 该方向"重要性"；取前 `k` 个奇异值即得到"最优低秩近似"（Eckart–Young 定理）。用途：图像压缩、主成分分析（PCA）、伪逆 `A^+ = VΣ^{-1}U^T`。
4. **最小二乘的几何**：把 `b` 投影到列空间，误差向量与列空间垂直；`x^` 是离解最近的可行解。加 `λ||x||^2`（岭回归）可防病态/过拟合。

## A.4 Python 对应

```python
import numpy as np, sympy as sp

A = np.array([[2, 1], [1, 3]])
b = np.array([[1], [2]])

# 解方程
np.linalg.solve(A, b)            # 方阵
np.linalg.lstsq(A, b, rcond=None)  # 最小二乘（推荐）

# 分解
np.linalg.eig(A)                 # 特征值/特征向量
np.linalg.svd(A, full_matrices=False)   # U, S, Vt
np.linalg.cholesky(A) if np.allclose(A, A.T) else None
np.linalg.cond(A)                # 条件数

# SymPy 符号版
sp.Matrix(A).eigenvects()
```

函数速查：`inv / det / rank / norm / eig / eigh(对称) / svd / lstsq / solve / cond / pinv`。

## A.5 常见误区

| 误区 | 正确 |
| ---- | ---- |
| `A * B` 当矩阵乘 | NumPy 中 `*` 是逐元素；矩阵乘用 `A @ B` 或 `np.matmul` |
| 直接用 `inv(A) @ b` | 数值差、慢；用 `solve` / `lstsq` |
| 以为 SVD 的 `S` 是矩阵 | 实际是**奇异值向量**；用 `np.diag(S)` 还原 |
| 病态方程无解 | 条件数大≠无解，而是解对输入"过敏"；看 `cond` |
| 忘记特征值可能是复数 | 非对称矩阵用 `eig`；要求实值用 `eigh`（需对称） |
