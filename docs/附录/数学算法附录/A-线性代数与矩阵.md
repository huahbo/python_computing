## A.1 直觉故事：矩阵到底在干什么

很多同学背熟了矩阵乘法，却不知道它"在算什么"。我们从一个具体问题开始：

> 一家店只卖两种套餐：A 套餐（米饭 1 份 + 鸡肉 2 份），B 套餐（米饭 2 份 + 鸡肉 1 份）。今天卖出 3 份 A、2 份 B，问一共用了多少米饭和鸡肉？

把配额写成向量：卖出的数量 `x = (3, 2)`（A 份数、B 份数）。每种套餐的用料写成列向量：A 套餐 `(1, 2)`，B 套餐 `(2, 1)`。那么总用料就是**线性组合**：

```text
总米饭 = 3×1 + 2×2 = 7；总鸡肉 = 3×2 + 2×1 = 8
→ 写成矩阵： [1 2; 2 1] × [3; 2] = [7; 8]
```

这个例子说明了三件事：

1. **向量是"配比"**：一行数据、一份订单、一个状态，都可以是一个向量；
2. **矩阵是"线性变换的约定"**：`A` 的每一列是一种"原料的配方"，`Ax` 就是按 `x` 的比例把各列混合起来；
3. **矩阵乘法 = 复合变换**：先做变换再变换一次，顺序不能换——所以 `AB ≠ BA` 一般情况下成立。

**为什么这对科学计算重要？** 因为很多模型都是一句"线性组合"：多项式拟合是"基函数的线性组合"、线性回归是"特征的线性组合"、傅里叶分析是"正弦波的线性组合"。学会线性代数，等于看懂了这些模型共同的骨架。

> **正文见**：[1 NumPy · 03 线性代数](../../chapters/01-numpy/03-线性代数.md)（矩阵运算与求解）、[1 NumPy · 04 多项式与拟合](../../chapters/01-numpy/04-多项式与拟合.md)（最小二乘）。

## A.2 关键概念讲解：把名词翻译成人话

下面每个概念，先给定义，再用一句话人话解释，最后配一个 2×2 小例子。

### A.2.1 转置、内积与范数

| 概念 | 定义 | 人话 |
| ---- | ---- | ---- |
| 转置 `A^T` | 行列互换 | "把表格行变列、列变行" |
| 内积 `x·y = x^T y` | 对应元素相乘再求和 | "两个向量有多'同向'" |
| 范数 `||x||_2` | `sqrt(x^T x)` | "向量长度" |

例子：`x = (1, 2)`，`y = (3, 4)`，则 `x·y = 1×3 + 2×4 = 11`，`||x||_2 = sqrt(1+4) ≈ 2.24`。内积越大且同向，相似度越高——这就是余弦相似度、皮尔逊相关、注意力机制的底层直觉。

### A.2.2 逆、行列式与秩：能否把变换"倒回去"

- **逆 `A^{-1}`**：把变换倒着做一遍。`A^{-1}A = I`。
- **行列式 `det(A)`**：变换后"体积"放大的倍数。`det(A) = 0` 表示变换把高维压扁了（不可逆），方程组要么无解要么无穷多解。
- **秩 `rank(A)`**：变换后空间的真正维度（列向量中线性无关的个数）。满秩方阵才可逆。

例子：`A = [[2,1],[1,2]]`。`det(A) = 4-1 = 3 ≠ 0`，可逆；`A^{-1} = (1/3)[[2,-1],[-1,2]]`。而 `B = [[1,2],[2,4]]` 两列成比例，`rank(B) = 1`，`det(B) = 0`——它把平面压成一条线，因此 `Bx = b` 要么无解要么无穷多解。

### A.2.3 特征值与特征向量：变换的"不动轴"

定义：若 `Av = λv`（`v ≠ 0`），则 `v` 是特征向量，`λ` 是对应特征值。人话：**有的方向被矩阵只"拉伸"不"拐弯"，拉伸倍数是特征值**。

继续用 `A = [[2,1],[1,2]]`：特征值 `λ1 = 3`（方向 `(1,1)`）、`λ2 = 1`（方向 `(1,-1)`）。也就是说：沿对角线方向放 3 倍、沿反对角线方向不动。

用处：
- 对称矩阵 `A = QΛQ^T`：把坐标轴转成"特征方向"，问题立刻解耦（PCA 就是找这些方向）；
- 幂迭代、PageRank、马尔可夫链稳态都在找"最大特征值的特征向量"。

### A.2.4 条件数：解的"敏感度"

`cond(A) = ||A|| · ||A^{-1}||`，粗略说明：`b` 变化一点点，`x` 可能变化多大倍数。条件数大（病态）≠ 无解，而是**数值上很难算准**。

> **正文见**：[1 NumPy · 03 线性代数](../../chapters/01-numpy/03-线性代数.md)（条件数/病态）、[3 SciPy · 02 优化工具包](../../chapters/03-scipy/02-优化工具包.md)（优化里的病态）。

## A.3 分解与算法：为什么这样做

### A.3.1 解方程组：从高斯消元到 LU

求解 `Ax = b` 最直接是高斯消元：把增广矩阵化成上三角，再回代。消元过程等价于把 `A` 写成 `A = LU`（L 下三角、U 上三角）。好处是：**解多组 `b` 时复用 LU，一次消元多次求解**。

- 矩阵规模 `n×n`，复杂度 `O(n^3)`；
- 数值上要**部分主元**（选最大的元素当主元），避免小除数放大误差；
- Python 里直接 `np.linalg.solve`（内部就是带主元的 LU），**不要**用 `inv(A) @ b`。

### A.3.2 特征值分解与 SVD：谁是"最重要的方向"

- **特征分解**：`A = VΛV^{-1}`（对称阵时 `V` 正交，`A = QΛQ^T`）。适合方阵、可对角化矩阵；求 `A^k`、判断稳态很舒服。
- **奇异值分解 SVD**：`A = UΣV^T`，**任意矩阵都行**。`U`、`V` 正交，`Σ` 对角（奇异值按降序）。直觉：把"变换"分解成"先旋转、再缩放、再旋转"。

SVD 最漂亮的性质是**最优低秩近似**（Eckart–Young）：保留前 `k` 大奇异值，就得到与原矩阵"最接近"的秩 `k` 矩阵。所以：
- 图像压缩：把大矩阵拆成"少数奇异值 × 两个小矩阵"；
- PCA：对数据矩阵做 SVD，右奇异向量就是主成分方向；
- 伪逆与最小二乘：`A^+ = VΣ^{-1}U^T`，比正规方程稳定。

> **正文见**：[1 NumPy · 05 综合案例](../../chapters/01-numpy/05-综合案例.md)（SVD 图像压缩）、[8 sklearn · 03 无监督学习的案例](../../chapters/08-sklearn/03-无监督学习的案例.md)（PCA 降维）。

### A.3.3 最小二乘：数据有噪声怎么办

超定方程 `Ax ≈ b`（方程比未知数多）通常无精确解，最小二乘找"残差平方和最小"的解：

```text
正规方程：x^ = (A^T A)^{-1} A^T b
几何：    把 b 投影到 A 的列空间，误差向量垂直于列空间
数值：    优先 lstsq（QR/ SVD 路径），避免求 (A^T A)^{-1}（会平方条件数）
```

如果再加 `||x||^2` 惩罚（岭回归），就是"在最小二乘和'不放大'之间妥协"——这是第 8 章正则化的数学原型。

## A.4 Python 对应（速查）

```python
import numpy as np, sympy as sp

A = np.array([[2, 1], [1, 2]])
b = np.array([[1], [2]])

np.linalg.solve(A, b)                 # 解方程组（推荐）
np.linalg.inv(A)                      # 显式求逆（尽量不用）
np.linalg.det(A), np.linalg.matrix_rank(A)
np.linalg.eig(A)                      # 特征值/特征向量
np.linalg.eigh(A) if (A == A.T).all() else None   # 对称矩阵专用
np.linalg.svd(A, full_matrices=False)  # U, S, Vt（S 是向量!）
np.linalg.lstsq(A, b, rcond=None)      # 最小二乘
np.linalg.cond(A)                      # 条件数
np.linalg.pinv(A)                      # 伪逆

# SymPy 符号解
sp.Matrix([[2,1],[1,2]]).eigenvects()
```

| 你想要 | 用哪个 |
| ---- | ---- |
| 解方阵方程组 | `np.linalg.solve` |
| 最小二乘 | `np.linalg.lstsq` |
| 特征值（对称） | `np.linalg.eigh` |
| SVD | `np.linalg.svd`（注意 `S` 是向量） |
| 判断病态 | `np.linalg.cond` |

## A.5 动手例题（选做：手算 + 验证）

**例 1：解方程组**。解 @BT@2x + y = 1@BT@、@BT@x + 2y = 2@BT@。手算：由第一式 @BT@y = 1 - 2x@BT@ 代入第二式 @BT@x + 2(1-2x) = 2@BT@ → @BT@-3x = 0@BT@ → @BT@x = 0@BT@，@BT@y = 1@BT@。代码验证：@BT@np.linalg.solve([[2,1],[1,2]], [1,2]) = [0, 1]@BT@。

**例 2：最小二乘的"投影直觉"**。数据 @BT@(0,1), (1,2), (2,3)@BT@ 明显在同一直线 @BT@y = x + 1@BT@ 上，最小二乘应还原出斜率 1、截距 1。若把第 3 点改成 @BT@(2, 4)@BT@（有噪声），斜率会略大于 1——因为解被"拉"向那个异常点。试试：

```python
import numpy as np
x = np.array([0., 1., 2.]); y = np.array([1., 2., 3.])
A = np.vstack([x, np.ones_like(x)]).T        # 列：[x, 1]
k, b = np.linalg.lstsq(A, y, rcond=None)[0]
print(k, b)                                   # 1.0 1.0
y2 = np.array([1., 2., 4.])
print(np.linalg.lstsq(A, y2, rcond=None)[0])  # 斜率 > 1，被噪声拉偏
```

## A.6 常见误区 + 用在哪（双向）

| 误区 | 正确 |
| ---- | ---- |
| `A * B` 当矩阵乘 | `*` 是逐元素；用 `A @ B` |
| 用 `inv(A) @ b` | 用 `solve` / `lstsq` |
| 以为 `S` 是矩阵 | SVD 返回奇异值**向量**，需 `np.diag(S)` |
| 忽略条件数 | 病态时解会"抖"，先看 `cond` |
| 非对称矩阵用 `eigh` | `eigh` 要求对称；否则用 `eig` |

## A.7 补充：特征值与 SVD 的 3 个实际用途

1. **收敛性判断（马尔可夫链/PageRank）**：状态转移矩阵的最大特征值决定系统是否收敛到稳态；PageRank 就是求转移矩阵最大特征值的特征向量（幂迭代）。
2. **去噪与压缩（SVD）**：保留前 k 个奇异值 = 丢掉"不重要的方向"。对一张 100×100 的图，只保留前 10 个奇异值，视觉上几乎一样，但数据量从 10000 降到约 2100。
3. **求逆与最小二乘（伪逆）**：@BT@A^+ = VΣ^{-1}U^T@BT@ 对任意矩阵（含奇异）都定义良好，是 @BT@lstsq@BT@ 的底层路径。

**一句话总结**：特征值/奇异值大小 = 该方向的重要程度；"取前几个"就是"保留主要信息，丢弃噪声"。
