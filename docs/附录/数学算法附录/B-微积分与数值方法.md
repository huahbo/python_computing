# 微积分与数值方法

> 一句话：微积分研究"变化与累积"，数值方法回答"电脑上怎么算"。本章覆盖导数/积分直觉、数值微分积分、插值、优化、傅里叶与常微分方程。

## B.1 直觉：导数、积分与泰勒

- **导数**：瞬时变化率（`f'(x) = lim dx→0 (f(x+dx)-f(x))/dx`）；梯度把导数推广到多元：`grad f = (∂f/∂x1, …, ∂f/∂xn)` 指向上升最快的方向。
- **积分**：累积量（面积/总量）；`∫_a^b f(x) dx` 与导数是互逆（微积分基本定理）。
- **泰勒展开**：`f(x+h) ≈ f(x) + f'(x)h + f''(x)h²/2 + …`——把非线性函数局部"线性化"（后文牛顿法/误差分析都用它）。

## B.2 关键公式速查

| 主题 | 公式/结论 | 用途 |
| ---- | ---- | ---- |
| 微分 | `(x^n)' = n x^{n-1}`、`(sin x)' = cos x`、`(e^x)' = e^x` | 手算/校验 |
| 链式 | `(f(g(x)))' = f'(g(x)) g'(x)` | 反向传播 |
| 梯度 | `grad f`；方向导数在梯度方向最大 | 梯度下降 |
| 泰勒 | 一阶/二阶近似 | 牛顿法、误差界 |
| 积分 | 基本定理、分部积分 | 概率期望/总面积 |
| 数值积分 | 梯形 `≈ (b-a)(f(a)+f(b))/2`；辛普森更高阶 | 无解析积分时 |
| 数值微分 | 中心差分 `(f(x+h)-f(x-h))/(2h)` | 无公式时/`SciPy.optimize`内部 |

## B.3 数值方法：算法思路

### B.3.1 数值积分与微分
- 把 `[a,b]` 分块，块内用低阶多项式近似：梯形（一阶）、辛普森（二阶）、高斯求积（自适应）；误差与步长 `h` 的幂有关。
- 数值微分怕噪声：慎用；需要时用中心差分或拟合后求导（`np.polyfit`→`np.polyder`）。

### B.3.2 优化（求极值）
| 方法 | 思想 | 适用 |
| ---- | ---- | ---- |
| 梯度下降 | 沿负梯度迭代：`x ← x - α·grad f(x)` | 大模型/无二阶信息 |
| 牛顿法 | 用二阶泰勒：`x ← x - H^{-1}·grad f` | 二阶信息可用时收敛快 |
| 拟牛顿/BFGS | 近似 `H^{-1}` | 中规模、`scipy.optimize.minimize` 默认 |
| 约束优化 | `min f(x) s.t. g(x)≤0` | 拉格朗日/KKT 条件 |

> 收敛性：凸函数梯度下降线性收敛；牛顿法（好初值）二次收敛。**初值很关键**。

### B.3.3 插值与拟合
- **插值**：曲线**穿过**所有数据点（拉格朗日/样条）；高次可能震荡（龙格现象）。
- **拟合（最小二乘）**：曲线**逼近**数据（不要求穿过）；由附录 A 的 `lstsq` 实现。
- 选择：噪声大→拟合；数据精确且要过点→样条插值。

### B.3.4 傅里叶变换（FFT）
- 把信号分解为不同频率的正弦波叠加：`X(k) = Σ x(n) e^{-2πikn/N}`；
- FFT 复杂度 `O(N log N)`；看频谱找周期、滤波、平滑（`scipy.fft / np.fft`）。

### B.3.5 常微分方程（ODE）
- 初值问题 `y' = f(t,y), y(t0)=y0`：数值解按步长推进（欧拉、RK45 等）；
- `scipy.integrate.solve_ivp` 自动选步长；符号精确解用 SymPy `dsolve`。

## B.4 Python 对应

```python
import numpy as np, scipy.integrate as si, scipy.optimize as so
from scipy import interpolate, fft

# 数值积分/微分
si.quad(np.sin, 0, np.pi)          # 数值积分
np.gradient(np.array([0, 1, 4, 9]), 0.1)   # 数值微分（中心差分）

# 优化
so.minimize(lambda x: (x[0]-2)**2 + (x[1]+1)**2, x0=[0, 0])   # BFGS

# 插值/拟合
interpolate.interp1d(x, y, kind="cubic")
np.polyfit(x, y, 2)

# FFT / ODE
fft.fft(signal)
si.solve_ivp(lambda t, y: -y, [0, 5], [1.0])   # y' = -y
```

## B.5 常见误区

| 误区 | 正确 |
| ---- | ---- |
| 插值=拟合 | 插值过点、拟合逼近；数据有噪声用拟合 |
| 优化不设初值 | 非凸问题初值决定结果；多试几个/给定范围 |
| 数值微分会放大噪声 | 先平滑/拟合，再求导；或改用解析导数 |
| 以为 FFT 只用于音频 | 任何周期信号/时间序列都能看频谱 |
| 用默认 ODE 求解器硬解刚性问题 | 选 `method="Radau"` 等刚性方法 |
