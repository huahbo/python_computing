## B.1 直觉故事：从"瞬时速度"说起

开车两小时走 180 公里，平均 90 km/h；但"先快后慢"时，平均速度看不出细节。

- **导数** = 瞬时变化率：时间间隔缩到无限小，平均速度的极限。几何 = 切线斜率；机器学习里 = "参数往哪调、调多少"。
- **积分** = 累积量：已知每秒速度求总路程 = 把速度乘时间加总，间隔越细越准。几何 = 曲线下面积。
- **泰勒展开**：$f(x+h)=f(x)+f'(x)h+\tfrac12 f''(x)h^2+\cdots$——把非线性函数在局部"线性化/抛物化"。牛顿法、误差分析、反向传播都靠它。

## B.2 关键概念（带手算小例子）

### B.2.1 导数、偏导与梯度

手算 $f(x)=x^2$ 在 $x=2$：$\dfrac{(2+h)^2-4}{h}=4+h\to 4$。所以 $f'(2)=4$。

多元 → 偏导 → 梯度：

$$\nabla f(x)=\Big(\frac{\partial f}{\partial x_1},\ldots,\frac{\partial f}{\partial x_n}\Big)$$

含义：指向 $f$ 上升最快的方向；负梯度 = 最速下降方向。

**导数速查**：$(x^n)'=nx^{n-1}$、$(\sin x)'=\cos x$、$(e^x)'=e^x$、$(\ln x)'=1/x$、$(uv)'=u'v+uv'$、$(f(g(x)))'=f'(g(x))g'(x)$。

### B.2.2 积分与基本定理

- 不定积分 = 求原函数；定积分 = 面积/累积；
- 基本定理：$\int_a^b f'(x)\,dx = f(b)-f(a)$；
- 手算：$\int_0^1 3x^2\,dx = x^3\big|_0^1 = 1$。

### B.2.3 为什么还要"数值"（难点）

实际函数常无解析式，或表达式复杂到算不动。近似方法：

- **数值微分**（中心差分）：$f'(x)\approx\dfrac{f(x+h)-f(x-h)}{2h}$，误差 $O(h^2)$（比前向差分 $O(h)$ 好）；
- **数值积分**：梯形（一阶）、辛普森（二阶抛物线）、高斯求积（高阶、自适应加密）。**误差阶**告诉你"步长减半，误差怎么降"——这是数值分析最核心的思想。

## B.3 深入：数值方法（重点、难点）

### B.3.1 优化：找"最低点"

| 方法 | 更新式 | 记忆点 |
| ---- | ---- | ---- |
| 梯度下降 | $x\gets x-\alpha\nabla f(x)$ | 沿最陡下坡走；步长要调 |
| 牛顿法 | $x\gets x-H^{-1}\nabla f(x)$ | 用二阶曲率加速 |
| 拟牛顿/BFGS | 近似 $H^{-1}$ | `scipy.optimize.minimize` 默认 |
| 约束优化 | KKT 条件 | 带 $g(x)\le 0$ |

**为什么牛顿法快**：$f$ 在 $x_k$ 附近用二阶泰勒近似，令导数为零得 $x_{k+1}=x_k-H^{-1}\nabla f$。凸、光滑、好初值时**二次收敛**（误差平方级下降）。

**步长手算**：$f(x)=(x-3)^2$，$x_0=1$，$\nabla f=2(x-3)=-4$。$\alpha=0.5$ → 一步到 $x=3$；$\alpha=2$ → $x=9$，直接弹过最优——"步长太大震荡"。

### B.3.2 插值 vs 拟合（本科高频考点）

- **插值**：曲线**穿过**每个已知点（拉格朗日、样条）；高次会**龙格震荡**（边界剧烈摆动）——不要迷信"高次"；
- **拟合**：曲线**接近**所有点（最小二乘，见附录 A）；噪声数据永远优先拟合（+正则化）；
- 选择：数据精确且要过点 → 样条插值；有噪声 → 拟合。

### B.3.3 傅里叶变换（FFT）

$$X(k)=\sum_{n=0}^{N-1}x(n)\,e^{-2\pi i kn/N}$$

把信号拆成不同频率正弦叠加。FFT 复杂度 $O(N\log N)$（直接 DFT 是 $O(N^2)$）；用途：找周期、去噪、平滑；截断信号会**频谱泄漏**（加窗缓解）。

### B.3.4 常微分方程（ODE）

初值问题 $y'(t)=f(t,y)\ ,\ y(t_0)=y_0$：

- **欧拉法**：$y_{n+1}=y_n+h f(t_n,y_n)$——简单但误差大（$O(h)$）；
- **RK45**：每步取 4~5 个点的加权平均，误差约 $O(h^4)$，`scipy.integrate.solve_ivp` 默认；
- **刚性问题**：特征值相差悬殊时，显式方法步长被迫极小 → 换隐式方法 $\mathrm{method="Radau"}$。

### B.3.5 怎么选数值方法（决策表）

| 场景 | 首选 | 理由 |
| ---- | ---- | ---- |
| 有解析式、要精确结构 | SymPy | 数值只是近似 |
| 只有采样数据、要面积 | `quad` | 自适应、精度高 |
| 求极值、无导数 | `minimize`（BFGS） | 稳健默认 |
| 数据精确要过点 | 样条插值 | 高次插值震荡 |
| 数据有噪声 | 最小二乘 | 插值会"记住"噪声 |
| 找周期/滤波 | FFT | 时域卷积长序列慢 |
| ODE 初值 | `solve_ivp`（RK45） | 精度/效率均衡；刚性用 Radau |

## B.4 动手例题（选做）

**例 1：数值积分 vs 解析**。$\int_0^1 3x^2\,dx=1$；梯形给 0.75，辛普森给 1.0。

**例 2：中心差分**。$f(x)=x^2$，$h=0.1$：$(f(2.1)-f(1.9))/0.2=(4.41-3.61)/0.2=4.0$（真值 $f'(2)=4$）。

```python
from scipy import integrate, optimize
import numpy as np
print(integrate.quad(lambda x: 3*x**2, 0, 1)[0])          # 1.0
print(optimize.minimize(lambda x: (x[0]-3)**2, x0=[1.]).x)  # ~3
x = np.array([1.9, 2.0, 2.1])
print(np.gradient(x*x, 0.1)[1])                             # ~4.0
```

## B.6 常见误区

| 误区 | 正确 |
| ---- | ---- |
| 插值=拟合 | 插值过点、拟合逼近；有噪声用拟合 |
| 优化不设初值 | 非凸问题初值决定结果；多试几组 |
| 数值微分直接用于噪声数据 | 先平滑/拟合再求导 |
| FFT 只能处理声音 | 任何时序都能做频谱 |
| 刚性系统用默认求解器 | 换 `method="Radau"` |
| 只看 $O(h)$ 就选方法 | 还要看常数、稳定性与实现难度 |

## B.9 综合案例：拟合 + 积分（做一道完整数值题）

**问题**：已知某产品的"价格-销量"散点，希望给出"总需求"（曲线下的面积）与"最优定价"（利润最大点）。

步骤：

1. 用最小二乘拟合价格 p 与销量 q 的线性/二次关系（附录 A 的正规方程或 np.polyfit）；
2. 用数值积分估算某区间的"总销量"（面积）；
3. 用优化求利润 f(p) = p*q(p) 的最大值点；
4. 用中心差分验证最优点的导数为 0。

参考要点代码：

    import numpy as np
    from scipy import integrate, optimize
    p = np.array([1., 2., 3., 4.]); q = np.array([9., 7., 5., 3.])
    coef = np.polyfit(p, q, 2)
    total = integrate.quad(lambda x: np.polyval(coef, x), 1, 4)[0]
    best = optimize.minimize_scalar(lambda x: -x * np.polyval(coef, x), bounds=(1, 4), method="bounded")
    print(total, best.x)

**反思**：把"数据→模型→积分→优化"串起来，就是科学计算的常用闭环。

## B.8 例题集（深入练习）

**例 1：牛顿法手算两步**。$f(x)=x^2-2$，求 $\sqrt2$。$f'(x)=2x$，$x_{k+1}=x_k-\dfrac{x_k^2-2}{2x_k}$。从 $x_0=1$：$x_1=1.5$，$x_2=1.4167$，$x_3=1.4142$——收敛到 $\sqrt2\approx1.41421356$（二次收敛）。

**例 2：误差阶实验**。用梯形法则算 $\int_0^1 x^2dx=1/3$：$h=0.5$ 得 0.375，$h=0.25$ 得 0.34375。步长减半，误差从 0.0417 降到 0.0104——大约除以 4（二阶收敛）。

```python
from scipy import integrate
for h in [0.5, 0.25]:
    xs = np.arange(0, 1 + h, h)
    trap = np.trapezoid(xs**2, xs)
    print(h, trap, abs(trap - 1/3))
```

**例 3：ODE 欧拉 vs RK45**。$y'=-y$，$y(0)=1$，精确解 $y=e^{-t}$。欧拉 $h=0.1$ 在 $t=1$ 得约 0.3487（误差大）；`solve_ivp` 用 RK45 得约 0.3679（近真值）。
