# 微积分与数值方法

> 一句话：微积分是"变化与累积"的语言，数值方法回答"电脑上到底怎么算"。本附录把第 2 章 SymPy 的符号推导与第 3 章 SciPy 的数值工具背后的数学讲清楚。

---

## B.1 直觉故事：从"瞬时速度"说起

你开车，两小时走了 180 公里，平均速度 90 公里/小时。可如果车是"先快后慢"呢？平均速度看不出任何细节。

**导数**就是回答"某一瞬间的速度"：把时间间隔缩到无限小，平均速度的极限。几何上它是曲线某点的切线斜率；物理上它是变化率；机器学习里它是"参数往哪个方向调、调多少"的依据。

**积分**是反向累积：已知每秒的速度，求走过的总路程——把每秒速度乘上时间加总，间隔越细越准。几何上它是曲线下面积；概率里它是期望。

**泰勒展开**把"复杂函数"在某个点附近写成多项式：`f(x+h) ≈ f(x) + f'(x)h + f''(x)h²/2`。它看起来很"取巧"，但牛顿法、误差分析、反向传播的直觉全都建立在"局部用直线/抛物线逼近"上。

> **正文见**：[2 SymPy · 01 符号对象与基本运算](../../chapters/02-sympy/01-符号对象与基本运算.md)（极限/导数/积分）、[2 SymPy · 02 利用SymPy求解问题](../../chapters/02-sympy/02-利用SymPy求解问题.md)。

## B.2 关键概念讲解（带手算小例子）

### B.2.1 导数与偏导

手算一个简单例子：`f(x) = x²`。按定义算 `f'(2)`：`( (2+h)² - 4 ) / h = (4h + h²)/h = 4 + h → 4`（`h→0`）。所以曲线在 `x=2` 的斜率是 4。

多元函数就要**偏导**（一次只动一个变量），把偏导排成向量就是**梯度**：

```text
梯度 grad f(x) = (∂f/∂x1, ∂f/∂x2, …, ∂f/∂xn)
几何意义：指向 f 上升最快的方向；负梯度 = 最速下降方向
```

**速查（常用导数）**

| 函数 | 导数 | | 函数 | 导数 |
| ---- | ---- | ---- | ---- | ---- |
| `x^n` | `n x^{n-1}` | | `sin x` | `cos x` |
| `e^x` | `e^x` | | `ln x` | `1/x` |
| `u(x)v(x)` | `u'v + uv'` | | `f(g(x))` | `f'(g(x)) g'(x)` |

### B.2.2 积分与基本定理

- 不定积分 `∫ f(x) dx` 是"求原函数"（反导数）；
- 定积分 `∫_a^b f(x) dx` 是面积/累积；微积分基本定理：`∫_a^b f'(x)dx = f(b) - f(a)`。

手算例子：`∫_0^1 3x² dx = x³ |_0^1 = 1`——正好验证"导数与积分互逆"。

### B.2.3 数值微分与积分（为什么还要"近似"）

很多实际函数没有解析式（例如只有采样数据），或者表达式复杂到 SymPy 也算不动。此时用近似：

- 中心差分：`f'(x) ≈ (f(x+h) - f(x-h)) / (2h)`，误差 `O(h²)`，比前向差分更准；
- 数值积分：梯形法则把曲线下的面积分成梯形求和；辛普森法则用二次抛物线逼近，更准；高阶自适应（`scipy.integrate.quad`）自动加密。

> **正文见**：[3 SciPy · 01 微积分工具包](../../chapters/03-scipy/01-微积分工具包.md)。

## B.3 数值方法详解：优化、插值、FFT、ODE

### B.3.1 优化：找"最低点"

问题：`min_x f(x)`。

| 方法 | 思想 | 一句话记忆 |
| ---- | ---- | ---- |
| 梯度下降 | `x ← x - α·grad f(x)` | 沿最陡下坡走，步长 α 要调 |
| 牛顿法 | `x ← x - H^{-1}·grad f` | 用"坡度的坡度"（曲率）加速 |
| 拟牛顿（BFGS） | 近似 `H^{-1}` | `scipy.optimize.minimize` 默认武器 |
| 约束优化 | KKT 条件 | 带 `g(x) ≤ 0` 时求解 |

一个手算直觉：`f(x) = (x-3)²`，最优在 `x=3`。若 `x0 = 1`，`grad f = 2(x-3) = -4`，更新 `x ← 1 - α(-4)`；α 太大（如 1）会直接跳到 5，再弹回来——这就是"步长太大震荡"。

> 优化是几乎所有机器学习和统计建模的引擎（见附录 E 的梯度下降）。

### B.3.2 插值与拟合：穿过点还是接近点

- **插值**：曲线必须**经过**每个已知点（拉格朗日、样条）。适合"数据精确、形状重要"；
- **拟合（最小二乘）**：曲线**接近**所有点（多项式拟合、岭回归）。适合"数据有噪声"。

例子：已知 `(0,0), (1,1), (2,4)`。线性拟合会给一条"平均线"；二次插值会精确穿过三点（但再高次就容易震荡——龙格现象）。**数据有噪声时永远优先拟合加正则化，而不是高次插值。**

> **正文见**：[3 SciPy · 03 插值工具包](../../chapters/03-scipy/03-插值工具包.md)。

### B.3.3 傅里叶变换：把信号拆成"频率"

直觉：任何周期信号都能写成不同频率正弦波的叠加。傅里叶变换把"时间域"的信号变成"频率域"的频谱 `X(k) = Σ x(n) e^{-2πikn/N}`。

- FFT 复杂度 `O(N log N)`，所以长序列也能秒级处理；
- 用途：找周期（电商销量季节）、去噪（滤掉高频）、平滑；
- 注意：非周期/截断信号会出现"频谱泄漏"（加窗缓解）。

### B.3.4 常微分方程 ODE：让系统"跑起来"

初值问题：`y'(t) = f(t, y)`，`y(t0) = y0`。数值上讲就是"一小步一小步地推进"：

```text
欧拉法：   y_{n+1} = y_n + h·f(t_n, y_n)    （简单但误差大）
RK45：    每步取 4~5 个点的加权平均          （scipy 默认，精度高）
刚性问题： 选 Radau 等隐式方法，稳定第一
```

> **正文见**：[3 SciPy · 01 微积分工具包](../../chapters/03-scipy/01-微积分工具包.md)（ODE 与 solve_ivp）、[2 SymPy · 02 利用SymPy求解问题](../../chapters/02-sympy/02-利用SymPy求解问题.md)（dsolve 符号解）。

## B.4 Python 对应（速查）

```python
import numpy as np
from scipy import integrate, optimize, interpolate, fft
import sympy as sp

x = sp.symbols("x")
sp.diff(sp.sin(x), x)                 # 符号导数
sp.integrate(3*x**2, (x, 0, 1))       # 符号定积分

integrate.quad(np.sin, 0, np.pi)      # 数值积分
np.gradient(np.array([0, 1, 4, 9]), 0.1)   # 数值微分

f = lambda x: (x[0] - 2)**2 + (x[1] + 1)**2
optimize.minimize(f, x0=[0, 0])       # BFGS 优化

interpolate.interp1d([0,1,2], [0,1,4], kind="cubic")   # 插值
np.polyfit([0,1,2], [0,1,4], 2)       # 拟合

fft.fft(signal)                       # FFT
integrate.solve_ivp(lambda t,y: -y, [0,5], [1.0])      # ODE
```

| 你想要 | 用哪个 |
| ---- | ---- |
| 符号导数/积分 | `sympy.diff / sympy.integrate` |
| 数值积分 | `scipy.integrate.quad` |
| 数值微分 | `np.gradient` |
| 优化 | `scipy.optimize.minimize` |
| 插值 | `interpolate.interp1d` |
| 拟合 | `np.polyfit / np.linalg.lstsq` |
| FFT | `scipy.fft.fft` |
| ODE | `solve_ivp` |

## B.5 动手例题（选做：手算 + 验证）

**例 1：优化步长的教训**。@BT@f(x) = (x - 3)²@BT@，@BT@x0 = 1@BT@，@BT@grad f = 2(x-3) = -4@BT@。@BT@α = 0.5@BT@：@BT@x1 = 1 - 0.5×(-4) = 3@BT@（一步到位）；@BT@α = 2@BT@：@BT@x1 = 9@BT@（弹过最优值）。这就是"学习率要小、要试"。

```python
from scipy.optimize import minimize
f = lambda x: (x[0] - 3) ** 2
print(minimize(f, x0=[1.0]).x)     # 约 [3.]
```

**例 2：数值积分与中心差分**。@BT@∫_0^1 3x² dx = 1@BT@（解析）；梯形法则给出 0.75，辛普森给出 1.0（更准）。中心差分：@BT@f(x)=x²@BT@，@BT@h=0.1@BT@ 时 @BT@(f(2.1)-f(1.9))/(0.2) = (4.41-3.61)/0.2 = 4.0@BT@，正好等于 @BT@f'(2)@BT@。

```python
from scipy import integrate
import numpy as np
print(integrate.quad(lambda x: 3*x**2, 0, 1)[0])   # 1.0
x = np.array([1.9, 2.0, 2.1])
print(np.gradient(x*x, 0.1)[1])                     # 约 4.0
```

## B.6 常见误区 + 用在哪（双向）

| 误区 | 正确 |
| ---- | ---- |
| 插值等于拟合 | 插值过点、拟合逼近；有噪声用拟合 |
| 优化不调初值 | 非凸问题初值决定结果；多试几组/给边界 |
| 数值微分直接用于噪声数据 | 先平滑/拟合（附录 A 最小二乘）再求导 |
| 以为 FFT 只能处理声音 | 任何时序/周期信号都能做频谱 |
| 用默认 solve_ivp 硬解刚性系统 | 换 `method="Radau"` |

## B.7 补充：怎么选数值方法（决策表）

| 场景 | 首选 | 为什么不选另一个 |
| ---- | ---- | ---- |
| 函数有解析式且可符号化 | SymPy 精确解 | 数值解只是近似，且看不懂结构 |
| 只有采样数据、要面积 | @BT@scipy.integrate.quad@BT@ | 梯形精度低，辛普森对尖峰不够自适应 |
| 求极值、不知道导数值 | @BT@minimize@BT@（BFGS） | 差分梯度慢；解析梯度快但易错 |
| 数据精确、要过点 | 样条插值 | 高次插值会震荡 |
| 数据有噪声 | 最小二乘/拟合 | 插值会把噪声也"记住" |
| 找周期/滤波 | FFT | 时域卷积在长序列上慢 |
| ODE 初值问题 | @BT@solve_ivp@BT@（RK45） | 欧拉法误差大；刚性用 Radau |

**经验法则**：先试官方/库默认，再根据报错/误差/稳定性换方法；永远保留一份"手算小例子"来验证你的理解（见 B.5）。
