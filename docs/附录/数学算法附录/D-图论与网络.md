# 图论与网络

> 一句话：把实体当"点"、把关系当"边"，就能用一套统一的数学工具分析任何网络——社交、交通、商品关系、引用网络。本附录为第 6 章 NetworkX 提供图论与算法背景。

---

## D.1 直觉故事：朋友圈里的"谁最重要"

想象你问"班里的社交核心是谁"。只看谁朋友多（**度中心性**）不一定准：一个人认识 10 个互相不认识的人，另一个人认识 10 个彼此都认识的人，前者更像"桥梁"。所以"重要"有不同定义：

- **度中心性**：连接数多 → "活跃"；
- **接近中心性**：到所有人平均距离短 → "信息传得快"；
- **介数中心性**：很多最短路经过它 → "枢纽/瓶颈"；
- **PageRank**：被"重要的人"指向 → "影响力"（搜索引擎逻辑）。

同一个网络，不同"重要"答案不同——所以做网络分析，第一步是**明确要问什么**。

> **正文见**：[6 NetworkX · 02 分析图](../../chapters/06-networkx/02-分析图.md)（度/中心性）、[6 NetworkX · 03 求解图的基本问题](../../chapters/06-networkx/03-求解图的基本问题.md)。

## D.2 图的基本表示（讲解 + 手算）

### D.2.1 怎么把图"喂给电脑"

| 表示 | 样子 | 适合 |
| ---- | ---- | ---- |
| 邻接矩阵 `A` | `A[i][j] = 1`（或权重） | 稠密图、矩阵运算；点多时费内存 |
| 邻接表 | 每个点存邻居列表 | 稀疏大图；遍历快 |

手算例子（4 个点：A-B、A-C、B-C、C-D）：

```text
邻接矩阵（无向图对称）：
    A B C D
A [ 0 1 1 0 ]
B [ 1 0 1 0 ]
C [ 1 1 0 1 ]
D [ 0 0 1 0 ]
```

### D.2.2 基本量：度、连通、树

- **度 `deg(v)`**：邻边数；有向图分**入度/出度**。
- **路径**：点与点之间能到达；**连通分量**：互为连通的最大点集。
- **树**：无环连通图，`n` 个点恰好 `n-1` 条边——网络的最"轻"骨架。
- **二分图**：点分成两类，边只在类间（学生-选课、用户-商品）。

### D.2.3 加权与有向

- **加权图**：边带距离/成本/强度；最短路、最小生成树、网络流都依赖这些权。
- **有向图**：边有方向（关注、引用、资金流）；"PageRank""拓扑排序"只对有向图有意义。

## D.3 经典算法：思路与手算

### D.3.1 遍历：BFS 与 DFS

- **BFS（广度优先）**：一层层向外扩散。无权图最短路就靠它；手算例子：从 A 出发，先到 B、C，再到 D，路径 A→C→D 是两步最短。
- **DFS（深度优先）**：一条路走到黑再回头。用于检测环、连通分量、拓扑排序。

### D.3.2 最短路径

| 算法 | 适用 | 思路 | 复杂度 |
| ---- | ---- | ---- | ---- |
| BFS | 无权 | 按层扩散 | `O(V+E)` |
| Dijkstra | 非负权 | 每次取当前最近点并"松弛"邻居 | `O((V+E) log V)`（堆） |
| Bellman-Ford | 可能有负权 | 反复松弛直到稳定 | `O(VE)` |
| Floyd-Warshall | 全源最短路 | 动态规划 | `O(V³)` |

手算 Dijkstra（无向、权为边上的数字）：从 A 出发，初始 dist：A=0、B=∞、C=∞、D=∞。先松弛到 B=2、C=5；取最小 B=2，松弛 C 得 2+1=3 <5，更新；再取 C=3，松弛 D=3+4=7；最后 D=7。三步得到 A→C→B→D 的路径长度。

### D.3.3 最小生成树（MST）

目标：用总权重最小的边把所有点连通（且无环）。**Kruskal**：边按权从小到大排序，用并查集判断是否会成环，不成环就加入。手算直觉：选最便宜的边，只要不形成圈就保留——最后恰好 `n-1` 条边。

### D.3.4 中心性与社区

- **介数中心性**：统计每条最短路经过某点的次数——"关键枢纽"；
- **PageRank**：随机游走者在图上散步的稳态分布；被高权重节点指向的节点权重更高；
- **社区发现**：把网络切成"内部紧密、外部稀疏"的组。常用 **Louvain**（贪心模块度优化）、**谱聚类**（拉普拉斯特征向量）、标签传播。

> **正文见**：[6 NetworkX · 04 综合案例](../../chapters/06-networkx/04-综合案例.md)（社区/中心性综合应用）。

## D.4 Python 对应（速查）

```python
import networkx as nx

G = nx.Graph()
G.add_edges_from([("A","B",{"w":2}), ("A","C",{"w":5}),
                  ("B","C",{"w":1}), ("C","D",{"w":4})])

nx.shortest_path(G, "A", "D", weight="w")     # Dijkstra
nx.dijkstra_path_length(G, "A", "D", weight="w")
nx.minimum_spanning_tree(G, weight="w")       # MST
nx.degree_centrality(G)
nx.betweenness_centrality(G)
nx.pagerank(G)
nx.community.louvain_communities(G)

nx.draw(G, with_labels=True)
```

| 你想要 | 用哪个 |
| ---- | ---- |
| 最短路 | `nx.shortest_path`（加权传 `weight`） |
| MST | `nx.minimum_spanning_tree` |
| 中心性 | `degree / closeness / betweenness / pagerank` |
| 社区 | `nx.community` |
| 可视化 | `nx.draw`（或结合 Matplotlib） |

## D.5 动手例题（选做：手算 + 验证）

**例：Dijkstra 手算**。图：A–B（权 2）、A–C（权 5）、B–C（权 1）、C–D（权 4）。

1. 初始化：@BT@dist(A)=0@BT@，其余 ∞；
2. 松弛 A 的邻居：B=2，C=5；
3. 取最小 B=2，松弛 C：@BT@2+1=3 < 5@BT@ → C=3；
4. 取 C=3，松弛 D：@BT@3+4=7@BT@；
5. 得 @BT@A→B→C→D@BT@，距离 7。

```python
import networkx as nx
G = nx.Graph()
G.add_weighted_edges_from([("A","B",2), ("A","C",5), ("B","C",1), ("C","D",4)])
print(nx.shortest_path(G, "A", "D", weight="weight"))     # ['A','B','C','D']
print(nx.shortest_path_length(G, "A", "D", weight="weight"))  # 7
```

**例：中心性可以完全不同**。星型网络（中心点 A 连 5 个叶子）：A 的介数中心性远高于叶子；而每个叶子的度都是 1——说明"度中心性"看不出谁是枢纽。

## D.6 常见误区 + 用在哪（双向）

| 误区 | 正确 |
| ---- | ---- |
| 以为图只能是邻接矩阵 | 稀疏大图用 NetworkX 的邻接表实现 |
| 无向图当成有向图算 | `Graph` 与 `DiGraph` 分开；看方向 |
| 用最短路回答"谁最重要" | 先明确"重要"的定义（度/介数/PageRank…） |
| 忽略权重 | 加权算法要传 `weight` 参数 |
| 社区数量随便定 | 社区发现与分辨率有关；试多组参数并看模块度 |

## D.7 补充：社区发现的直觉与模块度

社区发现的"好"标准是**模块度**：比较"社区内部实际边数"和"随机网络下的期望边数"。直觉：

- 模块度高 = 社区内部比随机更密、社区之间比随机更疏；
- Louvain 算法是"先局部合并、再全局聚合"的贪心，快且常用；
- 敏感性：同一个网络，不同分辨率/随机种子可能给出不同社区——**要报告所用的方法与参数**。

**一句话总结**：社区是"相对"概念，结论要配方法与参数一起给，不能只画一张颜色图。
