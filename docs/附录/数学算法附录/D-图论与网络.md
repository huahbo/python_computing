# 图论与网络

> 一句话：图 = 点 + 边，是"关系/网络"的通用表示。本附录覆盖图表示、基本量、经典算法（路径/树/中心性/社区）与对应代码。

## D.1 直觉：图表示什么

- **节点（顶点）**：实体（人、城市、网页、商品）。
- **边**：关系（朋友、道路、超链接、共同购买）。有向边（关注）与无向边（好友）、加权边（距离/强度）。
- 图模型能表达"结构"：社团、传播、最短路、枢纽——这正是 NetworkX 章要做的事。

## D.2 图的基本表示与速查

| 概念 | 定义/公式 | 说明 |
| ---- | ---- | ---- |
| 邻接矩阵 `A` | `A[i][j]=1 (或权重)` 若有边 | 方便矩阵运算；稀疏图费内存 |
| 邻接表 | 每个点存邻居列表 | 节省空间；遍历快 |
| 度 `deg(v)` | 邻边数（有向图分入度/出度） | 活跃度/重要性基础 |
| 路径/连通 | 点之间能走到；连通分量 | 网络可达性 |
| 树 | 无环连通图；`n` 个点 `n-1` 条边 | 骨架/最小生成树 |
| 二部图 | 点分成两类，边只在类间 | 匹配/推荐 |
| 加权图 | 边带权 | 最短路径/流 |

## D.3 经典算法：思路与用途

### D.3.1 遍历
- **BFS（广度）**：按"层"扩散，找最短路（无权图）。
- **DFS（深度）**：一条路走到黑，检测环、连通分量、拓扑排序。

### D.3.2 最短路径
| 算法 | 适用 | 思想 |
| ---- | ---- | ---- |
| Dijkstra | 非负权 | 贪心：每次取当前最近点松弛 |
| Bellman-Ford / 带负权 | 有负权 | 反复松弛 |
| Floyd-Warshall | 全源 | 动态规划 `O(n³)` |
| 关键 | 加权/无权 | A* 启发式搜索（估算） |

### D.3.3 树与网络流
- **最小生成树（MST）**：连接所有点且总权重最小（Kruskal 按边排序 + 并查集；Prim 加点）。
- **最大流/最小割**：二分匹配、交通流（Ford–Fulkerson）。

### D.3.4 中心性与社区
- **度中心性**：连接的边数。
- **接近中心性**：到所有点的平均距离（信息传播快慢）。
- **介数中心性**：经过该点的最短路径数量（桥梁/瓶颈）。
- **PageRank**：有向图随机游走稳态（重要性传播），是搜索引擎核心向量。
- **社区发现**：把网络分成"内部紧密、外部稀疏"的组（Louvain、谱聚类、标签传播）。

## D.4 Python 对应（NetworkX）

```python
import networkx as nx

G = nx.Graph()
G.add_edges_from([("A","B"), ("A","C"), ("B","D"), ("C","D"), ("D","E")])

nx.shortest_path(G, "A", "E")            # BFS 最短路
nx.dijkstra_path(G, "A", "E", weight="w")
nx.minimum_spanning_tree(G)
nx.degree_centrality(G)
nx.betweenness_centrality(G)
nx.pagerank(G)
nx.community.louvain_communities(G)

# 可视化
nx.draw(G, with_labels=True)
```

## D.5 常见误区

| 误区 | 正确 |
| ---- | ---- |
| 以为图只能用邻接矩阵 | 稀疏大图用邻接表；NetworkX 自动选择 |
| 无向图当有向图算 | `DiGraph` 与 `Graph` 分开；看边是否有方向 |
| 用最短路答"哪个点最重要" | 中心性指标多，先明确"重要"的定义 |
| 忽略权重 | 加权图算法 `dijkstra_path` 要指定 `weight` |
| 社区数固定 | 社区发现需要按分辨率/启发式调参，结果不唯一 |
