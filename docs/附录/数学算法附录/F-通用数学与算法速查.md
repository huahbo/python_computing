## F.2 常用公式卡

### 微积分
- `(x^n)' = n x^{n-1}`；`(e^x)' = e^x`；`(ln x)' = 1/x`
- 泰勒：`f(x+h) ≈ f(x) + f'(x) h + f''(x) h²/2`
- 数值微分（中心差分）：`f'(x) ≈ (f(x+h)-f(x-h))/(2h)`

### 线性代数
- `A^T` 转置；`(AB)^T = B^T A^T`；`tr(AB) = tr(BA)`
- 最小二乘：`x^ = (A^T A)^{-1} A^T b`（投影；数值上用 `lstsq`）
- SVD：`A = UΣV^T`；对称矩阵 `A = QΛQ^T`

### 概率统计
- `E[X] = Σ x p(x)`；`Var(X) = E[X²] - (E[X])²`
- 样本方差：`s² = Σ(x_i - x̄)²/(n-1)`
- 置信区间：`x̄ ± t_{α/2, n-1} · s/√n`
- 线性回归：`y = Xβ + ε`；`β^ = (X^T X)^{-1} X^T y`；`R² = 1 - SSE/SST`

### 机器学习
- 逻辑回归（sigmoid）：`p = 1/(1+e^{-θ^T x})`；损失 = 交叉熵
- 梯度下降：`θ ← θ - α·grad L`
- 正则化：Ridge `L + λ||θ||²`；Lasso `L + λ||θ||₁`

## F.3 复杂度与常用算法量级

| 运算 | 复杂度 | 备注 |
| ---- | ---- | ---- |
| 矩阵乘 `(n×n)` | `O(n³)` | 分治可略快；向量化库已优化 |
| 解方程组（LU） | `O(n³)` | 避免显式求逆 |
| 特征分解/SVD | 约 `O(n³)` | 只求前 k 个可加速 |
| FFT | `O(N log N)` | 比直接 DFT 的 `O(N²)` 快得多 |
| Dijkstra | `O((V+E) log V)`（堆） | 稠密/稀疏均可用 |
| 最小生成树 | `O(E log E)` | Kruskal |
| k-Means 一次迭代 | `O(n·k·d)` | 与样本数线性 |
| Python 纯循环 | 慢 | 用 NumPy 向量化（广播） |

## F.4 数值稳定性（科学计算必修）

1. **浮点误差**：`1e-16` 量级；比较用 `np.isclose` / `abs(a-b) < 1e-9`。
2. **条件数**：矩阵条件数大（病态）时，输入微小变化导致解剧变；先看 `np.linalg.cond(A)`。
3. **避免灾难性消去**：`sqrt(x²+1) - x` 当 x 很大；改用 `1/(sqrt(x²+1)+x)`。
4. **归一化**：优化/距离/聚类前对特征做标准化（`StandardScaler`）。
5. **对数域计算**：小概率连乘/超长乘积取 log；分类用 `log_proba` 数值更稳。
6. **随机可复现**：固定种子（`random_state` / `default_rng(seed)`）。

## F.5 可视化原则（配合第 5 章）

- 一图一信息；坐标轴标清楚；比较用同一尺度；
- 柱状图看类别、直方图看分布、散点看关系、折线看趋势；
- 图上标注单位、图例、样本量；颜色兼顾色盲（避免红绿并列）；
- 大数字用科学计数法/千分位；时间序列给坐标轴时间标签。
