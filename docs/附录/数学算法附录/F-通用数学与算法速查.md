## F.1 常用记号与希腊字母（讲解 + 速查）

数学里很多"看不懂"来自记号。先把它们认熟：

| 记号 | 含义 | | 记号 | 含义 |
| ---- | ---- | ---- | ---- | ---- |
| `Σ` | 求和 | | `∏` | 连乘 |
| `E[X]` | 期望 | | `Var(X)` | 方差 |
| `x^T` | 转置 | | `grad f` | 梯度 |
| `∂f/∂x` | 偏导 | | `∫` | 积分 |
| `λ` | 特征值/正则强度 | | `α` | 学习率 |
| `θ` | 参数/角度 | | `ε` | 误差/小量 |
| `≈` | 约等于 | | `<<` | 远小于 |

**读公式的口诀**：先找"求和/连乘"的范围，再看"指数/对数"在谁身上，最后看变量是矩阵还是标量。

## F.2 常用公式卡（速查）

### 微积分
- `(x^n)' = n x^{n-1}`；`(e^x)' = e^x`；`(ln x)' = 1/x`
- 泰勒：`f(x+h) ≈ f(x) + f'(x)h + f''(x)h²/2`
- 数值微分（中心差分）：`f'(x) ≈ (f(x+h) - f(x-h)) / (2h)`

### 线性代数
- `(AB)^T = B^T A^T`；`tr(AB) = tr(BA)`
- 最小二乘：`x^ = (A^T A)^{-1} A^T b`（数值上多用 `lstsq`）
- SVD：`A = UΣV^T`；对称矩阵：`A = QΛQ^T`

### 概率统计
- `E[X] = Σ x p(x)`；`Var(X) = E[X²] - (E[X])²`
- 样本方差：`s² = Σ(x_i - x̄)² / (n-1)`
- 置信区间：`x̄ ± t_{α/2, n-1} · s/√n`
- 线性回归：`y = Xβ + ε`，`β^ = (X^T X)^{-1} X^T y`，`R² = 1 - SSE/SST`

### 机器学习
- 逻辑回归（sigmoid）：`p = 1 / (1 + e^{-θ^T x})`；损失 = 交叉熵
- 梯度下降：`θ ← θ - α·grad L`
- 正则化：Ridge `L + λ||θ||²`；Lasso `L + λ||θ||₁`

## F.3 复杂度与常用算法量级（速查）

为什么"能算"和"算得动"是两回事？看复杂度。

| 运算 | 复杂度 | 备注 |
| ---- | ---- | ---- |
| 矩阵乘/解方程组（n×n） | `O(n³)` | 向量化库已优化；避免显式求逆 |
| 特征分解 / SVD | 约 `O(n³)` | 只求前 k 个可加速 |
| FFT | `O(N log N)` | 比直接 DFT 的 `O(N²)` 快得多 |
| Dijkstra | `O((V+E) log V)` | 用堆实现 |
| 最小生成树（Kruskal） | `O(E log E)` | 排序为主 |
| k-Means 一次迭代 | `O(n·k·d)` | 与样本数线性 |
| Python 纯循环 | 慢 | 用 NumPy 向量化/广播 |

**实践建议**：先写对，再量（`%timeit`）；大数据用向量化，循环只在必要时。

## F.4 数值稳定性（科学计算必修，讲解）

浮点数是有限精度的（约 15~16 位有效小数），所以"数学上对"的公式在电脑上可能"崩"：

1. **比较**：别用 `==` 比浮点；用 `np.isclose` / `abs(a-b) < 1e-9`。
2. **条件数**：`np.linalg.cond(A)` 大 → 病态，解对输入过敏；优先看它再"硬解"。
3. **灾难性消去**：`sqrt(x²+1) - x` 在大 `x` 时相减丢精度，改写 `1/(sqrt(x²+1)+x)`。
4. **缩放**：优化/距离/聚类前对特征标准化（`StandardScaler`）。
5. **对数域**：连乘小概率时取 log，避免下溢；分类看概率用 `log_proba`。
6. **可复现**：固定种子（`random_state` / `np.random.default_rng(seed)`）。

配一个手算直觉：`x = 10^8` 时，`sqrt(x²+1) - x` 用双精度算出来≈`0`（真正约 `5×10^{-9}`）——不是数学错了，是浮点"看不见"那么小的差。
