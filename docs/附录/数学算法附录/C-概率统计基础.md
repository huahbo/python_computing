## C.1 直觉故事：为什么不能只看平均分

假设两个班的平均分都是 75。甲班成绩清一色 74~76，乙班一半 50 分一半 100 分——平均分相同，但乙班的"不确定性"大得多。

所以描述数据至少要看两件事：**中心（用什么代表）** 和 **离散（数据有多散）**，最好再看**形状（分布）**。

- 均值 `x̄ = (1/n)Σ x_i`：常见但**怕极端值**；
- 中位数：排序中间值，稳健；
- 标准差 `s = sqrt(Σ(x_i - x̄)² / (n-1))`：离散程度；
- 分位数/箱线图：看分布尾巴、离群点。

## C.2 随机变量与分布（讲解）

### C.2.1 期望与方差

- **期望 `E[X] = Σ x·p(x)`**：长期平均。掷骰子，期望 `3.5`，尽管它从不会"等于 3.5"——期望是"中心的裁判"。
- **方差 `Var(X) = E[(X - E[X])²]`**：偏离平方的平均；标准差是回到原始量纲。
- 常用口诀：`Var(X) = E[X²] - (E[X])²`（手算方便）。

### C.2.2 常用分布

| 分布 | 记号 | 直觉 | 典型场景 |
| ---- | ---- | ---- | ---- |
| 正态 | `N(μ, σ²)` | 对称、钟形 | 测量误差、均值近似（中心极限定理） |
| 二项 | `B(n, p)` | n 次独立试验成功次数 | 点击率、产品质量 |
| 泊松 | `Poisson(λ)` | 单位时间事件数 | 订单到达、故障次数 |
| 均匀 | `U(a,b)` | 等概率 | 随机数生成、先验 |
| t / F / χ² | `t(n)` 等 | 小样本/方差比 | 检验、ANOVA |

**中心极限定理**（一定要记住）：大量独立同分布变量的**均值**近似正态，与原始分布无关。这解释了为什么"n 越大，样本均值越稳"，也是回归置信区间、t 检验的依据。

### C.2.3 协方差与相关

- 协方差 `Cov(X,Y)`：两个变量是否"同向变化"（数值与量纲有关）；
- 相关系数 `ρ = Cov / (σx·σy)`：归一化到 `[-1, 1]`。`ρ≈1` 强正相关；`0` 不线性相关（注意：可能还有非线性关系！）。

## C.3 统计推断：从样本到结论（讲解）

### C.3.1 参数估计与置信区间

- 点估计：用样本统计量猜总体参数（如 `x̄` 估计 `μ`）。
- 区间估计：给出一个范围并说明"可信度"。均值置信区间：

```text
x̄ ± t_{α/2, n-1} · s/√n
```

直觉：`s/√n` 是标准误（"平均值的抖动范围"），乘上 t 分位数就得到区间宽度。样本越大、标准差越小，区间越窄——这就是"数据越多越确信"的数学表达。

### C.3.2 假设检验：p 值到底在说什么

流程：
1. 立原假设 `H0`（例如"两种教学法平均成绩无差异"）；
2. 选统计量（`t`、`F`、`χ²`…）；
3. 算 **p 值**：在 `H0` 成立的假设下，看到"这么极端或更极端"数据的概率；
4. 约定 `α = 0.05`：`p < 0.05` 就拒绝 `H0`（但**不等于**"H0 被证伪"或"差异很大"）。

**常见检验速查**
| 检验 | 回答的问题 |
| ---- | ---- |
| 单样本 t / 双样本 t | 均值是否等于/不同 |
| 卡方 | 分类是否拟合、组间是否独立 |
| ANOVA (F) | 多组均值是否全相等 |
| KS | 分布形状是否一致 |

## C.4 回归与方差分析：建模视角（讲解）

### C.4.1 线性回归是"换了个视角的最小二乘"

模型：`y = β0 + β1 x1 + … + βk xk + ε`。OLS（普通最小二乘）就是求使残差平方和最小的系数——数学上正是附录 A 的最小二乘 `β^ = (X^T X)^{-1} X^T y`。

要讲清楚的假设（对推断重要）：
- **线性**（模型形式）、**独立**（样本间无系统性相关）、**同方差**（残差波动均匀）、**正态性**（残差近似正态）；
- 违背时：用稳健标准误、变换、加权或改用其他模型。

### C.4.2 好模型看什么

- `R² = 1 - SSE/SST`：解释的比例（越高越好，但过高要警惕过拟合）；
- **系数符号与大小**：实际含义（"每多 1 单位 x，y 平均变化 β"）；
- **p 值/置信区间**：这个系数"是否显著不为 0"；
- **残差图**：是否有趋势/异方差（比 R² 更诚实）。

手算小例子：数据 `(1,2), (2,4), (3,7)`，用一元回归算出的斜率约 `2.5`、截距约 `-0.5`——意思是"x 每加 1，y 平均加 2.5"（目测与数据一致）。

### C.4.3 ANOVA：多组到底有没有差异

ANOVA 检验 `H0: μ1 = μ2 = … = μk`，看的是**组间方差**与**组内方差**之比 `F`。F 大说明"组之间比组内随机波动更明显"。

## C.5 时间序列：和"普通回归"有什么不同（讲解）

| 概念 | 直觉 | 工具 |
| ---- | ---- | ---- |
| 平稳性 | 统计特性（均值/方差）不随时间漂移 | ADF 单位根检验 |
| 自相关 ACF | "现在"和"过去"的相关 | 判断 AR 阶数 |
| 差分 | `y_t - y_{t-1}` | 消除趋势/转平稳 |
| 移动平均/滚动 | 局部平均去噪 | `rolling` |
| 分解 | 趋势 + 季节 + 残差 | `seasonal_decompose` |
| ARIMA | AR（自回归）+ 差分 + MA | 预测/理解 |

关键区别：**时序不能当普通独立样本**——相邻点常相关，因此要先检验平稳性、看自相关，再用 ARIMA 等专门模型；否则回归的 p 值可能"虚假显著"。

## C.6 动手例题（选做：手算 + 验证）

**例：均值、标准差与置信区间**。样本 @BT@[68, 91, 55, 76, 88]@BT@：
- 均值 @BT@(68+91+55+76+88)/5 = 75.6@BT@；
- 样本标准差（用 n-1）约 @BT@14.0@BT@；
- 95% 置信区间：@BT@75.6 ± t_{0.025,4} × 14.0/√5 ≈ 75.6 ± 17.4@BT@ → 约 @BT@[58.2, 93.0]@BT@（区间很宽，因为样本只有 5 个）。

```python
import numpy as np
from scipy import stats
x = np.array([68, 91, 55, 76, 88])
print(x.mean(), x.std(ddof=1))
stats.t.interval(0.95, df=len(x)-1, loc=x.mean(), scale=stats.sem(x))
```

**例：相关性≠因果**。@BT@x = 1..10@BT@，@BT@y = x + 随机噪声@BT@ 相关系数接近 1，但若另有 @BT@z = 城市规模@BT@ 同时影响 x、y，则 x、y 的"高相关"可能只是共同原因造成——所以建模时要控制混杂变量。

## C.7 Python 对应（速查）

```python
import numpy as np, pandas as pd, statsmodels.api as sm
from scipy import stats

x = np.array([68, 91, 55, 76, 88])
np.mean(x); np.median(x); np.std(x, ddof=1); np.percentile(x, [25, 75])
pd.Series(x).describe()

stats.ttest_1samp(x, 60)          # 单样本 t 检验
stats.chisquare([10, 20, 30])      # 卡方拟合

X = sm.add_constant(np.array([[1.,2.],[2.,4.],[3.,7.]]))
model = sm.OLS(np.array([2.,4.,7.]), X).fit()
model.summary()                    # coef / p / R² / F

from statsmodels.tsa.seasonal import seasonal_decompose
df = pd.read_csv("data.csv", index_col=0, parse_dates=True)
seasonal_decompose(df["sales"], model="additive").plot()
```

| 你想要 | 用哪个 |
| ---- | ---- |
| 描述统计 | `Series.describe()` |
| 分布检验 | `scipy.stats` |
| 回归/ANOVA | `statsmodels.OLS / ols` |
| 时序分解 | `seasonal_decompose` |
| ARIMA | `statsmodels.tsa.arima.model.ARIMA` |

## C.8 常见误区 + 用在哪（双向）

| 误区 | 正确 |
| ---- | ---- |
| p 值小 = 影响大 | p 值与效应量是两回事；报告置信区间 + 效应量 |
| 只看均值 | 先画直方图/箱线图看分布 |
| 非平稳直接回归 | 先 ADF/差分；否则 p 值失真 |
| 相关系数当因果 | 相关 ≠ 因果 |
| 样本小也硬用正态近似 | 小样本用小样本检验/重抽样 |

## C.9 补充：假设检验实操清单

做检验前按这个清单走，能避开 80% 的坑：

1. **问题类型**：比较均值？比较分布？多组？时序？→ 选 t / 卡方 / ANOVA / KS / ADF；
2. **样本独立性**：同一批人前后测 → 配对检验，不是独立样本 t；
3. **正态性**：小样本看 QQ 图 / Shapiro 检验；明显偏态用非参数（如 Mann-Whitney）或自助法；
4. **多重比较**：一次做 20 次检验 → 用 Bonferroni / FDR 校正，否则"显著"可能是运气；
5. **报告**：给出 @BT@p@BT@ 值 + 效应量 + 置信区间，不单独报 "p<0.05"。

**一句话总结**：检验是"给结论找证据"，证据强度看效应量与区间宽度，不只看 p 值。
