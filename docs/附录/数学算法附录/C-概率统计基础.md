# 概率统计基础

> 一句话：概率给"不确定性"建模，统计从数据里"猜"出规律。本附录覆盖描述统计、常用分布、推断（检验/置信区间）、回归与时间序列。

## C.1 直觉与描述统计

- **随机变量**：取值带概率的变量。期望 `E[X]` = 中心位置；方差 `Var(X) = E[(X-E[X])²]` = 分散程度。
- **样本统计量**：从数据算出来的"估计"——均值、中位数、标准差、分位数、相关系数。
- **为什么先看分布**：均值会被极端值拉偏；分布形状（偏斜/厚尾）决定该用哪种方法。

常用量速查：

| 量 | 定义 | 说明 |
| ---- | ---- | ---- |
| 均值 `μ^ = (1/n)Σx_i` | 集中趋势 | 受异常值影响 |
| 中位数 | 排序中间值 | 稳健 |
| 方差/标准差 | `s² = Σ(x_i - x̄)²/(n-1)` | 离散程度（样本用 n-1） |
| 协方差/相关 | `Cov(X,Y)`、`ρ = Cov/(σx σy)` | 线性相关方向/强度 |
| 分位数 | 排序后百分比位置 | Q1/Q3/IQR（箱线图） |

## C.2 常用分布速查

| 分布 | 记号 | 用在哪 |
| ---- | ---- | ---- |
| 正态 | `N(μ, σ²)` | 近似很多现象；中心极限定理的主角 |
| 二项 | `B(n, p)` | 成功/失败次数 |
| 泊松 | `Poisson(λ)` | 一段时间内事件数 |
| 均匀 | `U(a, b)` | 随机数/先验 |
| t / F / χ² | `t(n)`, `F`, `χ²` | 小样本推断/方差分析 |

> **中心极限定理**：大量独立同分布随机变量的均值，近似正态分布——这是很多统计方法（包括回归的置信区间）的底气。

## C.3 统计推断：检验与置信区间

- **参数估计**：点估计（均值）→ 区间估计（置信区间：`x̄ ± t_{α/2}·s/√n`）。
- **假设检验**：先立原假设 `H0`（如"均值=0"），看数据在 `H0` 下多"极端"（p 值）；`p < 0.05` → 拒绝 `H0`。
- **两类错误**：第一类（误拒，α）、第二类（漏拒，β）；功效 = 1-β。
- **常见检验**：t 检验（均值）、卡方（拟合/列联）、F/ANOVA（多组均值）、KS（分布）。
- **重要提醒**：p 值小 ≠ 实际重要；报告效应量 + 置信区间。

## C.4 回归与方差分析（建模视角）

- **线性回归**：`y = β0 + β1x1 + … + ε`；OLS 最小化残差平方和（附录 A 最小二乘）。
- **假设**：线性、独立、同方差、正态（对推断）；违背时用稳健标准误/变换。
- **`R²`**：解释变量能解释的变异比例（`R² = 1 - SSE/SST`），过大要提防过拟合。
- **ANOVA**：检验多个组的均值是否相等（`F` 检验，组间方差/组内方差）。
- **逻辑回归**：把线性预测过 sigmoid 映射成概率：`P(y=1) = σ(β^T x)`；损失用交叉熵（与附录 E 衔接）。

## C.5 时间序列基础

| 概念 | 直觉 | 常用工具 |
| ---- | ---- | ---- |
| 平稳性 | 统计特性不随时间漂移 | 单位根检验（ADF） |
| 自相关/ACF | 与过去的相关 | 确定滞后阶数 |
| 差分 | `y_t - y_{t-1}` 消除趋势 | 转平稳 |
| 移动平均/平滑 | 去噪/看趋势 | `rolling` |
| 分解 | 趋势 + 季节 + 残差 | `seasonal_decompose` |
| ARIMA | AR（自回归）+ I（差分）+ MA（移动平均误差） | 预测/理解 |

## C.6 Python 对应

```python
import numpy as np, pandas as pd, statsmodels.api as sm
from scipy import stats

x = np.array([68, 91, 55, 76, 88])
print(np.mean(x), np.std(x, ddof=1), np.percentile(x, 75))

# 单样本 t 检验
stats.ttest_1samp(x, 60)

# 线性回归
X = sm.add_constant(np.array([1, 2, 3, 4, 5.]))
model = sm.OLS(np.array([2, 4, 5, 8, 9]), X).fit()
print(model.summary())   # 看 coef / p / R²

# 时间序列分解
from statsmodels.tsa.seasonal import seasonal_decompose
df = pd.read_csv("data.csv", index_col=0, parse_dates=True)
seasonal_decompose(df["sales"], model="additive").plot()
```

## C.7 常见误区

| 误区 | 正确 |
| ---- | ---- |
| p 值小 = 影响大 | p 值是"在 H0 下看到这个数据的概率"，与效应量是两回事 |
| 忽视样本量 | 样本大时微小差异也显著；看置信区间宽度 |
| 用均值代替看分布 | 先画直方图/箱线图 |
| 非平稳直接回归 | 时序先检验平稳性/差分 |
| 把相关系数当因果 | 相关 ≠ 因果 |
