\section{E.1
直觉故事：为什么模型会''学偏''}\label{e.1-ux76f4ux89c9ux6545ux4e8bux4e3aux4ec0ux4e48ux6a21ux578bux4f1aux5b66ux504f}

假设你用''学习时长''预测''考试成绩''，数据点大致在一条斜线附近。线性回归的任务就是找到''最合适的斜率与截距''。

但换个场景：只有 5 个学生，你加了 10
个特征（连''头发长度''都算上）。线性回归可以\textbf{完美穿过所有 5
个点}------看起来成绩很漂亮，但换一批学生就崩了。这就是\textbf{过拟合}：模型记熟了训练数据，却没学到普适规律。

所以机器学习的核心矛盾是：\textbf{如何在''训练集上够准''和''新数据上也准''之间平衡。}
答案是：任务框架（损失）+ 优化算法 + 验证评估 + 正则化/恰当复杂度。

\subsection{E.2.2
损失函数：怎么算''错得有多离谱''}\label{e.2.2-ux635fux5931ux51fdux6570ux600eux4e48ux7b97ux9519ux5f97ux6709ux591aux79bbux8c31}

\begin{itemize}
\tightlist
\item
  \textbf{回归·均方误差
  MSE}：\texttt{L\ =\ (1/n)Σ(y\_i\ -\ f(x\_i))²}。对离群点敏感；RMSE
  是它的平方根，量纲与 y 一致。
\item
  \textbf{回归·平均绝对误差
  MAE}：\texttt{(1/n)Σ\textbar{}y\_i\ -\ f(x\_i)\textbar{}}，更稳健。
\item
  \textbf{分类·交叉熵}：\texttt{L\ =\ -Σ\ y\_i\ log(p\_i)}。鼓励''预测概率对且自信''；与逻辑回归配合自然。
\item
  \textbf{聚类·k-Means}：点到最近中心的平方距离之和（WCSS），肘部法看拐点选
  k。
\end{itemize}

\subsection{E.2.3
优化：把损失调小}\label{e.2.3-ux4f18ux5316ux628aux635fux5931ux8c03ux5c0f}

梯度下降：\texttt{θ\ ←\ θ\ -\ α·grad\ L(θ)}。

手算直觉：设
\texttt{L(θ)\ =\ (θ\ -\ 3)²}，\texttt{θ0\ =\ 1}，\texttt{grad\ L\ =\ 2(θ-3)\ =\ -4}。取
\texttt{α\ =\ 0.5}：\texttt{θ\ ←\ 1\ -\ 0.5×(-4)\ =\ 3}，一步到最优。取
\texttt{α\ =\ 2}：\texttt{θ\ ←\ 1\ -\ 2×(-4)\ =\ 9}，弹到另一侧------这就是\textbf{学习率太大震荡}。实际操作中，还要做特征缩放（否则不同特征的学习率感受不同）。

\textbf{正则化}（在损失里加惩罚）：Ridge 加
\texttt{λ\textbar{}\textbar{}θ\textbar{}\textbar{}²}（系数不过大），Lasso
加
\texttt{λ\textbar{}\textbar{}θ\textbar{}\textbar{}₁}（鼓励稀疏）。本质是把''拟合''和''模型复杂度''放在一个天平上。

\section{E.3

\subsection{E.3.1
训练/验证/测试}\label{e.3.1-ux8badux7ec3ux9a8cux8bc1ux6d4bux8bd5}

\begin{itemize}
\tightlist
\item
  \textbf{训练集}：学参数；\textbf{验证集/交叉验证}：挑超参数；\textbf{测试集}：最后评估一次。
\item
  交叉验证（\texttt{k-fold}）：数据切 k 份轮流当验证集，结果更稳。
\item
  \textbf{千万别用测试集反复调参}------那等于把测试集''教''给模型。
\end{itemize}

\subsection{E.3.2 偏差-方差}\label{e.3.2-ux504fux5dee-ux65b9ux5dee}

总误差 ≈ 偏差² + 方差 + 噪声： - 太简单模型：高偏差（欠拟合）； -
太复杂模型：高方差（过拟合，训练好、测试差）； -
调复杂度（深度/正则/特征数）就是在这两者间找平衡。

\textbf{决策顺序建议}：问题类型 → 特征处理（缺失/缩放/编码）→
简单模型基线 → 评估 → 调复杂度（正则/深度）→ 交叉验证 → 最终测试一次。
