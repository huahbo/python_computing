\subsection{C.2.3
中心极限定理（必须理解）}\label{c.2.3-ux4e2dux5fc3ux6781ux9650ux5b9aux7406ux5fc5ux987bux7406ux89e3}

大量\textbf{独立同分布}随机变量之和（或均值）的分布近似正态，与原始分布无关：

\[\frac{\bar{X}-\mu}{\sigma/\sqrt n}\xrightarrow{ n\to\infty } N(0,1)\]

这解释了\textbf{为什么样本均值越稳}、为什么 t
检验/置信区间成立。注意它要求''独立同分布''：时间序列相邻样本相关时不满足，不能直接套。

\subsection{C.2.4
协方差与相关}\label{c.2.4-ux534fux65b9ux5deeux4e0eux76f8ux5173}

\(\mathrm{Cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)]\)；相关系数
\(\rho=\dfrac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1]\)。\(\rho=1\)
完全正线性相关；\(\rho=0\)
仅表示\textbf{不线性}相关（可能存在非线性关系！）。

\section{C.3
统计推断（重点、难点）}\label{c.3-ux7edfux8ba1ux63a8ux65adux91cdux70b9ux96beux70b9}

\subsection{C.3.1
置信区间：从''估计值''到''可靠性''}\label{c.3.1-ux7f6eux4fe1ux533aux95f4ux4eceux4f30ux8ba1ux503cux5230ux53efux9760ux6027}

均值置信区间：

\[\bar{x}\pm t_{\alpha/2,n-1}\cdot\frac{s}{\sqrt n}\]

\begin{itemize}
\tightlist
\item
  \(s/\sqrt n\) = 标准误：均值的''抖动范围''；
\item
  乘 \(t\) 分位数把''1 个标准误''扩成''95\% 覆盖''；
\item
  样本越大/波动越小 → 区间越窄 → ``越确信''。
\end{itemize}

\subsection{C.3.2 假设检验：p

\textbf{两类错误}：\(\alpha\)（第一类，误拒）、\(\beta\)（第二类，漏拒）；\textbf{功效}
\(1-\beta\)。样本太小 → 功效低 →

\textbf{多重比较}：一次做 20 次检验，纯运气也可能''显著''几次 → 用
Bonferroni/FDR 校正。

\subsection{C.4.1 线性回归 =
换视角的最小二乘}\label{c.4.1-ux7ebfux6027ux56deux5f52-ux6362ux89c6ux89d2ux7684ux6700ux5c0fux4e8cux4e58}

模型 \(y=\beta_0+\beta_1x_1+\cdots+\beta_kx_k+\varepsilon\)；OLS 解：

\[\hat{\beta}= (X^TX)^{-1}X^Ty\]

要求（推断时）：线性、独立、同方差、残差正态。违背时用稳健标准误/变换。

\subsection{C.4.2 怎么评价}\label{c.4.2-ux600eux4e48ux8bc4ux4ef7}

\begin{itemize}
\tightlist
\item
  \(R^2=1-\mathrm{SSE}/\mathrm{SST}\)：解释变异比例（过高要警惕过拟合）；
\item
  系数符号、大小、p 值、置信区间：每个变量的''作用方向/强度/显著性''；
\item
  \textbf{残差图}：比 \(R^2\) 更诚实（看趋势/异方差/离群点）。
\end{itemize}

手算：\((1,2),(2,4),(3,7)\) 一元回归斜率约 2.5、截距约 -0.5。

ANOVA：多组到底有没有差异}\label{c.4.3-anovaux591aux7ec4ux5230ux5e95ux6709ux6ca1ux6709ux5deeux5f02}

\[F=\frac{\text{组间方差}/\text{(组数-1)}}{\text{组内方差}/\text{(n-组数)}}\]

F 大 = ``组间差异比组内随机波动更明显''。

\section{C.11
综合案例：一份''完整统计报告''的骨架}\label{c.11-ux7efcux5408ux6848ux4f8bux4e00ux4efdux5b8cux6574ux7edfux8ba1ux62a5ux544aux7684ux9aa8ux67b6}

\textbf{问题}：某班两组练习方式（A/B）的成绩是否不同？影响分数的因素还有哪些？

步骤：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{描述统计}：每组均值/中位数/标准差/箱线图（C.1）；
\item
  \textbf{差异性检验}：先检查正态性（Shapiro），再用独立样本 t 检验或
  Mann-Whitney；报告 p 值与置信区间（C.3）；
\item
  \textbf{回归}：把''练习方式''与''前测成绩''放进线性回归，看系数与 p
  值（C.4）；
\item
  \textbf{时序（若有）}：对周销量做分解/ADF，再决定用差分或
  ARIMA（C.5）；
\item
  \textbf{结论模板}：``在控制了 X 后，A 组平均高 delta 分（95\%CI
  {[}\ldots{]}），p=\ldots；但样本量小，需谨慎解释。''
\end{enumerate}

参考要点代码：

\begin{verbatim}
import pandas as pd, statsmodels.api as sm
from scipy import stats
df = pd.read_csv("scores.csv")
a = df.loc[df.group == "A", "score"]; b = df.loc[df.group == "B", "score"]
print(stats.ttest_ind(a, b))
X = sm.add_constant(pd.get_dummies(df[["group", "pretest"]]))
print(sm.OLS(df.score, X).fit().summary())
\end{verbatim}

\textbf{反思}：统计报告不是''跑一个显著性''就完事；分布、检验假设、效应量、置信区间都要交代。

\section{C.10
例题集（深入练习）}\label{c.10-ux4f8bux9898ux96c6ux6df1ux5165ux7ec3ux4e60}

\textbf{例 1：t 检验完整流程（手算路径）}。样本
\([68,91,55,76,88]\)，检验 \(H_0:\mu=60\)。均值 \(75.6\)，标准误
\(s/\sqrt n\approx 14.0/2.236\approx 6.26\)，\(t=(75.6-60)/6.26\approx 2.49\)。查
\(\mathrm{df}=4\) 的 \(t\) 表，双尾 \(p\approx 0.067>0.05\) →
不显著（样本太小）。
