假设两个班的平均分都是 75。甲班成绩清一色 74\textasciitilde76，乙班一半
50 分一半 100 分------平均分相同，但乙班的''不确定性''大得多。

所以描述数据至少要看两件事：\textbf{中心（用什么代表）} 和
\textbf{离散（数据有多散）}，最好再看\textbf{形状（分布）}。

\begin{itemize}
\tightlist
\item
  均值 \texttt{x̄\ =\ (1/n)Σ\ x\_i}：常见但\textbf{怕极端值}；
\item
  中位数：排序中间值，稳健；
\item
  标准差 \texttt{s\ =\ sqrt(Σ(x\_i\ -\ x̄)²\ /\ (n-1))}：离散程度；
\item
  分位数/箱线图：看分布尾巴、离群点。
\end{itemize}

\textbf{中心极限定理}（一定要记住）：大量独立同分布变量的\textbf{均值}近似正态，与原始分布无关。这解释了为什么''n
越大，样本均值越稳''，也是回归置信区间、t 检验的依据。

直觉：\texttt{s/√n} 是标准误（``平均值的抖动范围''），乘上 t

\subsection{C.3.2 假设检验：p
值到底在说什么}\label{c.3.2-ux5047ux8bbeux68c0ux9a8cp-ux503cux5230ux5e95ux5728ux8bf4ux4ec0ux4e48}

流程： 1. 立原假设 \texttt{H0}（例如''两种教学法平均成绩无差异''）； 2.
选统计量（\texttt{t}、\texttt{F}、\texttt{χ²}\ldots）； 3. 算 \textbf{p
值}：在 \texttt{H0} 成立的假设下，看到''这么极端或更极端''数据的概率；
4. 约定 \texttt{α\ =\ 0.05}：\texttt{p\ \textless{}\ 0.05} 就拒绝
\texttt{H0}（但\textbf{不等于}''H0 被证伪''或''差异很大''）。

分类是否拟合、组间是否独立 \textbar{} \textbar{} ANOVA (F) \textbar{}
多组均值是否全相等 \textbar{} \textbar{} KS \textbar{} 分布形状是否一致

\section{C.4
回归与方差分析：建模视角（讲解）}\label{c.4-ux56deux5f52ux4e0eux65b9ux5deeux5206ux6790ux5efaux6a21ux89c6ux89d2ux8bb2ux89e3}

\subsection{C.4.1
线性回归是''换了个视角的最小二乘''}\label{c.4.1-ux7ebfux6027ux56deux5f52ux662fux6362ux4e86ux4e2aux89c6ux89d2ux7684ux6700ux5c0fux4e8cux4e58}

模型：\texttt{y\ =\ β0\ +\ β1\ x1\ +\ …\ +\ βk\ xk\ +\ ε}。OLS（普通最小二乘）就是求使残差平方和最小的系数------数学上正是附录
A 的最小二乘 \texttt{β\^{}\ =\ (X\^{}T\ X)\^{}\{-1\}\ X\^{}T\ y}。

要讲清楚的假设（对推断重要）： -
\textbf{线性}（模型形式）、\textbf{独立}（样本间无系统性相关）、\textbf{同方差}（残差波动均匀）、\textbf{正态性}（残差近似正态）；
- 违背时：用稳健标准误、变换、加权或改用其他模型。

\subsection{C.4.2
好模型看什么}\label{c.4.2-ux597dux6a21ux578bux770bux4ec0ux4e48}

\begin{itemize}
\tightlist
\item
  \texttt{R²\ =\ 1\ -\ SSE/SST}：解释的比例（越高越好，但过高要警惕过拟合）；
\item
  \textbf{系数符号与大小}：实际含义（``每多 1 单位 x，y 平均变化 β''）；
\item
  \textbf{p 值/置信区间}：这个系数''是否显著不为 0''；
\item
  \textbf{残差图}：是否有趋势/异方差（比 R² 更诚实）。
\end{itemize}

手算小例子：数据 \texttt{(1,2),\ (2,4),\ (3,7)}，用一元回归算出的斜率约
\texttt{2.5}、截距约 \texttt{-0.5}------意思是''x 每加 1，y 平均加
2.5''（目测与数据一致）。

\subsection{C.4.3
ANOVA：多组到底有没有差异}\label{c.4.3-anovaux591aux7ec4ux5230ux5e95ux6709ux6ca1ux6709ux5deeux5f02}

ANOVA 检验
\texttt{H0:\ μ1\ =\ μ2\ =\ …\ =\ μk}，看的是\textbf{组间方差}与\textbf{组内方差}之比
\texttt{F}。F 大说明''组之间比组内随机波动更明显''。

\section{C.9
补充：假设检验实操清单}\label{c.9-ux8865ux5145ux5047ux8bbeux68c0ux9a8cux5b9eux64cdux6e05ux5355}

做检验前按这个清单走，能避开 80\% 的坑：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{问题类型}：比较均值？比较分布？多组？时序？→ 选 t / 卡方 /
  ANOVA / KS / ADF；
\item
  \textbf{样本独立性}：同一批人前后测 → 配对检验，不是独立样本 t；
\item
  \textbf{正态性}：小样本看 QQ 图 / Shapiro 检验；明显偏态用非参数（如
  Mann-Whitney）或自助法；
\item
  \textbf{多重比较}：一次做 20 次检验 → 用 Bonferroni / FDR
  校正，否则''显著''可能是运气；
\item
  \textbf{报告}：给出 @BT@p@BT@ 值 + 效应量 + 置信区间，不单独报
  ``p\textless0.05''。
\end{enumerate}

\textbf{一句话总结}：检验是''给结论找证据''，证据强度看效应量与区间宽度，不只看
p 值。
