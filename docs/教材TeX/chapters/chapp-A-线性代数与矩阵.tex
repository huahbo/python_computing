\section{A.1
直觉：向量、线性组合与线性变换}\label{a.1-ux76f4ux89c9ux5411ux91cfux7ebfux6027ux7ec4ux5408ux4e0eux7ebfux6027ux53d8ux6362}

\begin{itemize}
\tightlist
\item
  \textbf{向量}：既有大小又有方向；在数据里，一行记录就是一个向量（\texttt{{[}身高,\ 体重,\ 年龄{]}}）。
\item
  \textbf{线性组合}：\texttt{c1·v1\ +\ c2·v2}：把若干向量按比例''混''起来。
\item
  \textbf{矩阵 = 线性变换}：\texttt{A} 把向量 \texttt{x} 变成
  \texttt{Ax}（旋转、拉伸、投影）。矩阵乘法 \texttt{AB} = 先做
  \texttt{B} 再做
  \texttt{A}，所以\textbf{矩阵乘法一般不可交换}（\texttt{AB\ ≠\ BA}）。
\item
  \textbf{线性方程组 \texttt{Ax\ =\ b}}：问''哪个向量经过 \texttt{A}
  变换会变成 \texttt{b}``------即把 \texttt{b} 表示为 \texttt{A}
  的列向量的线性组合。有唯一解 等价于 \texttt{A}
  可逆（列向量线性无关）。
\end{itemize}

\section{A.3 算法思路}\label{a.3-ux7b97ux6cd5ux601dux8def}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{高斯消元 → LU}：把解方程组变成''前代 + 回代''，复杂度
  \texttt{O(n\^{}3)}；有部分主元策略时数值更稳。
\item
  \textbf{特征值问题}：找一个''方向''，矩阵作用后只缩放。求
  \texttt{Av\ =\ λv} 等价于找 \texttt{det(A\ -\ λI)\ =\ 0}
  的根；对称矩阵特征值全是实数，且特征向量正交（SVD 是它的推广）。
\item
  \textbf{SVD}：\texttt{A\ =\ UΣV\^{}T}，其中 \texttt{U}/\texttt{V}
  是正交阵，\texttt{Σ} 是对角阵（奇异值降序）。奇异值大小 =
  该方向''重要性''；取前 \texttt{k}
  个奇异值即得到''最优低秩近似''（Eckart--Young
  定理）。用途：图像压缩、主成分分析（PCA）、伪逆
  \texttt{A\^{}+\ =\ VΣ\^{}\{-1\}U\^{}T}。
\item
  \textbf{最小二乘的几何}：把 \texttt{b}
  投影到列空间，误差向量与列空间垂直；\texttt{x\^{}}
  是离解最近的可行解。加
  \texttt{λ\textbar{}\textbar{}x\textbar{}\textbar{}\^{}2}（岭回归）可防病态/过拟合。
\end{enumerate}
