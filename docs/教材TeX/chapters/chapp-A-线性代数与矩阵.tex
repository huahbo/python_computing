\section{A.1
直觉故事：矩阵到底在干什么}\label{a.1-ux76f4ux89c9ux6545ux4e8bux77e9ux9635ux5230ux5e95ux5728ux5e72ux4ec0ux4e48}

很多同学背熟了矩阵乘法，却不知道它在''算什么''。从一个具体问题开始：

\begin{quote}
一家店卖两种套餐：A 套餐（米饭 1 份 + 鸡肉 2 份），B 套餐（米饭 2 份 +
鸡肉 1 份）。卖出 3 份 A、2 份 B，一共用了多少米饭和鸡肉？
\end{quote}

卖出数量写成向量 \(x=(3,2)\)；A、B 套餐用料写成列向量 \((1,2)\) 与
\((2,1)\)。总用料就是\textbf{线性组合}：

\[\text{米饭} = 3\times 1 + 2\times 2 = 7,\qquad \text{鸡肉} = 3\times 2 + 2\times 1 = 8\]

写成矩阵：

\[\begin{bmatrix} 1 & 2 \\ 2 & 1 \end{bmatrix} \begin{bmatrix} 3 \\ 2 \end{bmatrix} = \begin{bmatrix} 7 \\ 8 \end{bmatrix}\]

这个例子说明三件事：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{向量是''配比''}：一行数据、一份订单、一个状态，都可以是一个向量；
\item
  \textbf{矩阵是''线性变换的约定''}：\(A\)
  的每一列是一种''原料配方''，\(Ax\) 就是按 \(x\) 的比例把各列混合起来；
\item
  \textbf{矩阵乘法 = 复合变换}：先做 \(B\) 再做
  \(A\)，顺序不能换------所以一般 \(AB\ne BA\)。
\end{enumerate}

\subsection{A.2.2
逆、行列式与秩：能否把变换''倒回去''}\label{a.2.2-ux9006ux884cux5217ux5f0fux4e0eux79e9ux80fdux5426ux628aux53d8ux6362ux5012ux56deux53bb}

\begin{itemize}
\tightlist
\item
  \textbf{逆} \(A^{-1}\)：把变换倒着做一遍，\(A^{-1}A=I\)；
\item
  \textbf{行列式} \(\det(A)\)：变换后''体积''放大的倍数；\(\det(A)=0\)
  表示被压扁（不可逆）；
\item
  \textbf{秩}
  \(\mathrm{rank}(A)\)：变换后空间的真正维度（列向量中线性无关的个数）；满秩方阵才可逆。
\end{itemize}

例子：\(A=\begin{bmatrix}2&1\\1&2\end{bmatrix}\)。\(\det(A)=4-1=3\ne 0\)，可逆；\(A^{-1}=\frac{1}{3}\begin{bmatrix}2&-1\\-1&2\end{bmatrix}\)。而
\(B=\begin{bmatrix}1&2\\2&4\end{bmatrix}\)
两列成比例，\(\mathrm{rank}(B)=1\)，\(\det(B)=0\)------它把平面压成一条线，\(Bx=b\)
要么无解要么无穷多解。

\subsection{A.2.3
特征值与特征向量：变换的''不动轴''}\label{a.2.3-ux7279ux5f81ux503cux4e0eux7279ux5f81ux5411ux91cfux53d8ux6362ux7684ux4e0dux52a8ux8f74}

定义：若 \(Av=\lambda v\)（\(v\ne 0\)），则 \(v\)
是特征向量，\(\lambda\)
是特征值。人话：\textbf{有的方向被矩阵只''拉伸''不''拐弯''，拉伸倍数是特征值}。

对 \(A\) 手算：\(\det(A-\lambda I)=(A-\lambda I)\) 展开得
\(\lambda_1=3\)（方向 \((1,1)\)）、\(\lambda_2=1\)（方向
\((1,-1)\)）。即：沿对角线方向放 3 倍、沿反对角线方向不动。

用途： - \textbf{对称矩阵}：\(A=Q\Lambda Q^T\)（\(Q\)
正交），坐标轴转成''特征方向''后问题立刻解耦------PCA 就是找这些方向； -
\textbf{幂迭代 / PageRank /
马尔可夫链稳态}：都在找最大特征值对应的特征向量。

\begin{quote}
手算展开式：\(\begin{vmatrix}2-\lambda & 1\\1 & 2-\lambda\end{vmatrix}=(2-\lambda)^2-1=0\)，即
\(\lambda=1\) 或 \(3\)。
\end{quote}

\section{A.3
深入：分解与算法（重点、难点）}\label{a.3-ux6df1ux5165ux5206ux89e3ux4e0eux7b97ux6cd5ux91cdux70b9ux96beux70b9}

\subsection{A.3.1 解方程组：高斯消元与
LU}\label{a.3.1-ux89e3ux65b9ux7a0bux7ec4ux9ad8ux65afux6d88ux5143ux4e0e-lu}

求解 \(Ax=b\) 最直接是高斯消元（上三角 + 回代）。消元等价于
\(A=LU\)：\textbf{一次分解、多次求解}，解多组 \(b\) 时很划算。

\begin{itemize}
\tightlist
\item
  复杂度
  \(O(n^3)\)；必须\textbf{部分主元}（选最大元素当主元），避免小除数放大误差；
\item
  代码：\texttt{np.linalg.solve}（带主元的 LU），\textbf{不要}用
  \texttt{np.linalg.inv(A)\ @\ b}。
\end{itemize}

\subsection{A.3.2
特征值分解：对称矩阵为什么''好''}\label{a.3.2-ux7279ux5f81ux503cux5206ux89e3ux5bf9ux79f0ux77e9ux9635ux4e3aux4ec0ux4e48ux597d}

\begin{itemize}
\tightlist
\item
  一般方阵：\(A=V\Lambda V^{-1}\)（可对角化时）。特征向量可能不正交，且可能是复数；
\item
  \textbf{对称矩阵}：\(A=A^T\)
  时特征值全是实数，特征向量可正交归一：\(A=Q\Lambda Q^T\)。此时
  \(A^k=Q\Lambda^k Q^T\)，求幂、求逆、判断正定都极简单；
\item
  用途：二次型分析（\(x^TAx\) 的正定性 =\textgreater{}
  凸性）、PCA、谱聚类、稳定性分析。
\end{itemize}

\subsection{A.3.3
SVD：最重要的一段（本科必会）}\label{a.3.3-svdux6700ux91cdux8981ux7684ux4e00ux6bb5ux672cux79d1ux5fc5ux4f1a}

\textbf{定理（SVD）}：任意 \(m\times n\) 矩阵 \(A\) 可写成

\[A = U\Sigma V^T\]

其中
\(U\)（\(m\times m\)）、\(V\)（\(n\times n\)）是正交矩阵，\(\Sigma\) 是
\(m\times n\) 的''对角矩阵''，对角线元素
\(\sigma_1\ge\sigma_2\ge\cdots\ge 0\) 叫\textbf{奇异值}。

\textbf{几何解读（三步）}：先旋转（\(V^T\)）→ 逐方向缩放（\(\Sigma\)）→
再旋转（\(U\)）。奇异值 = 每个方向的''重要性/能量''。

\textbf{与特征值的关系}：\(A^TA\) 的特征值是 \(\sigma_i^2\)，\(V\) 是
\(A^TA\) 的特征向量；\(AA^T\) 给出 \(U\)。所以
SVD''任意矩阵都能做''，是特征分解的''万能推广''。

\textbf{三个用途（考试/作业高频）}：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{最优低秩近似}（Eckart--Young）：保留前 \(k\) 大奇异值得到
  \(A_k\)，是所有秩 \(k\) 矩阵中与 \(A\) 的 Frobenius
  距离最小者。\[\|A-A_k|_F^2 = \sum_{i>k}\sigma_i^2\] ------
  图像压缩、去噪、推荐系统都靠它。
\item
  \textbf{PCA}：对数据中心化后的矩阵做 SVD，\(V\) 的前 \(k\)
  列就是主成分方向；奇异值平方占比 = 解释方差比。
\item
  \textbf{伪逆与最小二乘}：\(A^{+}=V\Sigma^{-1}U^T\)（\(\Sigma^{-1}\)
  取非零奇异值的倒数），比正规方程 \((A^TA)^{-1}A^Tb\)
  数值更稳（避免把条件数平方）。
\end{enumerate}

\textbf{数值上怎么算}：实际用 QR 迭代/分治法（库内实现），复杂度约
\(O(mn^2)\)（薄 SVD）。代码只需 \texttt{np.linalg.svd}。

\subsection{A.3.4
最小二乘与正则化}\label{a.3.4-ux6700ux5c0fux4e8cux4e58ux4e0eux6b63ux5219ux5316}

超定方程组 \(Ax\approx b\) 的最小二乘解：

\[x^{*} = \arg\min_x\|Ax-b|_2^2 \quad\Longrightarrow\quad A^TAx = A^Tb\]

\begin{itemize}
\tightlist
\item
  几何：把 \(b\) 投影到 \(A\) 的列空间，误差向量与列空间垂直；
\item
  数值：优先 \(A^{+}b\)（SVD）或 QR；直接求 \((A^TA)^{-1}\)
  会平方条件数；
\item
  加惩罚
  \(\lambda\|x|^2\)（岭回归）：在''拟合''与''不放大''之间取舍------这就是第
  8 章正则化的数学原型。
\end{itemize}

\section{A.9 综合案例：SVD
图像压缩（串联全附录）}\label{a.9-ux7efcux5408ux6848ux4f8bsvd-ux56feux50cfux538bux7f29ux4e32ux8054ux5168ux9644ux5f55}

\textbf{目标}：把一张灰度图当作矩阵 A，用 SVD 保留前 k
个奇异值，观察压缩率与重构误差。

完整流程：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  读灰度图 → 数值矩阵 A（m 行 n 列）；
\item
  做薄 SVD：A = U S Vt（S 是奇异值向量）；
\item
  取前 k 个：A\_k = U{[}:, :k{]} @ diag(S{[}:k{]}) @ Vt{[}:k, :{]}；
\item
  比较：存储量从 m\emph{n 降到 k}(m+n)；误差 = 被丢弃奇异值的平方和。
\end{enumerate}

手算小例：2×2 矩阵 A = {[}{[}1,1{]},{[}1,-1{]}{]}，奇异值都是
sqrt(2)。若保留 k=1：A\_1 = U1 * sqrt(2) *
V1\^{}T，会丢掉''反对角信息''------对这张图来说信息全无，说明''前 k
个''要按奇异值落差选。

参考要点代码（四空格缩进可直接运行）：

\begin{verbatim}
import numpy as np, matplotlib.pyplot as plt
A = np.random.default_rng(0).random((60, 60))
U, S, Vt = np.linalg.svd(A, full_matrices=False)
for k in [5, 15, 30]:
    Ak = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
    print(k, "MSE:", np.mean((A - Ak) ** 2), "压缩比:", A.size / (k * (A.shape[0] + A.shape[1])))
\end{verbatim}

\textbf{反思}：SVD
是''数据驱动压缩''的数学核心；学完写一句结论：``奇异值大的方向 =
主要信息；保留它们的低秩近似 = 最优压缩。''

\textbf{例
1：特征值代入法}。\(A=\begin{bmatrix}2&1\\1&2\end{bmatrix}\)，特征多项式
\(\det(A-\lambda I)=\begin{vmatrix}2-\lambda&1\\1&2-\lambda\end{vmatrix}=(2-\lambda)^2-1=0\)，得
\(\lambda=1,3\)。代入
\(\lambda=3\)：\(\begin{bmatrix}-1&1\\1&-1\end{bmatrix}v=0\) →
\(v=(1,1)\)。这就是''先求特征值、再解齐次方程组''的标准流程。
