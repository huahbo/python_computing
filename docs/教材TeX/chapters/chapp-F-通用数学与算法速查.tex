\subsection{微积分}\label{ux5faeux79efux5206}

\begin{itemize}
\tightlist
\item
  \((x^n)'=nx^{n-1}\)；\((e^x)'=e^x\)；\((\ln x)'=1/x\)
\item
  泰勒：\(f(x+h)\approx f(x)+f'(x)h+\tfrac12 f''(x)h^2\)
\item
  数值微分（中心差分）：\(f'(x)\approx\dfrac{f(x+h)-f(x-h)}{2h}\)
\end{itemize}

\subsection{线性代数}\label{ux7ebfux6027ux4ee3ux6570}

\begin{itemize}
\tightlist
\item
  \((AB)^T=B^TA^T\)；\(\mathrm{tr}(AB)=\mathrm{tr}(BA)\)
\item
  最小二乘：\(x^{*}=\mathrm{arg\min}_x\|Ax-b|_2^2\)（数值用
  \texttt{lstsq}）
\item
  SVD：\(A=U\Sigma V^T\)；对称矩阵：\(A=Q\Lambda Q^T\)
\end{itemize}

\subsection{概率统计}\label{ux6982ux7387ux7edfux8ba1}

\begin{itemize}
\tightlist
\item
  \(E[X]=\sum x\,p(x)\)；\(\mathrm{Var}(X)=E[X^2]-(E[X])^2\)
\item
  样本方差：\(s^2=\frac{1}{n-1}\sum(x_i-\bar{x})^2\)
\item
  置信区间：\(\bar{x}\pm t_{\alpha/2,n-1}\cdot s/\sqrt n\)
\item
  线性回归：\(y=X\beta+\varepsilon\)，\(\hat{\beta}=(X^TX)^{-1}X^Ty\)，\(R^2=1-\mathrm{SSE}/\mathrm{SST}\)
\end{itemize}

\subsection{机器学习}\label{ux673aux5668ux5b66ux4e60}

\begin{itemize}
\tightlist
\item
  逻辑回归（sigmoid）：\(p=1/(1+e^{-\theta^Tx})\)；损失 = 交叉熵
\item
  梯度下降：\(\theta\gets\theta-\alpha\nabla L\)
\item
  正则化：Ridge \(L+\lambda\|\theta|^2\)；Lasso \(L+\lambda\|\theta|_1\)
\end{itemize}

\section{F.4
数值稳定性（科学计算必修，讲解）}\label{f.4-ux6570ux503cux7a33ux5b9aux6027ux79d1ux5b66ux8ba1ux7b97ux5fc5ux4feeux8bb2ux89e3}

浮点数是有限精度（约 15\textasciitilde16
位有效小数），``数学上对的公式''在电脑上可能''崩''：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{比较}：别用 \texttt{==} 比浮点；用 \texttt{np.isclose} /
  \(|a-b|<10^{-9}\)；
\item
  \textbf{条件数}：\(\mathrm{cond}(A)\) 大 → 病态，解对输入过敏；
\item
  \textbf{灾难性消去}：\(\sqrt{x^2+1}-x\)（大 \(x\)）→ 改写
  \(1/(\sqrt{x^2+1}+x)\)；
\item
  \textbf{缩放}：优化/距离/聚类前标准化（\texttt{StandardScaler}）；
\item
  \textbf{对数域}：连乘小概率取 log 防下溢；分类用 \texttt{log\_proba}；
\item
  \textbf{可复现}：固定种子（\texttt{random\_state} /
  \texttt{default\_rng(seed)}）。
\end{enumerate}

手算直觉：\(x=10^8\) 时 \(\sqrt{x^2+1}-x\) 双精度算出来约 0（真值约
\(5\times 10^{-9}\)）------不是数学错了，是浮点''看不见''那么小的差。

\section{F.8
数值小技巧（速查）}\label{f.8-ux6570ux503cux5c0fux6280ux5de7ux901fux67e5}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  求和/连乘尽量用向量化；避免 Python 循环里重复分配大数组；
\item
  概率乘积取对数：\texttt{np.log} + \texttt{np.sum}；
\item
  画图前把大数值日志化（\texttt{plt.yscale("log")}）；
\item
  长序列先 \texttt{np.fft.fft} 看谱，再决定滤波/平滑；
\item
  拟合前先 \texttt{np.nan\_to\_num}/去掉缺失，避免 NaN 传染；
\item
  复现：所有随机过程给 \texttt{random\_state}/种子，并写进报告。
\end{enumerate}
