\section{D.1
直觉故事：朋友圈里的''谁最重要''}\label{d.1-ux76f4ux89c9ux6545ux4e8bux670bux53cbux5708ux91ccux7684ux8c01ux6700ux91cdux8981}

想象你问''班里的社交核心是谁''。只看谁朋友多（\textbf{度中心性}）不一定准：一个人认识
10 个互相不认识的人，另一个人认识 10
个彼此都认识的人，前者更像''桥梁''。所以''重要''有不同定义：

\begin{itemize}
\tightlist
\item
  \textbf{度中心性}：连接数多 → ``活跃''；
\item
  \textbf{接近中心性}：到所有人平均距离短 → ``信息传得快''；
\item
  \textbf{介数中心性}：很多最短路经过它 → ``枢纽/瓶颈''；
\item
  \textbf{PageRank}：被''重要的人''指向 → ``影响力''（搜索引擎逻辑）。
\end{itemize}

同一个网络，不同''重要''答案不同------所以做网络分析，第一步是\textbf{明确要问什么}。

\subsection{D.2.2
基本量：度、连通、树}\label{d.2.2-ux57faux672cux91cfux5ea6ux8fdeux901aux6811}

\begin{itemize}
\tightlist
\item
  \textbf{度 \texttt{deg(v)}}：邻边数；有向图分\textbf{入度/出度}。
\item
  \textbf{路径}：点与点之间能到达；\textbf{连通分量}：互为连通的最大点集。
\item
  \textbf{树}：无环连通图，\texttt{n} 个点恰好 \texttt{n-1}
  条边------网络的最''轻''骨架。
\item
  \textbf{二分图}：点分成两类，边只在类间（学生-选课、用户-商品）。
\end{itemize}

\subsection{D.2.3
加权与有向}\label{d.2.3-ux52a0ux6743ux4e0eux6709ux5411}

\begin{itemize}
\tightlist
\item
  \textbf{加权图}：边带距离/成本/强度；最短路、最小生成树、网络流都依赖这些权。
\item
  \textbf{有向图}：边有方向（关注、引用、资金流）；``PageRank''``拓扑排序''只对有向图有意义。
\end{itemize}

\section{D.3
经典算法：思路与手算}\label{d.3-ux7ecfux5178ux7b97ux6cd5ux601dux8defux4e0eux624bux7b97}

\subsection{D.3.1 遍历：BFS 与
DFS}\label{d.3.1-ux904dux5386bfs-ux4e0e-dfs}

\begin{itemize}
\tightlist
\item
  \textbf{BFS（广度优先）}：一层层向外扩散。无权图最短路就靠它；手算例子：从
  A 出发，先到 B、C，再到 D，路径 A→C→D 是两步最短。
\item
  \textbf{DFS（深度优先）}：一条路走到黑再回头。用于检测环、连通分量、拓扑排序。
\end{itemize}

手算 Dijkstra（无向、权为边上的数字）：从 A 出发，初始
dist：A=0、B=∞、C=∞、D=∞。先松弛到 B=2、C=5；取最小 B=2，松弛 C 得 2+1=3
\textless5，更新；再取 C=3，松弛 D=3+4=7；最后 D=7。三步得到 A→C→B→D
的路径长度。

\subsection{D.3.3
最小生成树（MST）}\label{d.3.3-ux6700ux5c0fux751fux6210ux6811mst}

目标：用总权重最小的边把所有点连通（且无环）。\textbf{Kruskal}：边按权从小到大排序，用并查集判断是否会成环，不成环就加入。手算直觉：选最便宜的边，只要不形成圈就保留------最后恰好
\texttt{n-1} 条边。

\subsection{D.3.4
中心性与社区}\label{d.3.4-ux4e2dux5fc3ux6027ux4e0eux793eux533a}

\begin{itemize}
\tightlist
\item
  \textbf{介数中心性}：统计每条最短路经过某点的次数------``关键枢纽''；
\item
  \textbf{PageRank}：随机游走者在图上散步的稳态分布；被高权重节点指向的节点权重更高；
\item
  \textbf{社区发现}：把网络切成''内部紧密、外部稀疏''的组。常用
  \textbf{Louvain}（贪心模块度优化）、\textbf{谱聚类}（拉普拉斯特征向量）、标签传播。
\end{itemize}

\section{D.7
补充：社区发现的直觉与模块度}\label{d.7-ux8865ux5145ux793eux533aux53d1ux73b0ux7684ux76f4ux89c9ux4e0eux6a21ux5757ux5ea6}

社区发现的''好''标准是\textbf{模块度}：比较''社区内部实际边数''和''随机网络下的期望边数''。直觉：

\begin{itemize}
\tightlist
\item
  模块度高 = 社区内部比随机更密、社区之间比随机更疏；
\item
  Louvain 算法是''先局部合并、再全局聚合''的贪心，快且常用；
\item
  敏感性：同一个网络，不同分辨率/随机种子可能给出不同社区------\textbf{要报告所用的方法与参数}。
\end{itemize}

\textbf{一句话总结}：社区是''相对''概念，结论要配方法与参数一起给，不能只画一张颜色图。
