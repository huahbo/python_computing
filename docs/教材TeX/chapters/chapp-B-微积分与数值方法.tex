\section{B.2
关键概念（带手算小例子）}\label{b.2-ux5173ux952eux6982ux5ff5ux5e26ux624bux7b97ux5c0fux4f8bux5b50}

\subsection{B.2.1
导数、偏导与梯度}\label{b.2.1-ux5bfcux6570ux504fux5bfcux4e0eux68afux5ea6}

手算 \(f(x)=x^2\) 在 \(x=2\)：\(\dfrac{(2+h)^2-4}{h}=4+h\to 4\)。所以
\(f'(2)=4\)。

多元 → 偏导 → 梯度：

\[\nabla f(x)=\Big(\frac{\partial f}{\partial x_1},\ldots,\frac{\partial f}{\partial x_n}\Big)\]

含义：指向 \(f\) 上升最快的方向；负梯度 = 最速下降方向。

\textbf{导数速查}：\((x^n)'=nx^{n-1}\)、\((\sin x)'=\cos x\)、\((e^x)'=e^x\)、\((\ln x)'=1/x\)、\((uv)'=u'v+uv'\)、\((f(g(x)))'=f'(g(x))g'(x)\)。

\subsection{B.2.2
积分与基本定理}\label{b.2.2-ux79efux5206ux4e0eux57faux672cux5b9aux7406}

\begin{itemize}
\tightlist
\item
  不定积分 = 求原函数；定积分 = 面积/累积；
\item
  基本定理：\(\int_a^b f'(x)\,dx = f(b)-f(a)\)；
\item
  手算：\(\int_0^1 3x^2\,dx = x^3\big|_0^1 = 1\)。
\end{itemize}

\subsection{B.2.3
为什么还要''数值''（难点）}\label{b.2.3-ux4e3aux4ec0ux4e48ux8fd8ux8981ux6570ux503cux96beux70b9}

实际函数常无解析式，或表达式复杂到算不动。近似方法：

\begin{itemize}
\tightlist
\item
  \textbf{数值微分}（中心差分）：\(f'(x)\approx\dfrac{f(x+h)-f(x-h)}{2h}\)，误差
  \(O(h^2)\)（比前向差分 \(O(h)\) 好）；
\item
  \textbf{数值积分}：梯形（一阶）、辛普森（二阶抛物线）、高斯求积（高阶、自适应加密）。\textbf{误差阶}告诉你''步长减半，误差怎么降''------这是数值分析最核心的思想。
\end{itemize}

\textbf{为什么牛顿法快}：\(f\) 在 \(x_k\)
附近用二阶泰勒近似，令导数为零得
\(x_{k+1}=x_k-H^{-1}\nabla f\)。凸、光滑、好初值时\textbf{二次收敛}（误差平方级下降）。

\textbf{步长手算}：\(f(x)=(x-3)^2\)，\(x_0=1\)，\(\nabla f=2(x-3)=-4\)。\(\alpha=0.5\)
→ 一步到 \(x=3\)；\(\alpha=2\) →
\(x=9\)，直接弹过最优------``步长太大震荡''。

\subsection{B.3.2 插值 vs
拟合（本科高频考点）}\label{b.3.2-ux63d2ux503c-vs-ux62dfux5408ux672cux79d1ux9ad8ux9891ux8003ux70b9}

\begin{itemize}
\tightlist
\item
  \textbf{插值}：曲线\textbf{穿过}每个已知点（拉格朗日、样条）；高次会\textbf{龙格震荡}（边界剧烈摆动）------不要迷信''高次''；
\item
  \textbf{拟合}：曲线\textbf{接近}所有点（最小二乘，见附录
  A）；噪声数据永远优先拟合（+正则化）；
\item
  选择：数据精确且要过点 → 样条插值；有噪声 → 拟合。
\end{itemize}

\subsection{B.3.3
傅里叶变换（FFT）}\label{b.3.3-ux5085ux91ccux53f6ux53d8ux6362fft}

\[X(k)=\sum_{n=0}^{N-1}x(n)\,e^{-2\pi i kn/N}\]

把信号拆成不同频率正弦叠加。FFT 复杂度 \(O(N\log N)\)（直接 DFT 是
\(O(N^2)\)）；用途：找周期、去噪、平滑；截断信号会\textbf{频谱泄漏}（加窗缓解）。

\subsection{B.3.4
常微分方程（ODE）}\label{b.3.4-ux5e38ux5faeux5206ux65b9ux7a0bode}

初值问题 \(y'(t)=f(t,y)\ ,\ y(t_0)=y_0\)：

\begin{itemize}
\tightlist
\item
  \textbf{欧拉法}：\(y_{n+1}=y_n+h f(t_n,y_n)\)------简单但误差大（\(O(h)\)）；
\item
  \textbf{RK45}：每步取 4\textasciitilde5 个点的加权平均，误差约
  \(O(h^4)\)，\texttt{scipy.integrate.solve\_ivp} 默认；
\item
  \textbf{刚性问题}：特征值相差悬殊时，显式方法步长被迫极小 → 换隐式方法
  \(\mathrm{method="Radau"}\)。
\end{itemize}

\section{B.9 综合案例：拟合 +
积分（做一道完整数值题）}\label{b.9-ux7efcux5408ux6848ux4f8bux62dfux5408-ux79efux5206ux505aux4e00ux9053ux5b8cux6574ux6570ux503cux9898}

\textbf{问题}：已知某产品的''价格-销量''散点，希望给出''总需求''（曲线下的面积）与''最优定价''（利润最大点）。

步骤：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  用最小二乘拟合价格 p 与销量 q 的线性/二次关系（附录 A 的正规方程或
  np.polyfit）；
\item
  用数值积分估算某区间的''总销量''（面积）；
\item
  用优化求利润 f(p) = p*q(p) 的最大值点；
\item
  用中心差分验证最优点的导数为 0。
\end{enumerate}

参考要点代码：

\begin{verbatim}
import numpy as np
from scipy import integrate, optimize
p = np.array([1., 2., 3., 4.]); q = np.array([9., 7., 5., 3.])
coef = np.polyfit(p, q, 2)
total = integrate.quad(lambda x: np.polyval(coef, x), 1, 4)[0]
profit = lambda x: -x * np.polyval(coef, x)
best = optimize.minimize_scalar(profit, bounds=(1, 4), method="bounded")
print(total, best.x)
\end{verbatim}

\textbf{反思}：把''数据→模型→积分→优化''串起来，就是科学计算的常用闭环。
