\section{B.1
直觉故事：从''瞬时速度''说起}\label{b.1-ux76f4ux89c9ux6545ux4e8bux4eceux77acux65f6ux901fux5ea6ux8bf4ux8d77}

你开车，两小时走了 180 公里，平均速度 90
公里/小时。可如果车是''先快后慢''呢？平均速度看不出任何细节。

\textbf{导数}就是回答''某一瞬间的速度''：把时间间隔缩到无限小，平均速度的极限。几何上它是曲线某点的切线斜率；物理上它是变化率；机器学习里它是''参数往哪个方向调、调多少''的依据。

\textbf{积分}是反向累积：已知每秒的速度，求走过的总路程------把每秒速度乘上时间加总，间隔越细越准。几何上它是曲线下面积；概率里它是期望。

\textbf{泰勒展开}把''复杂函数''在某个点附近写成多项式：\texttt{f(x+h)\ ≈\ f(x)\ +\ f\textquotesingle{}(x)h\ +\ f\textquotesingle{}\textquotesingle{}(x)h²/2}。它看起来很''取巧''，但牛顿法、误差分析、反向传播的直觉全都建立在''局部用直线/抛物线逼近''上。

\subsection{B.2.1
导数与偏导}\label{b.2.1-ux5bfcux6570ux4e0eux504fux5bfc}

手算一个简单例子：\texttt{f(x)\ =\ x²}。按定义算
\texttt{f\textquotesingle{}(2)}：\texttt{(\ (2+h)²\ -\ 4\ )\ /\ h\ =\ (4h\ +\ h²)/h\ =\ 4\ +\ h\ →\ 4}（\texttt{h→0}）。所以曲线在
\texttt{x=2} 的斜率是 4。

多元函数就要\textbf{偏导}（一次只动一个变量），把偏导排成向量就是\textbf{梯度}：

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{梯度 grad f(x) = (∂f/∂x1, ∂f/∂x2, …, ∂f/∂xn)}
\NormalTok{几何意义：指向 f 上升最快的方向；负梯度 = 最速下降方向}
\end{Highlighting}
\end{Shaded}

\subsection{B.2.2
积分与基本定理}\label{b.2.2-ux79efux5206ux4e0eux57faux672cux5b9aux7406}

\begin{itemize}
\tightlist
\item
  不定积分 \texttt{∫\ f(x)\ dx} 是''求原函数''（反导数）；
\item
  定积分 \texttt{∫\_a\^{}b\ f(x)\ dx}
  是面积/累积；微积分基本定理：\texttt{∫\_a\^{}b\ f\textquotesingle{}(x)dx\ =\ f(b)\ -\ f(a)}。
\end{itemize}

手算例子：\texttt{∫\_0\^{}1\ 3x²\ dx\ =\ x³\ \textbar{}\_0\^{}1\ =\ 1}------正好验证''导数与积分互逆''。

\subsection{B.2.3
数值微分与积分（为什么还要''近似''）}\label{b.2.3-ux6570ux503cux5faeux5206ux4e0eux79efux5206ux4e3aux4ec0ux4e48ux8fd8ux8981ux8fd1ux4f3c}

很多实际函数没有解析式（例如只有采样数据），或者表达式复杂到 SymPy
也算不动。此时用近似：

\begin{itemize}
\tightlist
\item
  中心差分：\texttt{f\textquotesingle{}(x)\ ≈\ (f(x+h)\ -\ f(x-h))\ /\ (2h)}，误差
  \texttt{O(h²)}，比前向差分更准；
\item
  数值积分：梯形法则把曲线下的面积分成梯形求和；辛普森法则用二次抛物线逼近，更准；高阶自适应（\texttt{scipy.integrate.quad}）自动加密。
\end{itemize}

\subsection{B.3.1
优化：找''最低点''}\label{b.3.1-ux4f18ux5316ux627eux6700ux4f4eux70b9}

问题：\texttt{min\_x\ f(x)}。

一个手算直觉：\texttt{f(x)\ =\ (x-3)²}，最优在 \texttt{x=3}。若
\texttt{x0\ =\ 1}，\texttt{grad\ f\ =\ 2(x-3)\ =\ -4}，更新
\texttt{x\ ←\ 1\ -\ α(-4)}；α 太大（如 1）会直接跳到
5，再弹回来------这就是''步长太大震荡''。

\begin{quote}
优化是几乎所有机器学习和统计建模的引擎（见附录 E 的梯度下降）。
\end{quote}

\subsection{B.3.2
插值与拟合：穿过点还是接近点}\label{b.3.2-ux63d2ux503cux4e0eux62dfux5408ux7a7fux8fc7ux70b9ux8fd8ux662fux63a5ux8fd1ux70b9}

\begin{itemize}
\tightlist
\item
  \textbf{插值}：曲线必须\textbf{经过}每个已知点（拉格朗日、样条）。适合''数据精确、形状重要''；
\item
  \textbf{拟合（最小二乘）}：曲线\textbf{接近}所有点（多项式拟合、岭回归）。适合''数据有噪声''。
\end{itemize}

例子：已知
\texttt{(0,0),\ (1,1),\ (2,4)}。线性拟合会给一条''平均线''；二次插值会精确穿过三点（但再高次就容易震荡------龙格现象）。\textbf{数据有噪声时永远优先拟合加正则化，而不是高次插值。}

\subsection{B.3.3
傅里叶变换：把信号拆成''频率''}\label{b.3.3-ux5085ux91ccux53f6ux53d8ux6362ux628aux4fe1ux53f7ux62c6ux6210ux9891ux7387}

直觉：任何周期信号都能写成不同频率正弦波的叠加。傅里叶变换把''时间域''的信号变成''频率域''的频谱
\texttt{X(k)\ =\ Σ\ x(n)\ e\^{}\{-2πikn/N\}}。

\begin{itemize}
\tightlist
\item
  FFT 复杂度 \texttt{O(N\ log\ N)}，所以长序列也能秒级处理；
\item
  用途：找周期（电商销量季节）、去噪（滤掉高频）、平滑；
\item
  注意：非周期/截断信号会出现''频谱泄漏''（加窗缓解）。
\end{itemize}

\end{Shaded}
